## [0.6.3] — 2026-10-22

跨端调用体验与条件段落实时展开强化：变量卡片新增快捷复制通道 (Alt+C)、条件段落实时展开求值闭环、全套自动化门禁体检 723 项通过。

### 新增与交互优化

- **变量填参卡片新增「⧉ 复制」通道 (Alt+C)**：解决用户在微信、Word、QQ、浏览器等外部窗口使用变量模板时的痛点；用户填入参数后无需先插入编辑器，直接点击「⧉ 复制」或按 `Alt+C` / `Ctrl+Shift+C` 即可将展开后的最终正文写入剪贴板并自动销毁弹窗。
- **条件开关段落（toggle）实时展开与双向状态同步**：模板声明 `{{xlc:ask:发票=请下载专票|toggle}}` 时，变量卡片直接渲染为优雅的滑动开关，开启时包含文本，关闭时彻底剔除，并在实时展开预览区即时同步回显。
- **多源同步比对卡片与列表焦点动效**：同步比对模态框支持关键词与状态复合过滤，主列表行增加 2px 焦点指示与悬停微动效。

### 验证与已知边界

- 全套质量门禁：单元测试 723/723 全绿通过、TypeScript 类型检查 0 错误、错误处理静态扫描、密钥安全扫描、安装包根相对结构校验（13 项必需资源健全）全部通过。
