# 快速增加常用语与使用引导调研（2026-10-09）

## 研究范围与证据边界

本记录只补充快速增加、使用引导和预置分类的调研，不改变产品真源、侧车和宿主能力边界。用户附件中的红框是需求标记：①位于搜索无结果区域，②位于弹窗顶栏右侧的空白区域；图片本身没有额外的产品说明文字。

项目现状依据仓库 `README.md`、`src/ui/dialog.ts`、`src/ui/capture.ts`、`src/index.ts` 和既有定位/ADR。Quicker 资料来自官方动作页 [常用语（动作信息）](https://getquicker.net/Sharedaction?code=7f95cd24-fc50-4180-266c-08dbcf12c669)，于 2026-10-09 直接读取页面 HTML。页面中的 `quicker:` 预览协议、B 站视频、GIF 和登录后动作安装没有在本研究环境执行，因此以下“观察”限于页面公开文字、链接和截图；“建议”是面向小驴常用的产品设计推断。

## 当前项目已有的增加途径

README 已列出八类捕获入口：选中文字、当前块、块引用、链接、图片、文档树选中文档、剪贴板，以及命令/面包屑/顶栏/编辑器工具栏。实现中还存在：

- `CaptureDialog.newManual()`：打开空白新建表单。
- 选区、当前块、当前文档、剪贴板捕获；链接和图片右键捕获；类型自动推断。
- 「快速捕获剪贴板为条目」命令（默认 `⌥⇧V`），直接入库并按首行生成标题、同文去重。
- 搜索弹窗移动端底栏已有「＋新建」；空库态已有「＋ 新建条目」。
- 搜索无结果态目前只显示提示（AI 语义找、收藏为空等各有提示）；只有 `emptyLibrary` 分支渲染新建按钮。因此附件①对应的“带查询无结果”还缺少行动按钮。
- 桌面顶栏目前是搜索框和键盘提示行；`newManual` 已通过依赖注入提供给弹窗，但桌面顶栏没有常驻「新建」按钮。因此附件②可直接复用同一回调，不需要新增存储模型。

这些入口符合 ADR 0002：新条目正文仍写入库文档真实块，标题/标签/分类写 `custom-xlc-*` 属性，侧车只保存 UI 状态。

## Quicker 页面实证（观察，不等同于建议）

官方页面把动作标题描述为“快捷短语/对话模板/电话/地址/文本/密码/素材/代码/实时搜索/连续发送/标签/文件”。页面明确列出多种帮助入口，而不是只给一个安装按钮：

- 「点击进入 B 站的详细视频使用说明」；
- 「实时搜索使用技巧」；
- 「首次使用需绑定文件夹（同步说明）」；
- 「动作使用说明」；
- 「学习使用此动作的更多方式」；
- 「如何新增常用语/标签文件」；
- 讨论区还出现「如何一键增加新的常用语」主题链接。

页面自述的主要能力包括：实时搜索收藏语、点击即发送、批量导出搜索结果、按标签连续复制/发送、文本本地保存、批量编辑、右键快速编辑标签文件、多行保存/发送、选词自动放入搜索框，以及 `&`、`|` 搜索组合符。页面也把“地址/网址混乱”“文本过多难找”“缺少标签/图标分类”“无法拼音模糊搜索”等作为痛点。页面顶部提供“复制到剪贴板”安装动作，并明确提示“在面板窗口的空白按钮上右键粘贴”。

可复用的启发是“每个高频动作旁边都有可点的下一步说明”和“增加内容是一条明确的一键路径”。不能把 Quicker 的“密码”描述照搬到小驴常用：本项目定位明确排除密码管理，预置内容应使用占位符且不放真实个人信息。

## 针对本次五项需求的建议

### 1. ② 顶栏常驻增加按钮

在桌面搜索框右侧、键盘提示行同一层固定放置 `＋ 新建`（或 `＋ 常用语`）按钮；移动端保留底栏按钮，并在窄宽度时把顶栏按钮折叠成仅图标但保留 `aria-label`。点击直接调用现有 `newManual()`，避免复制另一套表单。

按钮旁可提供一个小型动作菜单，优先顺序如下：

1. 新建空白条目（当前行为）；
2. 从剪贴板新建（打开已有 `captureFromClipboard()` 表单，保留确认和元数据编辑）；
3. 快速保存剪贴板（已有 `quickCaptureFromClipboard()`，明确“一步入库”）；
4. 捕获当前选区/块/文档（没有上下文时显示诚实提示）。

顶栏按钮应在搜索、筛选、收藏/最近/无结果状态下都存在；按钮不随列表重绘，以免用户找不到入口。

### 2. ① 搜索无内容时显示增加按钮

当普通关键词搜索结果为 0 时，在“没有本地结果”文案下方显示 `＋ 新建“<关键词>”`。建议打开新建表单并**仅预填标题候选**，正文仍为空，用户确认后保存；这样不把搜索词静默写成正文。查询以 `?` 开头时不要把整个查询预填为标题，可显示 `＋ 新建条目` 并提示“可把语义描述带入 AI 草稿”。

空库态继续使用现有 `＋ 新建条目`；收藏/最近为空、类型/标签/分类筛选为空时，按钮文案统一为 `＋ 新建条目`，并在旁边提供“清除筛选”以免用户误以为库没有数据。创建成功后应清除当前查询并回到新条目，显示统一回执。

### 3. 更多方便增加常用语的途径（按投入/收益排序）

| 优先级 | 入口 | 交互建议 | 现有能力复用 |
| --- | --- | --- | --- |
| P0 | 顶栏常驻按钮 | 新建菜单，所有搜索状态可见 | `newManual`、捕获方法 |
| P0 | 无结果 CTA | 标题候选 + 新建表单；`?` 查询不直填 | `newManual`、搜索状态 |
| P0 | 当前编辑器上下文 | 选区/当前块/链接/图片右键捕获 | `CaptureDialog` 现有方法 |
| P1 | 剪贴板路径 | 「从剪贴板新建」可编辑；「快速保存」一步入库；重复时显示已存在条目 | `captureFromClipboard`、`quickCaptureFromClipboard` |
| P1 | 面包屑/顶栏/工具栏 | 在用户正浏览或编辑的位置提供捕获，不要求先打开搜索 | 已注册命令/工具栏回调 |
| P1 | 引导页和帮助卡 | 首次打开显示三步：复制/选择 → 新建 → 插入；随时可从 `? 使用方法` 打开 | 设置/首跑引导框架 |
| P2 | 模板包/场景包 | 「导入示例库」和「从模板包导入」，导入前显示分类、变量和条目数 | 现有 `xlc-pack` 导入/回执 |
| P2 | 外部迁移 | 粘贴 Espanso 等配置，逐条预览后导入；不做后台监听 | 现有导入冲突策略 |

无障碍和键盘：给顶栏按钮稳定的 `aria-label`，桌面可增加 `Alt+A`（或在键盘提示行展示的快捷键），表单保存/取消维持现有 Enter/Esc 语义；移动端按钮触控尺寸保持 44px。

### 4. 增加常用语使用方法介绍

建议提供一张可重复打开的“使用方法”卡（顶栏 `？`、底栏设置旁或首跑完成页均可达），内容控制在一屏：

1. **增加**：`＋ 新建`、选区/当前块右键、剪贴板快速捕获；
2. **找到**：关键词、拼音、标签/分类筛选、收藏/最近/常用排序；
3. **使用**：Enter 插入、Ctrl/⌘+Enter 复制、Alt+1~9 直达、打开来源；
4. **模板**：`{{xlc:ask:字段}}` 在插入前询问，`{{xlc:date}}`/`{{xlc:clipboard}}` 在插入或复制时替换，`{{xlc:snippet:标题}}` 展开片段；
5. **安全**：正文在思源块中，AI 默认关闭；不要把密码等机密放入常用语库。

说明卡应链接到一个可编辑的“📖 小驴常用：使用说明”条目或内置帮助文档；不要只依赖外部网页，以便离线和移动端查看。Quicker 页面提供“视频、搜索技巧、动作说明、新增常用语、更多方式”等分层链接，可作为信息架构参照。

### 5. 内置分类与模板介绍

建议把“预置”做成**首次运行可勾选导入的模板包**，而不是每次启动偷偷创建条目。每个模板有稳定逻辑 ID、分类和短说明；导入幂等，用户可以删除/改名/再分享。分类仅写 `custom-xlc-category`，不把分类清单塞进侧车。

推荐首批分类（可全部取消）：

| 分类 | 示例模板（仅占位符） | 使用规则说明 |
| --- | --- | --- |
| 联系方式 | 邮箱签名、电话、地址卡片 | 用 `{{xlc:ask:姓名}}`、`{{xlc:ask:邮箱}}`；不要填真实隐私作为示例 |
| 客服/沟通 | 道歉、进度跟进、SLA 说明 | 收件人、单号、日期用 ask/date；插入前确认语气 |
| 邮件/文档 | 开场、结尾、会议纪要骨架 | Markdown 条目保留标题/列表结构 |
| AI 提示词 | 摘要、翻译、代码审查 | 主题/语言/长度用 ask；AI 出域开关仍由用户控制 |
| 研发/写作 | Bug 报告、周报、SQL/代码骨架 | code 类型中的占位符按字面保存，避免改写代码 |
| 链接/网址 | 常用站点、项目地址 | URL 类型保存链接标题和来源，不自动访问 |

“账号/密码”不列为内置分类，避免暗示插件是密码管理器。模板包首页可附一条“开始前先读我”，说明分类可编辑、变量本次填写不回写、来源块可回链、删除插件不会删除库内容。

## 可验收的最小口径

- 顶栏 `＋ 新建` 在桌面普通搜索、无结果、收藏/最近为空和筛选状态均可见；点击只打开一次现有捕获表单。
- 普通查询无结果显示新建 CTA；点击后标题候选可编辑、正文不被静默填充；取消不创建块，保存有成功/失败回执。
- `?` 语义查询和提供方失败态不误把 AI 查询写进正文；空库态原有 CTA 不回归。
- 首跑模板包可选择分类、可跳过；导入后条目是真实思源块，重复导入按稳定 ID 跳过，分类和变量元数据保真。
- 使用说明在桌面和移动端可达，明确已验证能力与待验证宿主能力，不把页面调研或本地测试当成真实宿主验收。
