# T-0115 / R262：变量下拉与随机选择选项多维分隔符归一化

日期：2026-10-19

## 目标

统一变量下拉选择（`parseAskField`）与随机占位符（`pickRandomOption`）的选项分隔符处理，彻底消除中文输入法下的全角标点阻断问题：
1. 解决中文用户编写常用语模板时，随手输入的中文全角逗号 `，`（`\uFF0C`）或顿号 `、`（`\u3001`）导致整个选项列表被当作单一字符串处理的痛点；
2. 在 `src/model/variables.ts` 的 `parseAskField` 中接入 `/[,，、]/` 正则分割，支持 `{{xlc:ask:方案|标准版，专业版，旗舰版}}` 与 `{{xlc:ask:阶段|需求澄清、原型确认、研发交付}}` 自然识别为多选项 `select` 字段；
3. 在 `src/model/placeholders.ts` 的 `pickRandomOption` 中同步接入 `/[,，、]/` 正则分割，支持 `{{xlc:random|红包，优惠券，感谢信}}` 与 `{{xlc:random|特等奖、一等奖、二等奖}}` 随机命中；
4. 保持边界安全性：继续执行各选项去首尾空白（`trim()`）、空值过滤（`filter(Boolean)`）与最大 16 项上限截断，与 `src/model/item.ts` 中的 `cleanTagList` 保持相同水准的多维标点容错。

## 实现

- `src/model/variables.ts`：
  - `parseAskField` 将 `rawOptions.split(",")` 替换为 `rawOptions.split(/[,，、]/)`。
- `src/model/placeholders.ts`：
  - `pickRandomOption` 将 `rawArg.split(",")` 替换为 `rawArg.split(/[,，、]/)`。
- `tests/r67-variables.test.cjs`：
  - 新增 `ask 选项切分：支持中文全角逗号与顿号（[,，、]）归一化` 专项测试用例，覆盖中文全角逗号、顿号、混用多重分隔符与全文模板提取断言。
- `tests/r160-dynamic-placeholders.test.cjs`：
  - 新增 `随机选择：支持中文逗号与顿号（[,，、]）切分选项` 专项测试用例，覆盖中文逗号与顿号切分的随机分布断言。
