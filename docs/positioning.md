# 小驴常用 · 产品定位与功能-效果总表

> 版本：2026-10-07 v3（同类产品调研后修订，调研证据见 §六）。上一版：2026-10-06 v2。
> 原型基准：[docs/design/prototype.html](design/prototype.html)（v3）+ [docs/design/design-spec.md](design/design-spec.md)。

## 一、一句话定位

**思源笔记的内容资产层：高频内容不是复制粘贴的文本，而是有元数据、有来源、可检索、可变通、可共享的真实块资产。**

> 一次捕获，处处调用；块是真源，AI 是变通，变量是活的。

## 二、三个一级场景（v3 明确）

| 场景 | 典型内容 | 吃到的能力 |
| --- | --- | --- |
| ① 客服 / 邮件 / IM 模板 | 道歉回复、跟进话术、SLA 说明、签名 | 变量填充（收件人/单号每次不同）、AI 变换（正式化/缩短）、失效可见 |
| ② AI 提示词库 | 写作 prompt、代码审查 prompt、翻译指令 | 变量填充（主题/语言/篇幅）、AI 语义找（`?` 前缀）、provider 供其他插件调用 |
| ③ 研发 / 写作常用件 | SQL 模板、会议纪要骨架、周报开头、块引用 | 类型化插入语义、拼音直达、双栏预览、真源回链 |

## 三、定位四边界（做什么 / 明确不做什么）

| 维度 | 定位内 | 定位外（拒绝） |
| --- | --- | --- |
| 内容 | 常用语、客服/邮件模板、代码、链接、图片、附件、块结构、块引用、AI 提示词 | 密码、剪贴板历史、任意文件仓库 |
| 动作 | 搜索 → 预览 → 变量填充 → 插入/复制/打开来源；AI 整理与变换 | 全局热字符串自动替换、自动发送到外部应用、批量群发 |
| 数据 | 条目锚定真实思源块（真源/同步/回链） | 私有数据库第二真源 |
| AI | 整理建议、草稿生成、调用时变通、语义找条目 | 无人值守自动改写、内容出域无告知 |

与竞品的本质差异（详见 §六调研）：
- vs **Quicker/uTools 常用语**：他们是孤立文本的「收藏→粘贴」；小驴常用的每条内容是**活的思源块**——可同步、可回链、失效可见、可被其他插件经 `xiaolv-common/v1` 复用。
- vs **Espanso/TextExpander/Beeftext**：他们有变量与填充表单但**不认识思源**（无块引用、无文档结构、无笔记内检索）；我们补齐变量/填充后，同时保有块语义。
- vs **思源内置模板文件夹**：模板是文档级、无元数据、无检索、无来源管理；我们是**条目级资产**，带搜索/筛选/键盘直达/移动端/AI。

## 五、新功能规划（v3 新增，分三期）

> 原则：每期独立可发布；先补齐同类「合格线」，再放大「真源+AI」差异。原型见 prototype.html v3 对应屏。

### P0 · v0.2 变量与智能排序（补齐同类合格线，吃满场景①②）
| # | 功能 | 对标 | 验收口径 |
| --- | --- | --- | --- |
| F1 | **插入时变量填充**：`{{xlc:ask:字段}}`（文本）/ `{{xlc:ask:字段\|选项A,选项B}}`（下拉）/ 日期字段 → 插入前弹轻量填充卡片，Enter 插入、Esc 取消、Tab 切字段 | TextExpander fill-ins；Espanso forms | 含 ≥2 变量条目端到端；无变量条目零打扰 |
| F2 | **变量系统 v2**：`{{xlc:cursor}}` 光标落点、`{{xlc:doc}}` 当前文档名、`{{xlc:clipboard}}` 剪贴板（权限拒绝诚实降级） | Templater cursor/date、Espanso clipboard | 不可用变量明示跳过，不静默丢 |
| F3 | **使用计数 + 智能排序档**：插入记次数；排序档新增「常用」（次数×时间衰减），与手动/最近/标题并列 | Raycast 频率排序；TextExpander 使用统计 | 计数存侧车可重建；排序档可关 |

### P1 · v0.3 规模化组织（库 >200 条的体验）
| # | 功能 | 对标 |
| --- | --- | --- |
| F4 | **分类分组导航**：列表按分类分组 sticky 头 + 空分类态；筛选行新增分类下拉 | massCode 文件夹+标签 |
| F5 | **片段嵌套**：`{{xlc:snippet:标题}}` 插入时展开为另一条目内容（防环、深度 ≤3） | TextExpander nesting |
| F6 | **模板包分享**：MD 包加清单元数据（分类/变量说明），一键导入为「包」；为社区模板库铺路 | Espanso Hub（但走真源块+MD，不建私有仓库） |

### P2 · v0.4+ AI 与生态放大
| # | 功能 | 对标 |
| --- | --- | --- |
| F7 | **提示词场景包**：内置提示词模板包（写作/审查/翻译）+ 自定义 AI 变换指令（不只 5 个预设） | Quicker 便捷面板·AI 提示词 |
| F8 | **全局快速捕获**：全局快捷键 → 剪贴板 → 库（桌面端，宿主能力允许范围内） | Beeftext/Utools 快捷输入 |
| F9 | **provider 生态**：第三方插件内容源进分区（协议已备），检索聚合 | xiaolv-common/v1 既有 |

### 维持「明确不做」
热字符串全局替换、剪贴板历史、密码管理、私有云同步（借思源同步）、任意 JS/SQL 执行器。

## 六、调研证据（2026-10-07）

| 产品 | 关键事实（我们对照的差距/机会） | 来源 |

| TextExpander | **fill-ins（文本/下拉/日期）**、片段嵌套（insert snippet within snippet）、团队共享、使用统计、JS 脚本 | [snippets.textexpander.com](https://snippets.textexpander.com)、[community.textexpander.com](https://community.textexpander.com) |
| Raycast | Snippets 占位符+日期变换、频率驱动的排序、命令面板级 UX 标杆 | raycast.com（常识核对，搜索受限） |
| Beeftext | combos/分组、变量（日期/剪贴板/随机）、JSON 导入导出、富文本 | beeftext.org（常识核对，搜索受限） |
| Obsidian Templater | `tp.file.cursor(n)` 光标跳转、动态上下文（file/frontmatter）、文件夹触发 | [silentvoid13.github.io/Templater](https://silentVoid13.github.io/Templater/)（常识核对） |
| 思源内置模板/代码片段 | 文档级模板（`/模板`）、CSS/JS 片段是设置项——均无条目级元数据/检索/来源管理 | [ld246.com](https://ld246.com) |
| uTools 快捷输入/快贴 | 「设输入码→回车输入」、文本/截图收藏粘贴——孤立文本、无结构 | [u-tools.cn/plugins/detail/快捷输入](https://www.u-tools.cn/plugins/detail/%E5%BF%AB%E6%8D%B7%E8%BE%93%E5%85%A5/) |
| Quicker 便捷面板·常用语 | 常用语+快捷回复+**AI 提示词**+文本收藏合一——证明提示词管理是一级场景 | [getquicker.net](https://getquicker.net) |
| GitHub 开源片段库 | massCode/Lepton/Gisto：标签+文件夹+全文检索是基线，无来源/回链概念 | github.com（常识核对） |
