# 小驴常用 · 产品定位与功能-效果总表

> 版本：2026-10-06 v2（吸收 AI 融入决策后修订）。参考：Quicker「常用语」动作、雷切片段实验室 AI 实践、本机思源 3.8.6 内核 AI 端点核实。

## 一、一句话定位

**思源里的高频内容速调器：把你反复要用的内容，变成可搜索、可插入、可回链的条目——一次捕获，处处调用；AI 负责整理与变通，思源块负责真源与回链。**

## 二、定位四边界（做什么 / 明确不做什么）

| 维度 | 定位内 | 定位外（拒绝） |
| --- | --- | --- |
| 内容 | 常用语、客服/邮件模板、代码、链接、图片、附件、块结构、块引用 | 密码、剪贴板历史、任意文件仓库 |
| 动作 | 搜索 → 预览 → 插入/复制/打开来源；AI 整理与变换 | 自动发送到外部应用、批量群发 |
| 数据 | 条目锚定真实思源块（真源/同步/回链） | 私有数据库第二真源 |
| AI | 整理建议、草稿生成、调用时变通、语义找条目 | 无人值守自动改写、内容出域无告知 |

与 Quicker 常用语的本质差异：Quicker 的常用语是**孤立文本片段**；小驴常用的每条内容是**活的思源块**——可同步、可回链原文、失效可见、可被其他小驴插件经协议复用。

## 四、AI 融入原则（硬边界）

1. **默认关**：`aiEnabled` 默认 false；开启入口在设置面板，说明文案明示「使用你在思源 设置→人工智能 配置的模型」。
2. **不碰密钥**：只调内核 `/api/ai/chatGPT`（一次性补全）与 `/api/ai/listModels`（可用性预检）；插件不读取、不存储任何 API Key（满足安全边界 七.3）。
3. **正文出域须显式**：两级开关——「启用 AI」（仅元数据：标题/别名/标签/分类/摘要）与「允许 AI 读取完整正文」（整理/变换/草稿需要）。语义找条目默认只用元数据。
4. **原文不可变**：AI 变换结果只作为新内容预览/插入，绝不回写来源块（真源安全）。
5. **诚实失败**：未配置模型 / 空响应 / 超时（20s）→ 明确提示「AI 未配置或调用失败，请检查 设置→人工智能」，绝不拿假结果兜底。
6. **已知宿主限制（记录在案）**：`/api/ai/chatGPT` 在内核侧维护全局会话缓存（model/ai.go cachedContextMsg），插件侧以自包含 prompt 缓解、不调用 "Clear context" 避免动用户上下文；错误被吞为空串，故以 listModels 预检 + 空串双重判定。
