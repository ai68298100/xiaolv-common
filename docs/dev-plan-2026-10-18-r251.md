# T-0104 / R251：G4 搜索时间范围筛选（DateRangeFilter）模型与闭区间过滤

日期：2026-10-19

## 目标

补齐竞品差距分析（G4 / 对标 TextExpander）中的时间范围筛选能力，方便大库场景下定位特定时间创建或更新的高频常用语：
1. `src/model/search.ts` 扩展 `DateRangeFilter` 与 `SearchQuery.dateRange`；
2. 在 `passesFilters` 与 `applyBasicFilters` 中实现安全的闭区间时间戳比对；
3. 支持 `field: "updatedAt"`（默认）与 `field: "createdAt"` 双维度；
4. 容错防御：处理非法参数（非安全数字 `NaN`、`Infinity` 等忽略）、自相矛盾区间（`from > to` 直接返回不匹配）及时间戳缺失。

## 实现

- `src/model/search.ts`：
  - 导出 `DateRangeFilter` 接口（`from?: number; to?: number; field?: "updatedAt" | "createdAt"`）；
  - `SearchQuery` 增设可选 `dateRange?: DateRangeFilter` 属性；
  - `passesFilters` 增加时间范围匹配：
    - 针对 `entry[field]` 进行数值安全性校验；
    - `hasFrom && hasTo && from > to` 时返回 `false`；
    - `hasFrom && ts < from` 或 `hasTo && ts > to` 时返回 `false`；
  - `applyBasicFilters` 同步透传 `query.dateRange`，保持与类型/标签/分类/收藏范围相同的过滤语义。
- `tests/search-model.test.cjs`：
  - 新增 `dateRange 搜索时间范围筛选：闭区间过滤、createdAt/updatedAt 分野与非法参数容错` 测试用例，覆盖默认更新时间闭区间、单边 `from`/`to`、创建时间指定筛选、矛盾区间拒绝及 `applyBasicFilters` 组合断言。
