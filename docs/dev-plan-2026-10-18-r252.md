# T-0105 / R252：捕获查重算法健全性与自我误报防御

日期：2026-10-19

## 目标

完善捕获查重纯函数（`src/model/dedupe.ts`）与执行依赖链（`CaptureDeps`）：
1. 解决编辑现有条目或指定条目查重时由于未排除自身导致误判为“与已有条目同文”的问题（支持 `excludeId?: string` 选项）；
2. 强化文本规范化比对：支持全角空格 `\u3000` 与半角空格一致归一化；
3. 增加大小写比对模式（默认 `caseSensitive: false`，不区分大小写，使英文客服与日常短语更易命中查重；可按需开启敏感模式）。

## 实现

- `src/model/dedupe.ts`：
  - 导出 `DedupeOptions` 接口（`excludeId?: string; caseSensitive?: boolean`）；
  - `normalizeForCompare` 使用 `/[\s\u3000]+/g` 处理半角与全角连续空白；
  - `findDuplicateByContent` 增加 `options?.excludeId && entry.id === options.excludeId` 过滤自身，并在默认模式下对目标与已有条目执行 `toLowerCase()` 小写归一化比对。
- `src/ui/capture.ts`：
  - `CaptureDeps.findDuplicate` 接口扩展可选 `options?: {excludeId?: string}` 参数。
- `src/index.ts`：
  - `CaptureDialog` 依赖装配中的 `findDuplicate` 将 options 透传给 `findDuplicateByContent`。
- `tests/r14-dedupe-agent.test.cjs`：
  - 新增 `去重增强：excludeId 排除自身避免编辑自撞、全角空白归一化与大小写模式` 专项测试用例，覆盖自身排除、多条同文命中、全角空格匹配及大小写模式对照。
