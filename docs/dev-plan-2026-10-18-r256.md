# T-0109 / R256：预览窗格嵌套片段语法回显与可视化

日期：2026-10-19

## 目标

闭环 F5 片段嵌套（S4）在桌面与移动端主搜索面板右栏预览窗格（`paintPaneVars`）上的语法回显与可视化展示：
1. 此前预览面板仅解析并展示 `{{xlc:ask:…}}` 字段芯片与 `{{xlc:cursor}}` 光标标记，条目正文若引用了子片段（`{{xlc:snippet:标题}}`）在右栏元数据行完全隐蔽；
2. 接入 T-0106 封装的 `listSnippetRefs` 纯函数，自动提取非代码正文中的嵌套片段标题；
3. 在 `.xlc-pane-vars` 中展示 `paneSnippetsLabel`（`嵌套 %s 个片段：`）并为每个片段标题生成带有稳定标识 `data-xlc-control="preview.snippet-tag"` 的代码芯片；
4. 增补中英国际化资源并在 harness 中对齐；
5. 保证纯文本安全：所有标题芯片一律走 `textContent`，绝不注入 HTML。

## 实现

- `src/i18n/zh-CN.json` & `src/i18n/en.json`：
  - 增补中英对称键：`"paneSnippetsLabel": "嵌套 %s 个片段："` / `"paneSnippetsLabel": "Includes %s snippets:"`。
- `scripts/harness/entry.ts`：
  - 同步更新本地化字典 `paneSnippetsLabel`，并在首个示例正文中增加片段嵌套引用 `\n\n{{xlc:snippet:联系方式}}`。
- `src/ui/dialog.ts`：
  - 从 `../model/variables` 导入 `listSnippetRefs`；
  - `paintPaneVars` 接入片段引用提取与标签/代码芯片渲染，保持与变量芯片、光标提示的优雅隔点 ` · ` 分隔。
- `scripts/render-production.cjs`：
  - 在 `desktop-light` 冒烟断言中增加 `paneVarsSnippet` 与 `paneSnippetTag` 两项断言（断言数由 18 增至 20）。
