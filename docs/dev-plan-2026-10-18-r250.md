# T-0103 / R250：Espanso 导入类型推断与元数据字段对齐

日期：2026-10-19

## 目标

对齐数据模型（`src/model/item.ts`）与竞品迁移差距（G2）：
1. 解决 `src/service/espanso-import.ts` 中条目类型被无差别硬编码为 `"text"` 的问题；
2. 为外部导入正文增加自动类型推断：
   - 匹配完整代码围栏（` ``` ` 或 `~~~`）时，自动标记为 `itemType: "code"`，使导入的代码片段能够展示语言徽标并走代码专属的复制/插入通道；
   - 匹配单行安全 HTTP/HTTPS 链接时，自动标记为 `itemType: "url"` 并同步提取填充 `url` 属性，使网址快捷短语在动作菜单中直接获得“打开外链”能力；
   - 匹配包含 Markdown 格式字符的单行时标记为 `itemType: "markdown"`；其余安全回退为 `itemType: "text"`。

## 实现

- `src/service/espanso-import.ts`：
  - 导入 `isSafeHttpUrl` 与 `ItemType`；
  - 移除硬编码 `itemType: "text"` 与空 `url: ""`；
  - 接入正则与安全校验对 `kramdown.trim()` 进行类型推断与 URL 字段提取。
- `tests/r164-espanso-import.test.cjs`：
  - 新增 `类型推断与元数据对齐：code 围栏、安全 URL、markdown 与纯文本` 测试用例，覆盖代码围栏、安全链接、粗体/链接 Markdown 及纯文本的导入断言。
