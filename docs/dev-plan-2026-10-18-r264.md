# T-0117 / R264：搜索多关键词多维标点分词容错与高亮区间对齐

日期：2026-10-19

## 目标

为满足用户在桌面端与移动端即时搜索中的自然输入习惯，消除由于输入全角标点、分隔符号导致的搜索中断问题：
1. 解决用户在快速筛选多关键词时，习惯性输入中文逗号 `，`、顿号 `、`、加号 `+`、斜杠 `/`、反斜杠 `\`、分号 `;` 或竖线 `|` 作为连接符，此前仅支持 `\s+` 导致整串作为单一关键词无法命中条目的问题；
2. 导出 `SEARCH_TOKEN_DELIMITER = /[\s,，/\\+;；|｜]+/` 并封装统一纯函数 `splitSearchTokens(query: string): string[]`；
3. `src/model/search.ts` 的 `matchEntry` 接入 `splitSearchTokens`，确保各标点切分出的子 token 均参与跨字段累积分数与严格 AND 语义校验；
4. `src/ui/dialog.ts` 的 `appendHighlighted` 同步接入 `splitSearchTokens`，保证命中高亮区间与检索切词完全一致，文本一律走 `textContent` / `createTextNode`，绝不注入外部 HTML。

## 实现

- `src/model/search.ts`：
  - 导出 `SEARCH_TOKEN_DELIMITER` 与 `splitSearchTokens`；
  - `matchEntry` 使用 `splitSearchTokens` 替代原有 `trimmed.split(/\s+/)`。
- `src/ui/dialog.ts`：
  - `appendHighlighted` 使用 `splitSearchTokens` 提取检索关键词。
- `tests/r210-multi-keyword-search.test.cjs`：
  - 新增 `多关键词多维标点切分与 AND 检索：支持逗号、分号、加号、斜杠与竖线` 专项测试用例，覆盖逗号、加号、斜杠、分号、竖线及未满足阻断逻辑。
