# T-0116 / R263：cleanTagList 标签分隔符修正与多维标点及井号清洗

日期：2026-10-19

## 目标

彻底修正 `src/model/item.ts` 中 `cleanTagList` 的历史正则书写缺陷，对齐思源原生标签输入与中文多维标点习惯：
1. 修正历史遗留的 `v.split(/[,,、]/)` 笔误（误连写两遍 ASCII 半角逗号，导致中文全角逗号 `，` 丢失，用户输入 `工作，客服，模板` 被当作单一标签）；
2. 升级分隔符正则为 `/[,，、;；\s]+/`，无缝支持：
   - 半角与全角逗号（`,` 与 `，`）
   - 中文顿号（`、`）
   - 半角与全角分号（`;` 与 `；`）
   - 空格、制表符及连续混合空白（`\s+`）
3. 原生标签井号清洗：针对思源用户常带的 `#` 前缀与后缀（如 `#工作#`、`#客服`），通过 `.replace(/^#+/, "").replace(/#+$/, "")` 自动清洗为纯粹标签名；
4. 保持边界健壮性：去首尾空白、空值过滤、去重与单条目 32 个标签上限截断。

## 实现

- `src/model/item.ts`：
  - `cleanTagList` 将切分正则升级为 `/[,，、;；\s]+/`；
  - 增加对 `#` 标记的前后清洗并取前 `LIMITS.tag` 字符。
- `tests/item-model.test.cjs`：
  - 新增 `cleanTagList：中英文逗号、顿号、分号、空格分割与 # 前缀清洗` 专项测试用例，覆盖全角逗号、顿号与分号、连续空白字符、井号清洗及混合多维标点断言。
