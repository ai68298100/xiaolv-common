# 当期账本（2026-10-20 · T-0132 / R279）

## 一、当前任务

- **任务编号**：T-0132
- **版本轮次**：R279
- **功能方向**：条目空格键极速大卡片预览浮层 (Space Quick Look) (G21)
- **决策文档**：`docs/adr/0073-space-quick-look-preview.md`

## 二、目标与拆解

1. **键盘事件与输入状态隔离 (`src/ui/dialog.ts` `onKeydown`)**：
   - 仅当焦点不处于搜索输入框（`this.input` 非 `document.activeElement`）且当前有选中条目时，按 `Space` 唤起极速预览；
   - 搜索框打字输入空格严格保留原行为不拦截；
   - 浮层打开时 `Space` / `Esc` 关闭，`Alt+C`/`Ctrl+C` 复制；
   - 无待预览条目或无活动条目时不弹空壳。
2. **轻量全屏预览浮层 (`openQuickLookOverlay` / `closeQuickLookOverlay`)**：
   - 在对话框根元素内插入 `.xlc-quicklook` 遮罩层，`role="dialog"` / `aria-modal="true"` / `aria-label`；
   - 复用 `renderSafePreview` 渲染富文本，承载在 `.xlc-quicklook-body`；
   - 顶部展示条目标题、类型、快捷键提示键帽；
   - 关闭时完全移除节点并把焦点归还给快捷键前的活动元素。
3. **样式 (`src/styles/*.scss`)**：
   - 居中卡片最大宽 720px、最大高 80vh，圆角与阴影，背景遮罩半透明；
   - 极窄视口自适应（宽度 92vw、高度 85vh）；
   - 尊重 `prefers-reduced-motion` 与 `forced-colors`。
4. **交互审计与负向验证**：
   - `scripts/ui-interaction-audit.cjs` 增补用例：非输入态 `Space` 打开浮层、`Esc` 关闭、输入框内输入空格不触发浮层；
   - 注入违规（禁用空格分支）确认新用例失败，恢复后 74+ 用例全通。
