# T-0096 / R243：Issue #1 设置 UI 接线与离线回执

日期：2026-10-18

## 目标

把 R242 的独立笔记本创建契约接入首次运行设置，确保用户能明确选择“新建独立笔记本与库文档”，并在两步创建失败时保留输入和可审计错误。

## 实现

- 设置模式新增 `new-notebook`，独立笔记本名称与库文档名称分开填写；普通“新建专用库文档”流程保持原有默认推荐。
- 独立模式调用 `createIndependentLibrary`，成功后仅在笔记本与库文档都成功时写入配置，并记录 `createdNotebookIds`。
- 创建期间锁定相关字段防止重复提交；失败时保留表单、显示可换行错误状态，不写入半成品配置。
- 中英文文案、生产 harness mock、首跑成功/失败 smoke 断言和状态样式同步。
