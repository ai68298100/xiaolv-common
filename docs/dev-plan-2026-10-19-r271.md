# T-0124 / R271：批量导入 CSV/TSV 字段映射向导 (G13)

日期：2026-10-19

## 目标

对标 Raycast / Airtable 表格导入体验（G13），在 R267 通用 CSV/TSV 导入基础上增加交互式字段映射向导：
1. 粘贴表格文本后自动检测列数并展示「标题/正文/分类/标签/别名/链接」映射下拉框；
2. 支持一键「智能推断」（基于表头关键词匹配）；
3. 实时预览前 5 行解析结果，确认后再进入导入策略对话框；
4. 扩展 `parseCsvTsvItems` API 支持自定义列覆盖。

## 实现

- `src/ui/csv-tsv-wizard.ts`（新增）：
  - 交互式字段映射向导对话框，包含文本输入区、动态生成列映射下拉框、智能推断按钮、实时预览区；
  - 状态管理：`state.mapping` 记录各列索引，`parsedItems` 存储预览结果；
  - 集成 `inferColumnMapping` 与 `parseCsvTsvItems`，支持自定义列覆盖。
- `src/service/csv-tsv-import.ts`（修改）：
  - `parseCsvTsvItems` 增补 `customMapping` 参数，允许显式指定各列索引与 `hasHeaderRow` 模式；
  - 增强 `inferColumnMapping` 的表头判定逻辑，避免长句误判为表头。
- `src/i18n/zh-CN.json` 与 `src/i18n/en.json`：
  - 增补多语言资源：`fieldMapping`, `autoInfer`, `noData`, `fieldTitle`, `fieldContent`, `fieldCategory`, `fieldTags`, `fieldAlias`, `fieldUrl`。
- `tests/entry.ts`：
  - 导出 `csvTsvImport` 模块供测试套件统一引用。
- `tests/r271-csv-wizard.test.cjs`（新增 3 项专项用例）：
  - 自定义列映射覆盖；
  - tagsIndex 与 aliasIndex 自定义覆盖；
  - urlIndex 自定义映射。
