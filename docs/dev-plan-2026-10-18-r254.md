# T-0107 / R254：S1 变量填充卡默认值与预填支持

日期：2026-10-19

## 目标

补齐竞品差距分析（S1 / 对标 TextExpander / Espanso Forms）中的变量默认值与输入框预填能力：
1. 解决此前单选项文本（例如 `{{xlc:ask:数量|1}}`）被丢弃，以及等号默认值语法（例如 `{{xlc:ask:币种=CNY}}`）无法识别的问题；
2. 扩展 `AskField` 模型，新增 `defaultValue?: string` 属性；
3. `parseAskField` 提取等号默认值（`name=defaultValue`）与单选项回退默认值，同时保持 `date` 与 `textarea` 单选类型的特异解析；
4. `expandAsks` 展开增强：用户未提供填充值时优先采用清洗后的 `defaultValue`，无默认值才兜底 `__名称__`；
5. `variable-form.ts` 渲染增强：输入框自动预填 `field.defaultValue`，用户若无需修改可直接回车插入，极大提升模板填充效率。

## 实现

- `src/model/variables.ts`：
  - `AskField` 接口扩展可选 `defaultValue?: string` 属性；
  - `parseAskField` 拆分等号前后的 `name` 与 `defaultValue`；对单选项且非保留关键字（非 `date`/`textarea`）的纯文本选项回退为 `defaultValue`；
  - `askFieldTag` 回显支持等号默认值；
  - `expandAsks` 在 `filled` 为空且存在 `defaultValue` 时返回 `cleanFillValue(field.defaultValue)`。
- `src/ui/variable-form.ts`：
  - 在渲染字段 `input` / `textarea` 时若存在 `field.defaultValue`，自动预填 `input.value = field.defaultValue`。
- `tests/r67-variables.test.cjs`：
  - 新增 `ask 默认值与语法回显：等号语法、单选项回退默认值与默认值优先展开` 测试用例，覆盖等号语法解析、单选项默认值回退、date/textarea 等号默认值结合、下拉选项默认值、未填充时默认值展开与显式覆盖断言。
