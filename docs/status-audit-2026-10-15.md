# 插件现状审计与下一步计划（2026-10-15；最终门禁复验 2026-10-16）

## 当前结论

已发布版本仍是 v0.4.1。插件核心链路、内容库、搜索调用、变量、导入导出、provider 协议、发现、AI 边界与主要桌面交互均已实现；工作区中另有未发布的 T-0073/R220 搜索空态范围回退，以及已完成本地验证的 T-0076/R223 零搬运标签发现与引用入口。当前改动和本机 `dist/package.zip` 尚未提交或发布，包内版本仍为 0.4.1，因此不能把这个构建当成新版本发行包。

代码结构边界清晰：`src/index.ts` 管宿主生命周期与装配，`src/kernel/` 封装官方 API，`src/model/` 放纯数据和搜索逻辑，`src/service/` 管内容库、AI、发现、provider 与协议桥，`src/ui/` 负责各弹窗。思源块仍是正文与元数据真源；插件侧车存收藏、最近、频次、界面偏好和保存视图规则，不存源块正文。实现不依赖 SQL 或兄弟插件私有接口。

- **检索与调用**：关键词/多关键词、拼音与高频多音词、分类和标签筛选、收藏/最近/频次排序、变量填充、结构化内容分派、键盘工作流、标签直选和最近查询历史已实现。
- **捕获与生态**：选区/块/文档/剪贴板、拖拽与粘贴草稿、场景模板包和 `xiaolv-common/v1` provider 注册已实现。第三方 provider 的实际接入依赖其他插件，不能越界改兄弟插件生产代码。
- **AI**：接线、权限开关、元数据/正文边界、失败恢复和自动化覆盖已完成；真实思源模型端到端尚未验证。
- **性能**：设置、首跑和 Espanso 路径懒加载及超过 80 条时的固定行高窗口已实施。现有规模基线为最多 100 条搜索结果；Chromium 数据可用于回归，不能替代 Electron 首屏、滚动帧率或 Android 数据。
- **本轮在途功能**：T-0073/R220 已完成本地实现与验证：收藏/最近范围无结果时，一键扩大到全库并保留查询和焦点，同时把新建作为次级路径。详情与证据见 [ADR 0046](adr/0046-smart-empty-state-and-scope-fallback-contract.md) 和当期账本。
- **T-0076/R223**：已实现有界原生标签 + `custom-xlc-tags` 发现、当前筛选全选、默认引用收录、快照收录选项、引用源块实时读取及独立的源正文插入动作。引用条目只保存块引用 marker 和来源元数据；编辑、导出和撤销仍读取库内 marker。隔离发现 E2E 已覆盖标签合并、引用 marker、源块更新后的实时摘要/正文和撤销保留源块；该批改动尚未发布，Electron 动作证据由 T-0077 补齐，Android 仍未现场验收。
- **T-0078/R225**：已完成标签智能集合第二阶段。发现面板可保存当前精确标签视图；设置页列出名称、标签、范围和路径，可重新打开或删除快捷配置。文档/笔记本/文档树视图重开后自动预填标签、扫描完成自动选择确定可新增候选，并锁定引用入口模式；侧车只存规则，不存正文。指定笔记本/全部笔记本视图模型保留，但当前不允许保存或重开，避免伪造缺失目标与确认状态。

## 新增产品调研结论

T-0075/R222 补查了常用语产品的真实组织模型。主流 GUI 多采用“独立条目 + 搜索/标签/主题组”，配置型工具才更常见多文件拆分；Obsidian Core Templates 是文件夹中的 Markdown 模板，插入时展开文本，不能作为双链复用证据。PhraseExpress 是最贴近当前问题的先例：同一 phrase/folder 可用链接出现在多个文件夹或 phrase files 中，正文只保存一份；massCode 则提供独立 snippet、嵌套文件夹、跨文件夹多标签和导入前预览。

后续产品路线已按两层落地：用户在明确范围内用指定标签视图发现原块，再用只保存来源块 ID 与元数据的引用入口形成长期精选和跨集合排序。隔离内核已验证标签 API 形状；真实 Electron/Android 的源块实时读取、桌面插入和触控仍待现场证据，详见 [ADR 0048](adr/0048-reference-collections-without-moving-source-blocks.md)。
