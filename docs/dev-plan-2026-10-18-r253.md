# T-0106 / R253：F5 片段引用解析与语法诊断工具健全化

日期：2026-10-19

## 目标

补齐片段嵌套系统（F5 / S4）在模型层的解析与完整性诊断纯函数能力：
1. 解决此前仅有正则 `SNIPPET_PATTERN` 缺少统一列表提取纯函数的问题；
2. 导出 `listSnippetRefs(text: string): string[]`，去重、去首尾空白、限长截断并保留首次出现顺序，最多提取 16 个；
3. 导出 `diagnoseSnippetRefs(text: string, availableTitles?: ReadonlySet<string> | ReadonlyMap<string, unknown> | readonly string[]): SnippetRefDiagnosis`，分析是否存在片段引用、输出引用清单与当前库中缺失的目标片段标题，为编辑/模板诊断与后续界面提示提供坚实纯函数基座。

## 实现

- `src/model/variables.ts`：
  - 导出 `SnippetRefDiagnosis` 接口（`referencedTitles: string[]; missingTitles: string[]; hasSnippets: boolean`）；
  - 实现并导出 `listSnippetRefs`：快速检查 `{{xlc:snippet:`，提取匹配并限长 16 个；
  - 实现并导出 `diagnoseSnippetRefs`：兼容 Set、Map 和数组形式的可用标题集合，准确核对并输出 `missingTitles`。
- `tests/r72-snippet.test.cjs`：
  - 新增 `纯函数诊断：listSnippetRefs 去重解析与 diagnoseSnippetRefs 缺失判定` 测试用例，覆盖空内容、无引用普通文本、多重重复引用去重、缺失片段判定及全存在空缺失断言。
