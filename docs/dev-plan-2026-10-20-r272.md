# T-0125 / R272：性能优化与资源减负 (G15)

日期：2026-10-20

## 目标

对标 Raycast / Alfred 插件性能标准（G15），为小驴常用提供统一的性能优化工具集，确保高频触发事件有规范的防抖/节流机制：
1. 提供 `debounce`、`throttle`、`rafThrottle` 工具函数；
2. 提供 `cleanupOnDestroy` 包装器确保 DOM 销毁时清理事件监听器；
3. 提供内存泄漏检测工具（调试用）；
4. 零侵入式优化，不影响现有功能。

## 实现

- `src/ui/performance-utils.ts`（新增）：
  - `debounce<T>`：通用防抖工具，返回去抖后的函数；
  - `throttle<T>`：基于时间戳的节流工具；
  - `rafThrottle<T>`：基于 requestAnimationFrame 的节流工具，适合滚动等高频场景；
  - `cleanupOnDestroy(element, cleanupFn)`：自动清理事件监听器的包装器；
  - 内存泄漏检测工具：记录活跃事件监听器数量，导出到全局用于调试。
- **现有代码审查**：
  - 虚拟列表已使用 RAF-based 节流，无需修改；
  - 搜索输入已有 debounce 实现（200ms），无需修改；
  - 所有事件监听器均有对应的 `removeEventListener` 调用，无内存泄漏风险。
