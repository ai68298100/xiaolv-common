# T-0122 / R269：层次化标签与场景嵌套分类导航 (G11) 与级联过滤

日期：2026-10-19

## 目标

为解决多场景大库（>200 条）在分类和标签组织中的层次化深度管理需求（G11）：
1. 支持斜杠 `/` 路径定义的层次化嵌套分类与标签（例如「客服/售后/退换货」与「研发/前端/Vue」）；
2. 消除过去扁平全等匹配导致父级无法命中子级的割裂体验，实现父级自动级联匹配其下所有子级条目；
3. 严格设置层级前缀边界防御（`startsWith(parent + "/")`），严防「客服2」或「商务部」被误判为子级；
4. 构建纯函数层级树解析器，在 UI 筛选下拉框中支持树状缩进与分支指引符展示（`├ 售前`、`└ 售后`），提高视觉可读性。

## 实现

- `src/model/hierarchy.ts`：
  - 导出 `splitHierarchyPath`：斜杠切分与空白过滤；
  - 导出 `isHierarchicalChild`：严格前缀边界判定的父子层级关系算法；
  - 导出 `matchesHierarchicalCategory` 与 `matchesHierarchicalTag`：分类与多标签级联匹配纯函数；
  - 导出 `buildHierarchyTree`：根据路径集合与计数映射构建多叉层级树，递归计算子级汇总计数；
  - 导出 `flattenHierarchyTree`：扁平化为带树状缩进符号的下拉菜单项。
- `src/model/search.ts`：
  - 引入 `matchesHierarchicalCategory` 与 `matchesHierarchicalTag`；
  - `passesFilters` 升级为层级级联过滤，父级分类或标签自动匹配包含子路径的条目。
- `src/ui/dialog.ts`：
  - `renderFilterOptions` 接入 `buildHierarchyTree` 与 `flattenHierarchyTree`，为分类与标签下拉框提供层次化清晰展示，同时保持 `<option value>` 为合法完整路径。
- `tests/entry.ts`：
  - 导出 `hierarchy` 模块供测试套件统一引用。
- `tests/r269-hierarchy.test.cjs`：
  - 编写 4 项专项测试用例，覆盖路径切分、严格前缀边界、树构建与计数、下拉扁平化以及 `passesFilters` 级联实测。
