# T-0112 / R259：占位符日期算术中文自然语言快捷扩展

日期：2026-10-19

## 目标

为动态占位符（`placeholders.ts`）中的日期算术功能增加常用中文自然语言快捷支持（G1 / 对标 Espanso / TextExpander 核心差距的本地化体验升级）：
1. 解决中文用户在编写客服回复、会议通知与日程模板时，不得不记忆 `+1d`、`+2d` 或英文 `next_monday` 的心智负担；
2. 引入相对日快捷映射：`今天` (+0d)、`明天` (+1d)、`后天` (+2d)、`大后天` (+3d)、`昨天` (-1d)、`前天` (-2d)、`大前天` (-3d)；
3. 引入未来最近星期快捷映射：`下周一` ~ `下周日`（同时兼容 `下周天`、`下星期X`、`下礼拜X`），严格取未来最近一天（1~7天后，当天不算）；
4. 保持纯文本安全与原有带参规则一致：带参分隔符保持 `|`（避免碰 Lute emoji 短代码短语），非法参数原样保留不吞内容。

## 实现

- `src/model/placeholders.ts`：
  - 定义只读字典 `ZH_RELATIVE_DAYS` 与 `ZH_NEXT_WEEKDAY`；
  - `resolveDateArg` 优先检查中文自然语言键，命中则按日历计算绝对日期（`YYYY-MM-DD`）返回；
  - 未命中中文快捷时无缝回退至原有的 `[+-]N(d|w|m|y)` 相对偏移与英文 `next_*` 正则。
- `tests/r160-dynamic-placeholders.test.cjs`：
  - 新增 `日期算术：中文自然语言快捷支持（今天/明天/后天/昨天/下周X）` 专项测试用例，覆盖今天/明天/后天/大后天/昨天/前天/大前天、下周一~下周日、下星期/下礼拜同义词及全文模板多占位符替换应用。
