# T-0101 / R248：Issue #1 独立笔记本两步状态指示与补偿凭据展示

日期：2026-10-19

## 目标

落实 Issue #1（新建独立笔记本）在服务层与 UI 层的完整两步状态反馈与补偿失败凭据展示：
1. 服务层支持 `IndependentLibraryOptions.onProgress` 回调，按序通知 `creating-notebook` → `creating-doc`（若失败则通知 `rolling-back`）；
2. UI 层设置向导实时呈现分步文本（第 1/2 步新建笔记本、第 2/2 步新建库文档、回滚清理未完成笔记本）；
3. 当库文档创建失败且笔记本删除补偿也失败时，UI 展示结构化孤儿凭据区 `data-xlc-control="setup.independent.orphan-notebook"`，展示残留 `notebookId` 并提供一键复制按钮 `setup.independent.copy-orphan-id`；
4. 用户重新修改输入或切换模式时自动安全清理旧凭据区。

## 实现

- `src/service/library.ts`：
  - 导出 `IndependentLibraryStep` 与 `IndependentLibraryOptions`；
  - `createIndependentLibrary` 增加 `options.onProgress` 通知点，串行通知两步创建与可能的回滚。
- `src/i18n/zh-CN.json` & `src/i18n/en.json`：
  - 增补中英对称键：`setupIndependentStepNotebook`, `setupIndependentStepDoc`, `setupIndependentStepRollback`, `setupIndependentOrphanWarning`, `setupIndependentCopyOrphanId`, `setupIndependentOrphanCopied`。
- `src/ui/settings-dialog.ts`：
  - 接线 `onProgress` 动态更新 `independentNotebookStatus`；
  - 失败分支捕获 `result.compensation === "failed"` 且含 `result.notebookId` 时，创建 `orphan-notebook` 凭据区并提供复制按钮；
  - 输入事件与模式切换同步触发 `clearOrphanReceipt()`。
- `scripts/harness/entry.ts`：
  - 同步更新 harness 本地化字典与 `createIndependentLibrary` 桩实现。
