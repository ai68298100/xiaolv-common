# T-0120 / R267：通用 CSV/TSV 表格数据批量导入 (G8) 与智能字段映射

日期：2026-10-19

## 目标

为解决企业客户、客服团队、商务销售及知识作者大量将常用语/话术存储于 Excel、飞书表格、Google Sheets、Numbers 或本地 CSV/TSV 文件的迁移门槛，提供生产级通用表格数据批量导入引擎（G8）：
1. 完整支持 RFC 4180 规范解析，覆盖双引号包裹字段、转义双引号（`""` -> `"`）、字段内换行（CRLF/LF）与 UTF-8 BOM（`\uFEFF`）自动清除；
2. 纯函数自动嗅探分隔符（逗号 `,`、制表符 `\t`、分号 `;`），支持用户从 Excel/飞书表格直接复制单元格（TSV 格式）粘贴导入；
3. 智能推断中英文多场景表头（标题/正文/分类/标签/别名/链接/类型），并在无表头时按列位智能降级（1~4+ 列）；
4. 类型自动推断（URL、代码块、Markdown、纯文本），清洗标签多维分隔符与 `#` 井号，并生成稳定确定性逻辑 ID（`xlc-t...`）以无缝融入既有冲突策略（skip/overwrite/rename）；
5. 遵循 B-006 Kramdown 写前保守防御，对多行非代码块正文产生可追溯警示 Issue；
6. 在设置面板提供双入口：文件选择器直接支持 `.csv` / `.tsv` 文件，以及独立「从 CSV / 表格导入」对话框支持直接粘贴文本与实时解析预览。

## 实现

- `src/service/csv-tsv-import.ts`：
  - `sniffDelimiter(rawText)`：多分隔符稳定度加权嗅探；
  - `parseDelimitedTable(rawText, customDelimiter)`：RFC 4180 状态机解析与未闭合双引号容错；
  - `inferColumnMapping(grid)`：中英文常见表头字段自动识别与无表头位置降级推断；
  - `csvTsvLogicalId(title, category, alias, contentPrefix)`：64 位确定性 FNV-1a 逻辑 ID 生成；
  - `parseCsvTsvItems(rawText, customDelimiter, now)`：端到端解析、类型推断、标签清洗、B-006 警示与回执生成。
- `src/ui/settings-dialog.ts`：
  - 动态懒加载 `loadCsvTsvParser`；
  - `settings.data.import` 文件选择器扩展 `fileInput.accept = ".json,application/json,.md,text/markdown,.csv,text/csv,.tsv,text/tab-separated-values"`，增加 `.csv`/`.tsv` 自动解析并触发导入策略；
  - 新增 `settings.data.csvImport` 按钮及 `openCsvTsvImportDialog` 粘贴解析对话框；
  - `openImportPolicyDialog` 扩展接收 `{kind: "csv-tsv"; items: ExportedItem[]}` 来源。
- `src/i18n/zh-CN.json` 与 `src/i18n/en.json`：
  - 增补中英文多语言资源：`csvImportBtn`, `csvImportTitle`, `csvImportHint`, `csvImportPlaceholder`, `csvImportParsed`, `csvImportNone`。
- `tests/entry.ts`：
  - 导出 `csvTsvImport` 模块供测试套件统一引用。
- `tests/r267-csv-tsv-import.test.cjs`：
  - 8 项专项测试用例，覆盖嗅探、RFC 4180、CRLF、转义引号、中英文表头、无表头降级、稳定 ID 与端到端解析。
