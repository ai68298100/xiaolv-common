# T-0102 / R249：B-006 单行结构标记写前防御与代码围栏空白清洗

日期：2026-10-19

## 目标

依据 ADR 0058 与 B-006 约束，强化 `bodyWriteRestriction` 的纯函数安全边界：
1. 拦截单行中的 Markdown 结构块语法（引用块 `> `、无序/有序/任务列表项、表格行 `| `、水平分隔线、思源超级块分界 `{{{` / `}}}` 及块级 IAL 标记 `{: `），防止思源内核在落库时隐式派生多层嵌套容器块（BlockQuote / BlockList / BlockListItem / BlockTable）而导致子块 ID 丢失或属性落点错位；
2. 增强代码围栏首尾空白行清洗能力：将原本仅清理完全空行的逻辑增强为支持包含空格与制表符的纯空白行（`line.trim() === ""`），避免用户复制的代码围栏因首尾空白行而被误拒。

## 实现

- `src/model/kramdown.ts`：
  - 定义 `STRUCTURED_PATTERN = /\{:|[{]{3}|[}]{3}|^ {0,3}(?:`{3,}|~{3,}|>|(?:[-*+]|\d{1,9}[.)])[ \t]|\||(?:[-*_][ \t]*){3,}$)/`；
  - 增强首尾空白行清洗：`while (lines.length > 1 && lines[0]!.trim() === "") lines.shift();` 及 `lines[lines.length - 1]!.trim() === ""`；
  - 在单行判定处拒绝命中 `STRUCTURED_PATTERN` 的文本，返回 `"multi-line or structured body writing is unavailable pending B-006 host verification; use a single line or a complete code fence"`。
- `tests/kramdown-restriction.test.cjs`：
  - 新增独立专项测试套件，全面覆盖普通单行文本、带行内代码/变量占位符文本、带首尾空白行的合法代码围栏，以及引用块、列表项、任务列表、表格行、分割线、超级块分界和超限内容的拦截断言。
