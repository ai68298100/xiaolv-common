# T-0095 / R242：Issue #1 离线内核契约与补偿编排

日期：2026-10-18

## 目标

在不启动新的 Electron/思源宿主实验的前提下，为 Issue #1 建立可审计的“创建独立笔记本 → 创建库文档”离线契约，并覆盖失败补偿、重复点击和畸形回包。

## 实现

- `src/kernel/client.ts` 登记 `createNotebook` / `removeNotebook`，增加严格 notebook ID 与 `null` 回包解析；写端点保持 `maxRetries: 0`。
- `src/service/library.ts` 增加 `createNotebook`、`removeNotebook`、`createIndependentLibrary`，采用服务写锁、幂等回执和文档失败补偿删除；补偿失败回执保留 notebook ID。
- `LibraryConfig` 兼容可选 `createdNotebookIds`，旧配置归一化为空数组。
- `docs/host-contract.md`、ADR 0059、状态审计和路线图同步当前离线已实现、UI/宿主待验收的边界。

- 服务测试覆盖成功、权限/文档失败、补偿成功/失败、重复幂等和非法输入。
- 本轮最终门禁：`pnpm run check`、`pnpm test`（521/521）、`pnpm run build`、`pnpm run test:ui`、`pnpm run test:ix`、`pnpm run scan`、`pnpm run check:package`、`git diff --check`。
