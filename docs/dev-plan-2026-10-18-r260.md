# T-0113 / R260：F5 片段嵌套展开详情与可观测性（expandSnippetRefsDetailed）

日期：2026-10-19

## 目标

对标 TextExpander 嵌套片段（S4）及系统可观测性要求，升级 `LibraryService` 的片段展开能力：
1. 解决此前 `expandSnippetRefs` 仅返回替换后字符串、无法感知实际展开了哪些子片段、是否存在缺失依赖或递归成环等度量信息的问题；
2. 导出 `SnippetExpansionDetail` 接口：
   - `text`: 最终展开后的正文
   - `expandedTitles`: 成功展开的子片段标题清单（去重保序）
   - `missingTitles`: 引用但未找到条目的子片段标题清单（去重保序）
   - `maxDepthReached`: 实际到达的最大嵌套深度（未嵌套为 0，直接引用为 1，逐层递增）
   - `hasCycles`: 是否检测到递归成环（成环时自动熔断并注入可见标记）
   - `exceededMaxDepth`: 是否有超出 maxDepth 的过深嵌套未展开
3. 在 `LibraryService` 中实现 `expandSnippetRefsDetailed`，保持 `expandSnippetRefs` 零改动的完全向前向后兼容性（直接委托调用并返回 `.text`）。

## 实现

- `src/service/library.ts`：
  - 导出 `SnippetExpansionDetail` 接口；
  - 实现 `expandSnippetRefsDetailed(text: string, opts?: {maxDepth?: number}): Promise<SnippetExpansionDetail>`，在递归展开过程中精确定位并收集展开标题、缺失标题、到达的最大深度、成环状态及超深状态；
  - `expandSnippetRefs` 改为单行封装调用 `(await this.expandSnippetRefsDetailed(text, opts)).text`。
- `tests/r72-snippet.test.cjs`：
  - 新增 `expandSnippetRefsDetailed：跟踪展开片段、缺失项、环检测、最大深度与超限状态` 专项测试用例，覆盖正常多层展开、成环检测、缺失项收集与超深截断。
