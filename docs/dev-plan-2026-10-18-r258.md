# T-0111 / R258：模板包导入依赖预检与策略弹窗分级警示

日期：2026-10-19

## 目标

为 F6 模板包导入增加依赖完整性预检机制，并在导入策略确认弹窗中提供分级警示：
1. 当用户导入他人分享的模板包时，若模板中引用了子片段（`{{xlc:snippet:标题}}`）但该子片段并未随包一起附带（且当前包内无同名条目），在导入前提前告知用户该模板可能在展开时落入可见占位符；
2. `parseMarkdownPack` 自动比对包内所有条目引用的片段集合与包内条目自身的标题集合，计算出未随包附带的 `missingSnippets`；
3. `openImportPolicyDialog` 策略确认弹窗在存在缺失依赖时，展示 `packMissingSnippetsBadge`（`data-xlc-control="import.pack.missing-snippets"`）黄色警告徽标与 `packMissingSnippetsHint`（`data-xlc-control="import.pack.missing-hint"`）行内警示文本，列出具体缺失的片段标题；
4. 保持自包含包（自闭环完整包）的清洁：当包内已包含所有被引用的子片段时，`missingSnippets` 为空/未定义，弹窗不展示多余警告。

## 实现

- `src/service/import-markdown.ts`：
  - 导出 `MarkdownPackManifest` 接口（`name: string; vars: string[]; snippets?: string[]; missingSnippets?: string[]`）；
  - `parseMarkdownPack`：收集条目引用的片段标题与 `pack.snippets`，与包内所有条目标题对比，输出 `missingSnippets`。
- `src/i18n/zh-CN.json` & `src/i18n/en.json`：
  - 增补对称中英文案：`packMissingSnippetsBadge`（`"缺 %s 个子片段"` / `"%s missing snippets"`）与 `packMissingSnippetsHint`（`"注意：模板包引用的片段（%s）未随包附带，若当前库中无同名条目将显示占位符。"` / `"Note: Referenced snippets (%s) are not included in this pack and will show placeholders if missing from your library."`）。
- `src/ui/settings-dialog.ts`：
  - `openImportPolicyDialog`：当 `parsed.pack?.missingSnippets` 存在且非空时，渲染警告徽标与警示段落。
- `scripts/harness/entry.ts`：
  - 更新 `openImport()` 桩数据，包含 `pack` 与 `missingSnippets: ["联系方式"]`。
- `scripts/render-production.cjs`：
  - 扩展 `import-policy` 冒烟断言至 8 项，验证缺失徽标与警示文本。
- `tests/r13-export-md.test.cjs`：
  - 新增 `missingSnippets` 依赖检测与自闭环自包含包的双向断言。
