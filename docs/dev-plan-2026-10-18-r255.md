# T-0108 / R255：拼音前缀连续音节高亮定位平滑化

日期：2026-10-19

## 目标

解决实时拼音搜索打词过程中高亮闪断（闪烁）的用户体验缺陷：
1. 此前全拼匹配 `findPinyinMatches` 仅支持完整字符累加（`concatPy === token`），当用户正在敲击多音节词的过程中（例如输入 `"yanq"` 期望定位 `"延期"`，或输入 `"kaipi"` 期望定位 `"开票"`），由于末字拼音尚未打完，首字母与严格全拼均无法命中，导致条目虽在搜索列表中，但标题高亮瞬间消失，打完后又重新出现；
2. 升级连续拼音音节匹配算法：支持前面的汉字完整拼音匹配，同时最后一个汉字支持前缀拼音平滑匹配（`token.length >= 2 && item.py.startsWith(remainingToken)`）；
3. 支持单字拼音前缀定位（例如 `"ya"` 定位 `"延"`）；
4. 约束边界：单字母（`token.length === 1`）不触发单字前缀匹配，仅走首字母规则，避免泛滥高亮。

## 实现

- `src/model/pinyin-tiny.ts`：
  - 重构全拼音节匹配循环为 `accumulatedTokenIndex` 累积推进机制；
  - 遇到完整音节消耗（`remainingToken === item.py`）时终止并记录区间；
  - 遇到部分包含（`remainingToken.startsWith(item.py)`）时推进游标并继续向后匹配下一汉字；
  - 遇到末字前缀拼音匹配（`token.length >= 2 && item.py.startsWith(remainingToken)`）时，将整段汉字 `[startItem.index, item.index + 1]` 记录为高亮区间并成功退出。
- `tests/r212-pinyin-highlighting.test.cjs`：
  - 新增 `拼音连续音节前缀平滑匹配（Prefix Syllable Match，消除输入中高亮闪断）` 测试用例，覆盖末字前缀匹配（`"yanq"` 匹配 `"延期"`、`"kaipi"` 匹配 `"开票"`、`"zhongy"` 匹配 `"重要"`）、单字前缀匹配（`"ya"` 匹配 `"延"`）以及单字母规则隔离。
