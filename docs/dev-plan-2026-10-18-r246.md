# T-0099 / R246：异常文本转换共享重构

日期：2026-10-18

## 目标

消除核心服务、内核客户端和 UI 中重复且不安全的异常文本转换，统一任意 thrown value 的可见回执语义，减少维护分叉。

## 实现

- 新增无依赖的 `src/model/errors.ts`，提供 `toErrorMessage`，覆盖 `Error`、字符串、`null`、普通对象、循环对象和 hostile Proxy。
- 接入插件入口、内核客户端、LibraryService、协议服务、Espanso 导入和捕获/搜索/设置 UI，源码中的旧 `(err as Error).message` 与重复三元转换已清零。
- 新增共享函数直接边界测试，并保留 R245 导入回执负向测试。
