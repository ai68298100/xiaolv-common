# 小驴常用 · 设计规范（Design Spec v3.1）

> 版本：2026-10-07 v3.1（原型补入 R73/R74/R84/R90 生产新功能：搜索清空 ×、分类分组、自定义变换、提示词场景包、snippet/clipboard 变量钮）。视觉基准：[prototype.html](prototype.html)（屏 0 规范板 + 8 屏 × 双主题，PNG 同目录）。
> 生产落地：`src/styles/index.scss`（屏 1-8 的生产 DOM/CSS 形态均已接线；真实思源桌面与 Android 行为仍待 B-001/B-002）。
> 原则：与思源 b3 视觉融合为基线，不硬编码主题色；插件样式一律 `xlc-` 前缀隔离；不引入运行时依赖。

## 一、设计原则（按优先级）

1. **调用优先**：一切设计服务于「想到 → 插入」的最短路径。键盘全程可达，Alt+1~9 直达，Esc 永远可退。
2. **真源可见**：条目是活的思源块——来源可回链、失效可见（⚠ 图标 + 预览横幅双位提示），从不静默。
3. **变量是活的**（v3 新增）：内容里的 `{{xlc:…}}` 是一等公民——捕获时可点选插入、列表徽标可见、预览可解释、插入时轻量询问；紫罗兰色系独占，与 AI 蓝区分。
4. **克制用色**：主色只给核心动作（插入/保存/确认）；AI 一级高亮（主色淡彩+虚线描边）；中性色承担 90% 面积；类型徽标是唯一的固定淡彩（两主题通用）。
5. **诚实呈现**：AI 未配置、来源失效、移动端插入待验证、索引截断——一律明示，绝不静默兜底。

## 二、Design Tokens

### 2.1 色彩（语义对齐思源 b3；亮=daylight / 暗=mid-night）

| Token | 亮 | 暗 | 用途 |
| --- | --- | --- | --- |
| `--b3-theme-primary` | #3575f0 | #5a8af2 | 核心动作、选中态、AI 元素 |
| `--b3-theme-primary-light` | #7f9ff5 | #3d4a66 | hover 描边、AI 按钮描边 |
| `--b3-theme-primary-lighter` | #c6d5fa | #2c3a55 | 选中 chip 底 |
| `--b3-theme-background` | #ffffff | #1e1e1f | 弹窗/菜单底、输入聚焦底 |
| `--b3-theme-surface` | #f7f8fa | #26262a | 输入底、搜索框底、设置卡底 |
| `--b3-theme-on-background` | #1f2329 | #dcdcdc | 主文字 |
| `--b3-theme-on-surface` | #7d8085 | #8a8a93 | 次级文字/meta/foot |
| `--b3-border-color` | #e5e7eb | #36363a | 描边/分隔线 |
| `--b3-list-hover` | #eef1f6 | #2c2c31 | hover/选中行底 |

固定淡彩（两主题通用，原型同款）：TXT `#4a8a4a/13%` · MD/AI=主色 9% · URL `#b0680a/13%` · CODE `#8a5ad0/13%` · IMG `#3a9ab5/13%` · FILE `#8a8a93/14%` · REF `#d05a8a/13%` · WARN `#c2503a/12%` · **VAR `#8a5ad0/12%`（v3 新增，与 CODE 同族紫但等宽字体+小写语法呈现）**。收藏星 `#e8a020`。

### 2.2 字号阶梯（禁止任意字号；数字等宽 `tabular-nums`）

16 弹窗标题 → 15 表单标题 → 14 面板标题 → 13.5 预览标题 → 13 行标题/菜单项/输入 → 12.5 按钮/预览正文 → 12 chip/说明 → 11.5 meta/foot → 11 kbd/徽标/分组头。正文行高 1.7-1.75，说明行 1.6。

### 2.3 间距 / 圆角 / 阴影 / 动效

- 间距：4px 栅格（4/8/12/16/20）；弹窗内容边距 14，卡片内边距 12-14，表单卡 18-20。
- 圆角梯度（嵌套外大内小）：4 ordinal → 6 警条/小件 → 8 按钮/输入/搜索 → 10 弹窗主体/行卡 → 12 菜单/表单卡/设置卡 → 16 底部 sheet → 999 chip/徽标/开关。
- 阴影三级（多层低透明，禁纯黑硬阴影）：L1 `0 1px 2px + 0 1px 3px @5%/4%`（卡片/主按钮）；L2 `0 1px 2px + 0 4px 14px`（浮层）；L3 `0 8px 32px + 0 2px 8px @14%/8%`（弹窗/菜单，取 `--b3-dialog-shadow`）。
- 动效：单一缓动 `cubic-bezier(.33,1,.68,1)`；120ms（hover/按压/颜色）/ 160ms（弹层 xlc-pop：translateY(6px)+scale(.98)→none）/ 220ms（大浮层）；只动 transform/opacity/背景色。

### 2.4 图标与符号

文本符号统一集（等宽渲染安全）：＋ 插入 · ⧉ 复制/副本 · ⤓ 插入到文档 · ↗ 打开来源 · ✎ 编辑 · 🗑 删除 · ✦ AI · ⚠ 失效 · ★/☆ 收藏 · ⇅ 排序 · 📌 置顶组头 · ⚙ 设置 · ← 返回。图标列固定 16px 宽做光学对齐（`.xlc-menu-ic`）。

## 三、组件规范

### 3.1 按钮（`.btn` / `.xlc-dialog .b3-button`）
高度 28（min-height），padding 4×12，圆角 8，字号 12.5。五类：默认（描边）/ primary（主色实底+L1 阴影，hover brightness 1.06）/ AI（主色淡彩底+primary-light 描边）/ ghost（无边框透明，hover 显底）/ 文字链（`.xlc-form-ai`，主色 12px）。态：hover 换底、active `scale(.97)`、focus-visible 2px 主色外描边（offset 1）、disabled `opacity .5 + not-allowed`。

### 3.2 chip / 筛选（`.chip`）
胶囊 26 高、12px 字、padding 2×11。选中=primary-lighter 底+主色字+600。AI 横幅 chip 虚线描边。下拉筛选（类型/标签/分类）：`appearance:none` + 自绘 SVG 箭头（中性灰 `#7d8085`），与 chip 同高同字。搜索框有输入时右端出现 18px 圆形清空 ×（R84；hover 反色）。

### 3.3 行（`.xlc-row`）
高 ≥44（桌面）/52（移动），padding 10×12，标题 13/500，meta 11.5 on-surface（使用次数等宽数字，v3）。选中=inset 3px 主色条+hover 底+ordinal 反色。星标：默认 `opacity .45`，行 hover/收藏/选中现身；悬停染金。失效 ⚠ 为 18px 圆片（tooltip 兜底，完整横幅在预览）。

### 3.4 变量元素（v3 新增）
- 徽标（列表）：`{{}} N 变量`，紫罗兰淡彩+等宽 10.5px。
- 预览提示行（`.pane-vars`）：「插入时将询问 N 个变量：」+ 语法 chip，10% 紫底。
- 快捷插入条（捕获表单）：点选即插入文本光标处；字段含 `{{xlc:ask:字段}}`、`{{xlc:ask:字段|A,B}}`、`{{xlc:snippet:标题}}`（F5 片段嵌套）、`{{xlc:cursor}}`、`{{xlc:date}}`、`{{xlc:doc}}`、`{{xlc:clipboard}}`。
- 填充卡片（屏 4）：360px 卡，头部=类型徽标+标题+`Esc 取消`；说明行声明「草稿值不回写库」；字段 label 附等宽语法 tag（下拉字段列出选项）；底部 `Tab 下一项 · Enter 插入` + 取消/插入。自动变量（`{{xlc:doc}}`）禁用态灰显。

### 3.5 表单（`.xlc-form`）
字段=12px 标签（500）+ 输入 13px + 11px 提示。输入框 surface 底、8 圆角、7×10 padding；hover 描边 primary-light，focus 描边主色+底提亮为 background。textarea 行高 1.7 可拖高。双栏行 `.xlc-form-row`（fixed 130px 档位给类型/分类/日期）。

### 3.6 菜单（`.xlc-menu`）
桌面：右下锚定 320px 卡（≤容器宽-32），L3 阴影，12 圆角，max-height 72%，内部滚动且**子项禁 flex 收缩**（防预览盒压瘪——R65 修复的守门断言）。结构：标题行（条目名 · 动作/AI 变换）→ 动作分区 → AI 分区（淡蓝底 `4%`，项主色，内置五种 + 自定义变换 F7 并列）→ 次级分区（删除项固定语义红）→ 预览盒（surface+描边，max-height 150，兜底原文摘要）。项态：hover 换底、禁用 45% 透明 + not-allowed（AI 变换结果未就绪时插/复制/存为禁用）。移动端：底部整宽 sheet 形态（16 圆角顶 + safe-area，项高 44）。

### 3.7 开关 / 设置卡（`.xlc-switch` / `.xlc-card`）
开关 34×20 纯 CSS，knob 16 白圆+阴影，checked 主色底右移 14。设置分区=surface 卡+1px 描边+10 圆角+12×14 padding+L1 阴影；卡标题 12/600/字距 .4 on-surface；行=文字(grow)+开关右贴。

### 3.8 空态 / 回执
空态：44px 虚线圆角图标位（✦ 主色）+ 13px 主文案 + 11.5px 语义找提示（仅 AI 开启时），居中 44px 上边距。回执：全路径 showMessage，含数量等宽数字；错误红色、诚实文案。

## 五、新功能交互规范（绑 ROADMAP R66+）

1. **F1 变量填充**：语法 `{{xlc:ask:名称}}`（文本）、`{{xlc:ask:名称|A,B,C}}`（下拉，↑↓ 选择）、`{{xlc:ask:名称|date}}`（日期）。触发点：搜索 Enter / 点行 / 移动「插入选中」。填写值仅作用于本次插入（草稿不回写）。重复变量同名只问一次。
2. **F2 系统变量**：`{{xlc:cursor}}` 光标落点（宿主不可达时降级为文末并提示）、`{{xlc:doc}}` 当前文档名、`{{xlc:clipboard}}` 剪贴板（权限拒绝→该字段置空+回执说明）。AI 变换时变量原样保留不参与改写。
3. **F3 使用计数**：插入/复制成功 +1；「常用」排序=次数×时间衰减；数据存侧车（可重建、可清空、设置可关）。
4. **F6 模板包**：MD 包头部加 YAML 清单（包名/条目数/变量说明/分类）；导入走既有策略三选；导出可按分类筛选。
