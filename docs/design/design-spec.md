### R227：固定笔记本范围与可取消的关闭确认（2026-10-16）

保存的笔记本视图显示“已保存笔记本”，扫描目标取实际会话记录的笔记本 ID，不依赖入口文档的当前位置。旧视图缺少固定目标时明确提示从原笔记本重新保存；保存失败保留命名表单和输入值。

有可撤销批次时，关闭先打开官方 Dialog，说明关闭只结束撤销入口、已加入内容仍保留；焦点默认落在“返回并保留撤销”。取消/Esc 返回发现页，明确关闭仍须再次检查写入状态。重复/迟到提交不得多次关闭；从另一发现入口发起切换时，成功关闭后继续打开请求的视图，取消则保留当前会话。

### R226：标签视图的宿主表单与筛选布局（2026-10-16）

发现页候选标签计数胶囊放在筛选区独立一行，按可用宽度换行；最多显示 12 个标签，标签区高度上限 96px，超出可滚动。胶囊不绝对定位，不覆盖标签输入、保存视图或全选动作；长标签可换行。

发现工作面采用紧凑间距；控件与回执不压缩，窗口高度不足时可滚动到完整撤销按钮。可达性以按钮在视口内且实际命中为准，不通过强制点击绕过裁剪。

保存视图使用思源官方 `Dialog`，宽度 `min(440px, 92vw)`，沿用表单容器、焦点描边和主次按钮。名称默认取当前标签，空白名称就地报错；Enter 保存，取消/Esc 返回发现页并恢复按钮焦点，中文输入法确认不提交。命名窗不响应遮罩关闭，所有取消路径在关闭动画开始前终止提交；关闭发现页也关闭命名窗。

视图重开后，候选复选框与底部已选计数在同次绘制中保持一致；只自动勾选确定可新增项，重复项仍需明确确认。宿主现场覆盖和限制见 `docs/electron-acceptance-2026-10-16.md`；Android 继续保持尚未验证。
> 原则：与思源 b3 视觉融合为基线，不硬编码主题色；插件样式一律 `xlc-` 前缀隔离；不引入运行时依赖。

R187 新增局部视觉基座见 `src/styles/tokens-r187.scss`：R54 的淡薰衣草画布只作用于插件根和显式标记的 Dialog host；普通工作面使用白色表面和描边建立层级，主动作使用语义 accent，暖色只用于提醒。发现页在窄屏使用根滚动，候选正文保持至少 160px 的可读区域，页脚动作随页面滚动可达。R189 的状态镜像（现位于 prototype 屏 11）展示适用于不同操作的空闲/加载/成功/失败/空结果样例，以及超长文本、来源失效和断点差异；它不声称每项操作都具备五态，状态证据见 `docs/ui-component-catalog.md`。

## 一、设计原则（按优先级）

1. **调用优先**：一切设计服务于「想到 → 使用」的最短路径。桌面键盘全程可达，Alt+1~9 快速插入，Esc 永远可退；移动端未完成真实宿主验收前按复制路径说明。
2. **真源可见**：条目是活的思源块——来源可回链、失效可见（⚠ 图标 + 预览横幅双位提示），从不静默。
3. **变量是活的**（v3 新增）：内容里的 `{{xlc:…}}` 是一等公民——捕获时可点选插入、列表徽标可见、预览可解释、插入时轻量询问；紫罗兰色系独占，与 AI 蓝区分。
4. **克制用色**：主色只给核心动作（插入/保存/确认）；AI 一级高亮（主色淡彩+虚线描边）；中性色承担 90% 面积；类型徽标是唯一的固定淡彩（两主题通用）。
5. **诚实呈现**：AI 未配置、来源失效、移动端插入待验证、索引截断——一律明示，绝不静默兜底。

## 二、Design Tokens

### 2.1 色彩（语义对齐思源 b3；亮=daylight / 暗=mid-night）

| `--xlc-accent-text` | #504abd | #c3beff | 主色浅底上的可读文字 |
| `--xlc-surface` / `--b3-theme-background` | #ffffff | #22222d | 工作面/弹窗内容底 |
| `--xlc-soft` / `--b3-theme-surface` | #f1f1f9 | #2a2936 | 输入、次级表面 |
| `--xlc-canvas` | #f7f7fc | #181820 | 页面画布 |
| `--xlc-ink` / `--b3-theme-on-background` | #2c2b3e | #f0eef8 | 主文字 |
| `--xlc-muted` / `--b3-theme-on-surface` | #6c6a7f | #b2aec4 | 次级文字、meta |
| `--xlc-line` / `--b3-border-color` | #e6e5f0 | #393744 | 描边/分隔线 |
| `--xlc-lavender` | #eeecfb | #343046 | 选中、变量和 AI 淡底 |

| `--xlc-danger` | #a34151 | #ffadb9 | 错误/危险操作 |

类型徽标使用 `--xlc-badge-*` 语义色：文本为绿色、URL 为暖色、图片为青色、文件为中性、代码/引用/变量为薰衣草系；AI 复用主色淡底。暗色主题由对应语义 token 提亮文字并切换淡底。原型屏 0 展示品牌和主表面颜色；`tokens-r187.scss` 是生产 CSS 的精确值来源。

### 2.2 字号阶梯（禁止任意字号；数字等宽 `tabular-nums`）

字号值按用途从局部语义变量读取。`tokens-r187.scss` 定义 15 个字号值，生产 `index.scss` 实际引用其中 12 个，另 3 个用于共享对话框样式；R189 将 148 处字号/行高/字重数值写法改为 token 引用，但唯一字号值数量没有减少，因此这证明了集中修改入口，不等于字体层级已精简。当前字重为 400/500/600/650/700，行高包含 10 个倍率和 10 个像素值。原型板目前展示字号值及典型用途，尚未为每个字号档定义唯一的行高/字重组合；同一字号在不同组件可能使用不同组合。将标量 token 收敛为组件级文字样式，需要先逐规则梳理并做截图回归，本轮不声称这项已完成。

### 2.3 间距 / 圆角 / 阴影 / 动效

- 间距：目标基准为 4px；图标光学对齐和控件内距可使用有明确用途的例外。R189 测得 `padding/margin/gap` 变量覆盖 195/200（97.5%），但仍使用 24 个不同的数值（含负值），其中 9 个落在 4px 网格上；因此“覆盖”已收口，“固定栅格”尚未达成。逐步归并剩余值需要组件级截图对比与断点回归，列为待办，不以 token 命名掩盖偏离。
- 圆角：由 `--xlc-radius-*` 命名。当前常用值包括 1/4/6/7/8/10/12/16/18/22px、圆形和胶囊；实际组件按角色复用，screen 0 展示主要角色而不是每个光学例外。
- 工作面以描边和表面明度分层，卡片与常规按钮不加阴影；浮层按宿主 overlay token 使用阴影。阴影不代替清晰间距和边框。
- 动效：主要缓动 `cubic-bezier(.33,1,.68,1)`；生产时间变量为 120/160/220ms，少量共享控件 140ms（显式记录在 token）；只动 transform/opacity/背景色。尊重 `prefers-reduced-motion`。

### 2.4 图标与符号

文本符号统一集（等宽渲染安全）：＋ 插入 · ⧉ 复制/副本 · ⤓ 插入到文档 · ↗ 打开来源 · ✎ 编辑 · 🗑 删除 · ✦ AI · ⚠ 失效 · ★/☆ 收藏 · ⇅ 排序 · ★ 收藏分组 · ⚙ 设置 · ← 返回。收藏仅在默认排序下作为首组显示，不代表独立的置顶功能。图标列固定 16px 宽做光学对齐（`.xlc-menu-ic`）。

## 三、组件规范

完整实现接口、状态矩阵与页面组件索引见 [`../ui-component-catalog.md`](../ui-component-catalog.md)。本节定义视觉角色；组件清单定义生产 DOM 的用途和可变参数，`prototype.html` 屏 11 是对应五态、鉴权/权限失败和断点的可视化样例。

### 3.1 按钮（`.btn` / `.xlc-dialog .b3-button`）
按钮高度按页面组件设置（通用按钮 28px 起，粗指针下不少于 44px）；圆角/字阶/间距读取 token。变体包括默认、primary、AI、ghost、危险和文字链。hover、active、focus-visible、disabled 有样式；loading 由具体异步按钮改文案或禁用；捕获必填错误使用 `xlc-input--error` 并在输入后清除。

### 3.2 chip / 筛选（`.chip`）
胶囊 26 高、12px 字、padding 2×11。选中=primary-lighter 底+主色字+600。AI 横幅 chip 虚线描边。下拉筛选（类型/标签/分类）：`appearance:none` + 自绘 SVG 箭头（中性灰 `#7d8085`），与 chip 同高同字，默认项显示「类型：全部 / 标签：全部 / 分类：全部」。排序 chip 始终显示「排序：当前方式」，悬停/辅助文本说明当前排序的实际规则。搜索框有输入时右端出现 18px 圆形清空 ×（R84；hover 反色）。

排序与分组需一起解释，不能把筛选范围和排序档位混成两个排序按钮：`★ 只看收藏`、`最近使用`是范围筛选；`⇅ 排序：…`打开四档直选菜单。默认档浏览时按收藏顺序置前，其余依最近使用、更新时间稳定排列；有搜索词时保留收藏优先，非收藏结果按匹配相关度及稳定次序排列。最近使用档浏览时按最近使用时间排序，有搜索词时仍由匹配相关度优先。使用频次档按使用次数优先，同次数按最近使用；标题档只影响无搜索词浏览，搜索结果仍按匹配相关度。当前页面会按分类标题分组（分类名升序、无分类末尾）；默认档将收藏另列首组，其余排序不会将收藏单独置顶。只有多于一个有效分组时才显示分组标题。

桌面快捷键采用“键帽 + 动作”结构，并放在带「操作提示」标题的统一说明条中：`↑ ↓ 选择`、`Enter 插入`、`Ctrl/⌘ + Enter 复制`、`Alt/⌥ + 1-9 快速插入`、`Esc 关闭面板`。快捷键不再只显示不可解释的符号；Windows 统一使用 `Ctrl` 文案，窄屏横向滚动而不挤压搜索框。

### 3.3 行（`.xlc-row`）
高 ≥44（桌面）/52（移动），padding 10×12，标题 13/500，meta 11.5 on-surface（使用次数等宽数字，v3）。选中=inset 3px 主色条+hover 底+ordinal 反色。星标：默认 `opacity .45`，行 hover/收藏/选中现身；悬停染金。失效 ⚠ 为 18px 圆片（tooltip 兜底，完整横幅在预览）。

### 3.4 变量元素（v3 新增）
- 徽标（列表）：`{{}} N 变量`，紫罗兰淡彩+等宽 10.5px。
- 预览提示行（`.pane-vars`）：「插入时将询问 N 个变量：」+ 语法 chip，10% 紫底。
- 快捷插入条（捕获表单）：10 种按钮均有稳定 `capture.variable.*` ID。点选替换当前选区；无选区时插入文本光标处；保留两侧正文，插入后回焦且光标位于语法末尾，并派发 input 以刷新关联校验。语法含 `{{xlc:ask:字段}}`、`{{xlc:ask:字段|选项A,选项B}}`、`{{xlc:ask:字段|textarea}}`（R160 多行）、`{{xlc:snippet:标题}}`（F5 片段嵌套）、`{{xlc:cursor}}`、`{{xlc:date}}`、`{{xlc:date|+3d}}`（R160 日期算术）、`{{xlc:random|选项A,选项B}}`（R160 随机）、`{{xlc:doc}}`、`{{xlc:clipboard}}`。
- 填充卡片（屏 4）：360px 卡，头部=类型徽标+标题+`Esc 取消`；说明行声明「草稿值不回写库」；字段 label 附等宽语法 tag（下拉字段列出选项）；底部 `Tab 下一项 · Enter 插入` + 取消/插入（含 textarea 字段时提示行改为「多行框内 Enter 换行」，R162）；卡体限高 `min(720px, 92vh)` 内部滚动（16 字段上限不撑出视口，R162）。自动变量（`{{xlc:doc}}`）禁用态灰显。

### 3.5 表单（`.xlc-form`）
字段=12px 标签（500）+ 输入 13px + 11px 提示。输入框 surface 底、8 圆角、7×10 padding；hover 描边 primary-light，focus 描边主色+底提亮为 background。textarea 行高 1.7 可拖高。双栏行 `.xlc-form-row`（fixed 130px 档位给类型/分类/日期）。

### 3.6 菜单（`.xlc-menu`）
桌面：右下锚定 320px 卡（≤容器宽-32），L3 阴影，12 圆角，max-height 72%，内部滚动且**子项禁 flex 收缩**（防预览盒压瘪——R65 修复的守门断言）。结构：标题行（条目名 · 动作/AI 变换）→ 动作分区 → AI 分区（淡蓝底 `4%`，项主色，内置五种 + 自定义变换 F7 并列）→ 次级分区（删除项固定语义红）→ 预览盒（surface+描边，max-height 150，兜底原文摘要）。项态：hover 换底、禁用 45% 透明 + not-allowed（AI 变换结果未就绪时插/复制/存为禁用）。移动端：底部整宽 sheet 形态（16 圆角顶 + safe-area，项高 44）。

### 3.7 开关 / 设置卡（`.xlc-switch` / `.xlc-card`）
开关 34×20 纯 CSS，knob 16 白圆+阴影，checked 主色底右移 14。设置分区=background 卡+1px 描边+10 圆角+14×16 padding+低透明阴影；不叠加品牌渐变，获得焦点时仅提升描边和细阴影，不增加高频动画；卡标题 12/600/字距 .4 on-surface；行=文字(grow)+开关右贴。搜索、捕获、首跑和导入页面沿用同样的卡片边界，保持跨页面一致。

### 3.8 空态 / 回执
空态：44px 虚线圆角图标位（✦ 主色）+ 13px 主文案 + 11.5px 语义找提示（仅 AI 开启时），居中 44px 上边距。普通关键词无结果时显示「新建条目」，标题候选来自搜索词；`?` 语义查询不预填标题。筛选无结果显示「清除筛选」与「新建条目」。空结果时预览清空为「选择左侧条目后，这里会显示预览」，不能留存上一条内容。**空库态（R107）**：无查询且全库总量为 0 时，主文案「还没有常用内容」+ 说明保存位置和捕获途径 + 主色「＋ 新建条目」按钮（复用 newItem 依赖）——首跑引导完成后的第一个落点即可行动。普通搜索占位符说明可搜索标题、别名、标签、分类和正文摘要；搜索框下方始终说明 `?` 是 AI 语义搜索前缀。桌面底栏显示全库条目总量（不是当前筛选命中数）；`?` 搜索时改为 AI 推荐数；错误态清空计数，移动端隐藏计数与保存声明。行标题搜索命中片段以主色加粗呈现（`.xlc-hit`，AI 语义找结果不高亮）。回执：全路径 showMessage，含数量等宽数字；错误红色、诚实文案。

### 3.9 预览元数据行 / 排序直选（R108，融合 Raycast Detail.Metadata 与动作可枚举惯例）
- **元数据行**（`.xlc-pane-meta`，窗格标题下、变量提示行上）：类型徽标 + 分类 chip + 标签 chips（最多 3 + 「+N」溢出计数）+ 右对齐更新日期。分类/标签 chip **可点击即筛选**（再点同值清除，与筛选下拉联动同步）；1970 级脏时间戳不显示；提供方行与空态隐藏。灵感来自 Raycast「有详情面板时行保持克制、结构化信息进 Detail.Metadata」——列表行不因此加码。
- **排序直选菜单**：排序 chip 点击弹 220px 紧凑菜单（`.xlc-menu--compact`），4 档可枚举、当前档 ✓ + 加粗（`cycleSort` 循环切换不可见、不可直选，已移除）。同款交互惯例：Raycast 的动作始终可枚举。

## 四、页面规范（原型 v4 屏 → 结构/状态/键盘）

| 屏 | 内容 | 关键状态与规则 |
| --- | --- | --- |

### 4.1 首跑与设置状态（R170）

- 首跑默认选择「新建专用库文档（推荐）」，并保留「现有文档 / 文档树 / 按笔记本」三种模式；各模式只显示对应控件。新建路径在现有笔记本中创建一个库文档。笔记本选择的加载、空列表、失败/重试状态就地显示；创建按钮需有可用笔记本和非空标题，下一步需有有效文档或已加载笔记本。
- 笔记本模式只索引笔记本根目录的一级文档，并将新条目写入其中第一个可用文档；摘要、确认页和错误状态必须说清这一范围。根目录为空时不能完成设置。
- 当前库设置同时显示模式/数量与路径或笔记本名；更改库时预选现有目标，避免将当前配置误认为未选择。
- 常用内容示例通过设置显式导入，全部进入当前库文档，分类存为条目属性；当前包 25 条中 8 条符合单行/完整代码围栏写入边界，其余 17 条逐条显示拒绝原因。首跑不自动创建笔记本或按分类创建多份文档；在库配置支持分类到目标文档路由与部分失败恢复之前，不展示这类承诺。
- 可见交互按「入口 → 前置条件 → 禁用/加载态 → 成功或失败回执 → 空态恢复入口」成对校对；异步失败不可静默吞掉。

### 4.3 R188 异步和边界状态

- 每个数据操作按其真实状态机展示适用状态；原型屏 11 是对照样例，不表示每个操作都需五种状态或生产页同时出现五态。空态需要说明原因/范围并给出适用的恢复入口。
- 当前已知的辅助技术反馈有明确作用域：搜索列表 busy、搜索状态行/计数 live、发现根 busy/状态/回执 live、发现分页页码使用 polite live status、发现空态仍保留在 role=list/listitem 结果结构、首设选择器 busy。其他区域不因清单描述而自动获得这些语义。失败原因在实际操作回执中显示；文档树/笔记本目标读取明确提供重试。成功后的列表刷新以实际数据操作为准。
- 保存、导入、收录等写操作按具体入口锁定重复提交；当前没有通用乐观更新回滚框架。删除/覆盖和带可撤销收录批次的关闭有确认；发现收录成功后提供条件撤销回执。不要将此局部能力推断成所有破坏性动作均可恢复。
- 超长标题在列表中可视觉省略，文本节点未被截断；正文、路径和特殊字符按页面样式换行或在局部滚动容器中查看。来源失效条目保持可见并显示告警。
- 桌面宽度保持双栏搜索/预览；≤620px 搜索列表退化为单列，移动表面使用底部 sheet、安全区和触控尺寸；发现页在 ≤620px 或低高度时由根容器滚动，预览和页脚保持可达。减少动效尊重 `prefers-reduced-motion`。

### 4.2 R173-R174 主页面信息层级

- 搜索框占位符说明可搜索字段；下方轻提示说明 `?` 仅是 AI 语义搜索前缀。普通搜索和语义搜索的作用不混在同一句占位符里。
- 每个快捷键都同时呈现按键和动作，避免用户需要猜测「直达」「复制」的对象；Windows 使用 `Ctrl`，Apple 使用 `⌘/⌥`。
- 筛选下拉默认项显示「类型：全部 / 标签：全部 / 分类：全部」，排序入口显示「排序：当前方式」，并用 title/辅助标签解释当前规则。
- 空库态说清“还没有内容、可以怎么添加、会保存到哪里”；无结果预览说清“先选择左侧条目”。普通搜索无结果时按钮直接显示「新建「搜索词」」，避免用户猜测新建对象；底部真源声明改为面向用户的保存位置和失效反馈说明。
- 底栏计数明确是库内总条目数，不随筛选变化；语义查询显示 AI 推荐数。搜索错误时隐藏数量，避免误读为内容为空。移动端不显示桌面计数和保存声明；点按条目只选择并更新预览。无定向目标时底部主按钮执行复制降级并显示待验证回执，有定向目标时执行插入；长按仍可打开动作菜单，真实思源设备行为尚未验证。
- 收藏是范围筛选和默认排序的优先显示规则，不是一个全局“置顶”档。除默认排序外不出现单独收藏分组；最近使用/使用频次/标题档的搜索行为分别按排序说明与匹配度规则处理。

## 五、新功能交互规范（绑 ROADMAP R66+）

1. **F1 变量填充**：语法 `{{xlc:ask:名称}}`（文本）、`{{xlc:ask:名称|A,B,C}}`（下拉，↑↓ 选择）、`{{xlc:ask:名称|date}}`（日期）。触发点：搜索 Enter / 桌面点行 / 移动端底部主按钮「插入选中」。填写值仅作用于本次插入（草稿不回写）。重复变量同名只问一次。
2. **F2 系统变量**：`{{xlc:cursor}}` 光标落点（宿主不可达时降级为文末并提示）、`{{xlc:doc}}` 当前文档名、`{{xlc:clipboard}}` 剪贴板（权限拒绝→该字段置空+回执说明）。AI 变换时变量原样保留不参与改写。
3. **F3 使用计数**：插入/复制成功 +1；「使用频次」排序按使用次数降序，同次数按最近使用时间；数据存侧车（可重建、可清空、设置可关）。
4. **F6 模板包**：MD 包头部加 YAML 清单（包名/条目数/变量说明/分类）；导入走既有策略三选；导出可按分类筛选。
