正文预览允许换行或局部滚动；列表标题单行省略。目前没有专用的展开全文控件：{{xlc:ask:客户名称|textarea}} / https://example.com/a?x=1&y=2

来源失效 / 内核请求失败

来源块失效时保留条目并显示告警；鉴权失败与权限不足分别保留搜索上下文、清空过期结果并提供重试。UI 与隔离内核已验证，Electron 真实宿主仍待现场确认。

删除 / 覆盖 / 退出

先确认后执行；可恢复动作提供撤销回执，不可恢复动作明确说明影响范围。

图片 / 附件 · 链接文本

图片和附件在桌面预览、双端动作菜单与使用帮助显示能力说明：预览是 Markdown 原文，复制得到链接文本；查看原文件请用「打开来源」。不支持复制图片位图或文件本体。先将资源添加到思源，再从图片或附件的右键菜单保存。

多块内容 · 待修复 B-006
