## [0.6.0] — 2026-10-21

推出思源全库块级全文检索融合（Zero-SQL）、全局 Headless 纯求值与 Quicker 联动、多源内容库同步比对合并引擎、Bento Grid 现代双色视觉体系与专业级键盘交互。

### 新增与核心能力

- **思源全库块级全文检索（Zero-SQL）**：官方端点 `/api/search/fullTextSearchBlock` 深度接入，恪守零 SQL 红线，支持全库百万级块毫秒级全文召回，自动清洗 `<mark>` 标签与 Kramdown 结构保真。
- **搜索前缀穿透与块类型/路径限定语法**：输入以 `@`、`/` 或 `sy:` 开头瞬间切换全库模式；支持 `type:code` / `type:h` / `type:quote` 等精准限定块类型，支持 `in:路径`、`path:路径` 与 `book:笔记本` 原生穿透。
- **智能推荐别名与首字母加权**：全库块一键收录（`Alt+S`）自动推导拼音缩写（如 `接口方案` -> `jkfa`）或英文各词首字母作为别名；标题全拼与拼音首字母缩写享有专属优先级加权。
- **多词命中二次精细重排 (Secondary Re-ranking)**：基于标题块密集命中、正文密集匹配与结构标签综合打分，大幅提升多关键词全库召回的语义吻合度。
- **Headless 纯求值与别名闪电直达 (`recall` / `resolve`)**：开放 `window.xiaolvCommon` 与思源协议命令 `xiaolv.common.recall` / `resolve`，外部输入别名或拼音缩写一步直接取回已展开变量与宏的最终文本，免切思源窗口。
- **结构化元数据与缺失变量清单 (`missingVariables`)**：回传包含 `hasVariables`、`variables` 与 `missingVariables` 数组，外部 Quicker 动作可精准探测是否需要弹窗收集用户输入。
- **小驴生态零依赖只读协同 (Ecosystem Adapter)**：自动安全探测打卡清单、人脉名片、拾遗剪藏；扩展生态宏 `{{xlc:checkin:today}}`，未安装时安全优雅降级。
- **Bento Grid 双色便当盒数据看板**：设置面板引入芒果日落暖橙（`🔥 累计调用`）与香芋柔紫（`⚡ 效率增益`）双色卡片，数据统计与成就感兼备。
- **分段胶囊沉浸控制器与全表面 Pill 胶囊化**：顶部作用域切换栏重构为沉浸底槽 + 悬浮胶囊控制器（`.xlc-segmented-track`）；列表行徽标与标签全量采用 9999px 胶囊圆角。
- **专业级键盘操作流**：全局支持 `Ctrl+Enter` / `Cmd+Enter` 快速保存与插入；变量填参卡片增加“↺ 恢复默认”与快捷选项点选胶囊行（`.xlc-varform-quick-options`）；列表行增加 2px 焦点指示与序号高光圆环。
- **移动端与自适应强化**：移动端右下角挂载 44px 深色悬浮新建键（FAB）；热门标签与搜索历史支持横向手势平滑滑动防折行顶跳（防 CLS）；录入表单挂载实时字符计数器。
- **多源内容库同步比对与五态合并引擎**：32 位 FNV-1a 哈希与属性归一，精确识别五态分类（`identical`, `added`, `removed`, `modified`, `conflict`）；模态框统计卡片支持点击单选/反选，秒级聚焦隔离冲突项与变动项。
- **富文本任务列表高保真导出**：剪贴板转换与详情预览全面支持 `- [ ]` / `- [x]` 原生复选框与删除线渲染，自动清洗 Kramdown 专属属性标记。
