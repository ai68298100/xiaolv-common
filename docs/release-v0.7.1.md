## [0.7.1] — 2026-10-24

块层级上下文大纲探针与多格式复制增强：块层级大纲路径探针 (Alt+H)、原始 Markdown 快速复制 (Alt+M)、随机数范围宏 (1..100) 与预览所属文档路径直达。

### 新增与核心优化

- **块层级大纲路径探针 (`Alt+H`)**：搜索全域块或常用条目时，按 `Alt+H` 瞬间浮显当前块在笔记体系中的完整层级大纲路径；预览面板元数据行新增 `📄 所属文档` 路径标签，单点直达源文档。
- **原始 Markdown 语法快捷复制 (`Alt+M`)**：按 `Alt+M` 直接将带有原生语法的 Markdown 内容复制到剪贴板，支持窗口固定模式（Alt+P）常驻连续取用。
- **随机选择宏支持整数范围生成 (`{{xlc:random|1..100}}`)**：扩展 `pickRandomOption`，支持 `1..100` 或 `1000..9999` 连续数字区间随机生成，研发测试、工单编号与验证码模板开箱即用。
