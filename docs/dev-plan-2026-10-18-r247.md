# T-0100 / R247：异常处理门禁接入与开发者路径收口

日期：2026-10-18

## 目标

让 R246 的 `toErrorMessage` 重构形成持续有效的工程门禁，避免后续贡献再次引入不安全的 thrown value 属性读取，并让新成员能在常规开发与 CI 中看到同一条检查路径。

## 实现

- 增强 `scripts/check-error-handling.cjs`：覆盖任意变量名、可选链、重复 `Error`/字符串三元转换以及不安全的 `message`/`name` 类型断言；忽略注释，保留源码行号，并支持 `--root` 负向注入。
- 扩展 `tests/check-error-handling.test.cjs` 的负向夹具，确认四类违规都能让门禁失败，且注释中的示例不会误报。
- 将 `pnpm run check:errors` 接入 GitHub Actions gates、README 开发步骤和 `docs/delivery.md` 发布顺序。

## 验证

- `node --test tests/check-error-handling.test.cjs`

- `pnpm run build`
