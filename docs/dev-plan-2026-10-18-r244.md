# T-0097 / R244：本机使用统计摘要

日期：2026-10-18

## 目标

把已有的本机使用计数从“只能清空”提升为可读摘要，让用户能快速判断常用库的实际使用量，同时不读取正文、不新增网络或宿主依赖。

## 实现

- `src/model/storage.ts` 新增 `summarizeUsage`，只聚合合法计数、涉及条目数和最近时间。
- 设置页“变量与插入”区域新增稳定控件 `settings.usage.summary`，显示累计使用次数与涉及条目数；清空统计后立即回到零态。
- 中英文文案、轻量边框样式、harness 翻译和生产 smoke 断言同步。
