## [0.7.2] — 2026-10-24

多格式剪贴板直喷与智能别名推荐：纯文本清洗快捷复制 (Alt+Shift+C)、智能推荐别名胶囊自动生成、多格式剪贴板直喷与 729 项全绿单测保障。

### 新增与核心优化

- **纯文本清洗快捷复制 (`Alt+Shift+C`)**：针对微信、QQ、网页纯文本表单等不支持 Markdown 格式的外部场景，一键剥离所有 Markdown 语法标记（粗体/链接/围栏/IAL 等），直出纯净无杂质的纯文本。
- **新建与编辑表单智能别名推荐**：输入常用语标题时，表单自动推导拼音缩写（如输入“客户满意度调查”自动推导 `khmydde`），在别名输入框下方呈现为轻量胶囊，点击即可一键填入，极大提升别名命名效率。
- **全格式快捷剪贴板闭环**：形成 Alt+C（标准富文本/HTML）、Alt+Shift+C（清洗纯文本）、Alt+M（原始 Markdown 语法）与 Alt+R（思源块引用）的完整复制矩阵。
