## [0.6.2] — 2026-10-22

借鉴 Raycast / TextExpander 优秀实践：支持条件开关段落（toggle/checkbox）、复制模板原文操作、全仓多语言与 XSS/IME 选词防护加固。

### 新增与交互优化

- **条件开关段落支持 (`{{xlc:ask:名称=内容|toggle}}`)**：借鉴 TextExpander 的 Optional Text Block 与 Raycast 模式，支持开关变量类型（`toggle` / `checkbox` / `switch` / `开关`）。开启时渲染内容，关闭时安全剔除该段落，并在填参卡片呈现直观滑动开关。
- **动作菜单新增「复制模板原文」**：含有动态变量的条目在动作菜单新增 `📄 复制模板原文（不展开变量）`，方便用户跨文档分享、备份或复用原始模板语法。
- **全仓双语 i18n 完整性与 XSS 安全防御全面加固**：自动化遍历扫描全仓 `t()` 键名，补齐占位符双语词条；重构设置面板 Bento 数据卡片为纯 DOM 原生节点，杜绝任何外部输入注入风险。
- **中文输入法（IME）选词全链路防误触**：在就地修改、文档选择与发现对话框全面拦截 `isComposing` 与 `keyCode === 229`，彻底杜绝打汉字选词时的误触提交。

### 验证与已知边界

- 全套质量门禁：单元测试 722/722 全绿通过、TypeScript 类型检查 0 错误、错误处理静态扫描、密钥安全扫描、安装包根相对结构校验（13 项必需资源健全）全部通过。
