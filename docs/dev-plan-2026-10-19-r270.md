# T-0123 / R270：全域内容搜索终端 (Omni-Search Terminal · G12) 落地

日期：2026-10-19

## 目标

将小驴常用从单纯的常用语库提升为思源笔记的全局内容启动器与搜索终端（G12，用户提议立项）：
1. 引入「当前打开文档」与「全库笔记」两个搜索范围 chip，与既有「收藏/最近」互斥；
2. 当常用语库无匹配结果时，提供终端级直达按钮，无缝降级至全域内容检索；
3. 全域检索结果就地复用 SearchEntry 模型，支持语法高亮预览、复制、插入与一键收录为常用语；
4. 100% 走官方结构化端点（`getChildBlocks` + `getBlockKramdowns` + `searchDocs`），绝不引入 SQL 依赖。

## 实现

- `src/service/omni-search.ts`（新增）：
  - 纯函数 `scoreAndFilterBlocks`：复用 `splitSearchTokens` 多维标点切词，按「标题命中 20 分 / 摘要 10 分 / 正文 5 分」加权打分，AND 严格语义；
  - `searchCurrentDocumentBlocks`：先 `getChildBlocks` 拉取当前文档顶层块（上限 100），再批量 `getBlockKramdowns` 取正文，最后过滤打分；
  - `searchAllNotesDocuments`：走官方 `searchDocs` 端点取得文档级命中（HPath 与文档 ID 自动解析），结果附带 `当前文档`/`全库笔记` 标签；
  - `OmniSearchService` 服务包装类，统一对外暴露 `searchInCurrentDoc` 与 `searchInAllNotes`。
- `src/model/search.ts`：
  - `SearchQuery.scope` 扩展为 `"all" | "favorites" | "recent" | "current-doc" | "all-notes"`；
  - `SearchEntry` 增补可选 `targetBlockId` 与 `url` 字段，兼容全域结果虚拟 ID。
- `src/ui/empty-state.ts`：
  - `SearchScope` 类型扩展为支持全库范围；
  - 导出 `shouldShowOmniSearchFallback` 判定函数，专为常用库空结果时的终端级扩展引导服务。
- `src/ui/dialog.ts`：
  - `DialogDeps` 增补可选 `searchCurrentDoc` / `searchAllNotes` / `createFromOmni` 服务接口；
  - 顶部筛选行新增 `当前文档` 与 `全库笔记` 两个 chip；
  - 常用库空结果状态下生成「在当前文档中检索「%s」」「在全库笔记中检索「%s」」两个主按钮（自动恢复焦点与查询上下文）；
  - 预览窗格底部新增 `save-omni` 按钮（仅在 omnidoc 范围下可见），将任意笔记块或文档一键收录为常用语；
  - 全域结果仍由 `renderSafePreview` 安全着色引擎渲染（零 XSS 风险）。
- `src/i18n/zh-CN.json` 与 `src/i18n/en.json`：
  - 增补 `searchCurrentDocAction`、`searchAllNotesAction`、`scopeCurrentDoc`、`scopeAllNotes`、`saveToCommon`、`savedToCommon`、`emptyCurrentDoc`、`emptyAllNotes` 等多语言资源。
- `tests/entry.ts`：
  - 导出 `omniSearch` 模块供测试套件统一引用。
- `tests/r270-omni-search.test.cjs`（新增 5 项专项用例）：
  - AND 多关键词命中与权重排序；
  - 空关键词直接返回空数组；
  - 标题命中得分应高于正文命中；
  - AND 严格性（缺一即拒）；
  - 空块内容自动跳过。
