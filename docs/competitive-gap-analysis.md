## 四、明确不做清单（恪守产品定位与核心安全红线）

1. **操作系统全局键盘 Hook 拦截替换**（Espanso 核心形态）：跨进程键盘拦截存在极高杀软误报与用户隐私泄露风险，小驴常用恪守在思源沙箱与面板内运行；
2. **任意系统 Shell / Python 命令静默执行**：严禁未受控执行外部系统命令，防范恶意导入包注入后门；
3. **插件自建第三方云服务同步**：完全信赖思源笔记自身的内核同步与备份体系，绝不将任何明文数据留存在第三方服务器；
4. **伪造宿主行为或私自修改其他插件代码**：联动一律走 `xiaolv-common/v1` 公开协议。
