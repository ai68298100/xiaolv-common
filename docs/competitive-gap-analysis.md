| # | 功能 | 对标 | 实现难度 | 产品影响 | 规划建议 |
|---|---|---|---|---|---|
| G6 | **轻量富文本/语法高亮预览** | Raycast / TextExpander Preview | 中 | 提升代码条目和 Markdown 格式的视觉感知 | 在右侧详情预览窗格，对代码块语言与 Markdown 语法做轻量 CSS 芯片着色（纯只读，防 XSS） |

| G8 | **TextExpander / CSV 通用批量格式导入** | TextExpander / CSV | 低 | 降低传统团队常用语库向思源笔记迁移的门槛 | 增加标准 CSV/TSV 文本导入解析器，按列映射标题、分类与正文 |

## 三、明确不做项（与定位/安全红线冲突）

| # | 功能 | 对标 | 不做原因 |
|---|---|---|---|
| — | 操作系统全局热键自动截断替换（全局 Hook） | Espanso 核心形态 | 跨进程键盘拦截存在极大隐私与杀软误报风险，插件恪守在思源沙箱内运行 |
| — | 任意系统 Shell / Python 命令静默执行 | Espanso Script 扩展 | 插件严禁未授权执行宿主命令，防止恶意模板包注入危险脚本 |
| — | 插件端自建远端云服务同步 | TextExpander Teams | 数据完全交给思源笔记自身的同步体系，插件绝不在第三方服务器留存明文 |
- **最大差距**：日期算术（G1）——Espanso 的杀手级功能之一，客服模板场景极高频，实现成本低
- **通用对齐度**：85%（缺失项集中在日期算术/随机选择/批量操作/富文本预览四个可实现方向）
- **明确不做**：系统级热字符串（定位冲突）、Shell/JS 执行（安全）、团队同步（需后端）
- **与定位一致性**：所有 HIGH/MEDIUM 差距均不触碰 ROADMAP「暂缓与明确不做」清单
