# T-0098 / R245：导入异常回执边界加固

日期：2026-10-18

## 目标

保证导入逐条应用和收尾重建索引在遇到任意 JavaScript thrown value 时仍返回可审计回执，不因假设异常一定是 `Error` 而二次抛错。

## 实现

- `src/service/importer.ts` 增加统一 `safeErrorMessage` 转换：覆盖 `Error`、字符串、`null`、普通对象、循环对象和抛错代理等输入，并提供稳定兜底文本。
- 逐条导入失败行和 `reindexError` 统一使用安全转换，保留真实 action 与已完成的部分写入回执。
- 新增负向回归：注入 `null`、字符串、普通对象三类异常，确认导入仍返回单条失败记录且不丢失整体回执。
