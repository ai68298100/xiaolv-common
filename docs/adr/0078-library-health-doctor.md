# ADR 0078：常用内容库健康度与语法体检中心 (G26) 契约

## 状态

已接受，T-0137 / R284（2026-10-20，对标 PhraseExpress Macro Checker / VSCode Diagnostics 代码与模板健康体检能力，落地 G26）。

## 背景与上下文

小驴常用已具备丰富的变量系统、多层嵌套片段（F5/S4）、日期算术、UUID、文本命名转换、内联算式求值以及正则过滤能力。当用户的常用库积累到数十上百条常用语后：
1. **死循环与缺失引用风险**：条目 A 引用了条目 B，条目 B 又引用了条目 A，形成死循环片段引用；或者被引用的子条目已被改名或删除，导致插入时留下可见降级标记；
2. **占位符语法破损**：由于用户手动编辑或误删标点，正文中可能存在破损未闭合的双花括号（如 `{{xlc:date|+3d`）或非法占位符参数；
3. **URL 失效与结构受限**：链接条目使用了非法非 http(s) 协议，或者内容触发了 B-006 多块写前防御标记；
4. **行业对标**：PhraseExpress 核心内置 Macro Checker，自动排查循环宏与失效变量；VSCode 具备全项目 Diagnostics。

## 决策

1. **纯函数体检诊断引擎 (`diagnoseLibraryHealth`)**：
   - 在 `src/model/health-doctor.ts` 实现安全的纯函数诊断工具；
   - 诊断维度：
     - **死循环引用检测 (Cyclic Snippets)**：基于有向图深度优先搜索（DFS）检测嵌套片段是否存在环路（如 A -> B -> A 或自引用 A -> A）；
     - **缺失片段引用 (Missing Snippets)**：核对 `listSnippetRefs` 提取的所有片段标题是否存在于当前内容库中；
     - **占位符语法异常 (Malformed Placeholders)**：检测破损未闭合的 `{{xlc:` 结构、空字段名 `{{xlc:ask:}}`、非法日期算术或计算式；
     - **受限结构防御检测 (Restricted Kramdown)**：检查是否包含未经允许的复杂嵌套结构标记；
     - **非法协议检测 (Invalid Protocol)**：检查 URL 条目是否包含非 http/https 协议；
2. **诊断结果分级与统计模型 (`HealthDiagnosisResult`)**：
   - 严重度分级：`error`（阻断性错误，如死循环成环、格式损坏）与 `warning`（降级提示，如缺失子片段、空字段兜底）；
   - 诊断回执包含：扫描条目数、健康条目数、异常条目数、问题项明细（条目 ID、标题、行号/位置、问题类型、可读建议说明）；
3. **零副作用与安全红线**：
   - 纯只读静态分析，绝不擅自修改任何思源块与侧车存储；
   - 零 eval，内存受限保护。

## 结果与证据

- 单元测试增设专项诊断套件，覆盖自环/长环引用、缺失片段、损坏占位符、非法 URL 与全健康条目集；
- 严格负向验证与全门禁通过。
