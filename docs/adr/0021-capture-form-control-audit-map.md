# ADR 0021：捕获表单核心控件审计映射

- 状态：接受
- 日期：2026-10-12
- 关联：T-0046 / R193 / ADR 0019

## 背景

捕获表单已有正文非空检查、重复内容确认、保存锁和失败后保留表单，但生产 smoke 只确认字段及布局存在，没有实际触发保存或取消。空正文错误仅以边框和通用通知表达，错误没有关联到字段，也没有可访问的文本说明。

## 决策

1. 按 ADR 0019 为条目类型、正文、标题、别名、标签、分类、保存和取消添加稳定 `data-xlc-control` 标识。
2. 正文必填和 URL 格式错误都定位到正文控件，显示具体本地化原因，以 `aria-invalid` 和 `aria-describedby` 关联；用户输入后清除错误状态。
3. 复用 `test:ui` 生产 DOM smoke，验证空值错误与焦点、错误修正、URL 拒绝、成功保存的实际 payload 和关闭，以及取消关闭但不写入。
4. harness 只记录捕获写入参数用于断言；Chromium smoke 不代表真实思源持久化，真实块写入仍以隔离内核证据和 Electron 现场验收边界为准。
5. 本批只映射核心字段与保存/取消。AI 整理/草稿、建议采纳和变量快捷栏在当时保留为后续逐控件映射，已由 ADR 0022（R194）完成；失败恢复由 ADR 0023（R196）补齐。

## 取舍

- 行内错误与红色边框同时保留，兼顾快速扫视、焦点定位和辅助技术读取；输入即清除，下一次提交再校验修正后的值。
- 现有重复检查、按钮锁、重复确认和写入失败恢复逻辑不改变；本批增加可观察断言，不把现有 harness 的成功桩描述为宿主写入验收。

## 验证

- `pnpm run test:ui` 覆盖控件 ID、空正文校验、URL 校验、输入清错、有效字段 payload、保存关闭及取消无写入。
- 负向注入移除正文 `aria-invalid` 后，capture smoke 按预期失败；恢复源码后完整 UI smoke 通过。
- `pnpm run check`、`pnpm test`（340/340）、build、`test:ui`、`test:ix`（44/44）、隔离内核（12/12）、发现隔离内核（8/8）、密钥扫描、包检查、原型渲染和 `git diff --check` 通过。
- 首次将两个隔离内核任务并发运行，共用临时工作区导致发现扫描计数污染；使用新工作区/端口串行重跑后 8/8 通过。结果已记入当期账本。

## 未决

- 本 ADR 原定的 AI 整理、AI 草稿、全部采纳和变量快捷栏后续审计已在 ADR 0022 完成；失败/重试与关窗隔离已在 ADR 0023 完成。真实模型和 Electron 生命周期仍按 B-001 验收。
- 保存失败、重复内容确认及异步期间宿主关闭路径已有生产逻辑，但本批不新增专项 harness 场景；实际思源 Electron 生命周期仍按 B-001 验收。
