# ADR 0085：多源内容库同步比对与冲突合并策略引擎 (Sync Diff & Merge Engine · G33)

## 状态
已接受，T-0145 / R292（2026-10-21）。

## 背景与上下文
在跨设备协作、模板包升级、外部内容库导入以及多文档库同步场景中，两端条目可能同时发生增删改，若采用无脑全量覆盖或盲目跳过，会导致用户本地修改被意外冲掉或远端更新无法合入。为了保证用户资产绝对安全，需要建立确定性、可预测、支持人工审阅与智能合并的差异比对引擎：
1. 精确计算条目指纹（32 位 FNV-1a 哈希），支持属性乱序归一；
2. 识别五种差异状态：完全一致 (`identical`)、远端新增 (`added`)、本地独有 (`removed`)、单向变动 (`modified`)、两端冲突 (`conflict`)；
3. 支持五种清晰合并策略：
   - 智能合并 (`smart-merge`)：标签并集、分类继承、正文最新优先；
   - 最新优先 (`latest-wins`)：依据更新时间决胜；
   - 两者并存 (`keep-both`)：远端冲突项分叉 (fork) 生成新条目；
   - 远端为准 (`keep-remote`)：以远端版本覆盖本地；
   - 本地为准 (`keep-local`)：保留本地版本，忽略远端变更；
4. 提供开箱即用的可视化比对模态框，让用户在按下合入前清晰确认每项操作。

## 决策
1. **纯函数与零外部依赖（Zero-side-effect Core）**：
   - 在 `src/model/sync-diff.ts` 实现全部差异比对、计划生成与合并运算纯逻辑，不持有任何网络或 DOM 状态；
   - 严格遵循 `LIMITS` 约束，对恶意循环与超限字段提供兜底防御。
2. **可视化模态框交互契约（DOM & Headless 双态）**：
   - 在 `src/ui/sync-diff-modal.ts` 实现 `openSyncDiffModal`，支持在真实桌面端渲染与 Node/Headless 测试环境下的交互流转；
   - 包含统计摘要卡、策略切换下拉、镜像删除开关、差异明细表与实时计划提示。
3. **数据真源与可审计性**：
   - 合并运算输出结构化回执 `SyncReceipt`，清晰记录每项的 `action`（noop, create, update, fork, delete）与最终条目形态；
   - 不修改底层未受控数据，保持幂等性。

## 结果与证据
- 单元测试增至 693 项，`tests/r292-sync-diff.test.cjs` 包含 7 项核心契约用例，全绿通过；
- 验证涵盖哈希防碰撞、字段变动侦测、五态分类、五种合并策略推导、智能标签合并与 UI Mock 交互。
