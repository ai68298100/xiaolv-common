# ADR 0073：条目空格键极速大卡片预览浮层 (Space Quick Look) (G21) 契约

## 状态

已接受，T-0132 / R279（2026-10-20，对标 macOS Finder Quick Look / Raycast 全局空格极速预览，落地 G21）。

## 背景与上下文

小驴常用在桌面端拥有右侧双栏预览窗格，但在复杂办公场景中：
1. **长代码块与长文本痛点**：对于上百行的代码脚本或长篇邮件模板，右侧窄栏预览窗格（通常仅 300~400px 宽）阅读困难，需要反复横向和纵向滚动；
2. **窄屏与移动端痛点**：在 ≤620px 视口或移动端，右侧窗格默认隐藏；
3. **行业对标**：macOS Finder 与 Raycast 核心体验标配：在列表选中任何项时，按下空格键（`Space`）即可弹出一个大视口、无边框、居中的全量富文本快速预览浮层；再次按下空格键或 `Esc` 即可瞬间关闭并恢复焦点，丝滑无比。

## 决策

1. **键盘事件与输入状态隔离 (`src/ui/dialog.ts`)**：
   - 仅当搜索输入框没有焦点（或焦点处于结果列表行）且当前有选中条目时，按 `Space` 触发极速预览；
   - 当用户在搜索输入框中打字输入空格时，严格保留原有输入行为，绝不拦截！
2. **轻量全屏预览浮层组件 (`openQuickLookOverlay`)**：
   - 居中展示最大宽度 720px、最大高度 80vh 的沉浸式快速预览卡片；
   - 复用既有的 `renderSafePreview`（富文本排版、代码语法芯片、行号对齐、标签/分类胶囊）；
   - 顶部提供快捷键键帽引导（`Space`/`Esc` 关闭，`Enter` 插入，`Alt+C`/`⌘+C` 复制）；
3. **无障碍与焦点管理**：
   - 浮层拥有 `role="dialog"` 与 `aria-modal="true"`；
   - 关闭后焦点平滑归还此前选中的列表项或搜索框。

## 结果与证据

- 交互审计扩展用例，验证非输入态 Space 唤起浮层、Esc 关闭浮层以及输入框内输入空格不受影响；
- 严格负向验证与全门禁通过。
