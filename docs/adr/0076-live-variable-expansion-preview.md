# ADR 0076：模板变量填写卡交互式实时求值与动态预览 (G24) 契约

## 状态

已接受，T-0135 / R282（2026-10-20，对标 Raycast Live Snippet Preview / TextExpander 变量展开所见即所得，落地 G24）。

## 背景与上下文

在小驴常用中，当模板包含 `{{xlc:ask:字段}}` 时，插入前会弹出轻量变量填写卡片（Variable Fill Card）：
1. **现有局限**：用户在填写表单时，只能看到各个输入框（文本/下拉/日期/多行），看不到这段内容在完整模板正文中的实际落点与展开效果；
2. **复合模板痛点**：对于商务合同、复杂邮件或 SQL/代码模板，变量往往嵌入在长语句或表格中。用户无法在按下回车前确认语病、格式错位或排版截断；
3. **行业对标**：Raycast Live Snippet Preview 与 TextExpander 在表单中输入变量时，卡片内实时呈现替换后的正文片段，所见即所得。

## 决策

1. **实时展开纯函数与防抖更新 (`renderLiveVariablePreview`)**：
   - `VariableFillOptions` 扩展 `templateText?: string`；
   - 在卡片底部增加紧凑且可折叠的「实时预览」区域（`.xlc-varform-preview`）；
   - 用户在任一输入框打字、改选下拉或修改日期时，触发轻量防抖（30ms），调用 `expandAsks` 与 `stripCursorToken` 进行正文替换；
   - 动态更新预览文本，未填写的字段显示为降调高亮标记（如 `[待填: 字段名]` 或 `__字段名__`），已填字段显示用户真实输入值；
2. **安全与防注入红线**：
   - 预览区域坚守零 HTML 注入红线，纯文本安全挂载，绝不使用 `innerHTML`；
   - 长度截断保护：最大预览展示 1000 字符，超出追加省略号；
3. **桌面与移动端体验自适应**：
   - 移动端默认折叠，可点击展开查看；
   - 桌面端平滑展示在按钮上方，不抢夺输入框垂直空间（独立可滚动）。

## 结果与证据

- 单元测试覆盖动态展开函数、未填与已填混合场景、特殊符号转义与长文本截断；
- 负向验证确保防抖与更新逻辑被篡改时精准失败；
- 全门禁通过。
