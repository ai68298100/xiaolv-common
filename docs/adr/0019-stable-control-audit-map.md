# ADR 0019：稳定控件标识与逐页交互审计

- 状态：接受
- 日期：2026-10-12
- 关联：T-0044 / R191

## 背景

`test:ix` 有 28 项交互链路断言，但不少动作依赖可见文字或样式类定位，组件清单也没有与每个已测控件建立对应关系。不能据此声称所有按钮、链接、表单控件和菜单项都逐一验收。新增底栏入口审计时还发现搜索弹窗在常用视口下内容超出宿主高度，帮助/设置控件不可达。

## 决策

1. 使用 `data-xlc-control` 作为交互审计的稳定、语义化控件 ID；不复用样式类作为唯一身份，也不由按钮文案临时推导 ID。
2. 按页面逐批建立“控件 ID → 入口/前置条件 → 可观察结果 → 断言编号”映射。测试需触发真实生产 DOM 监听，并观察状态变化、界面归宿或 service 调用结果。
3. 每批只声明已覆盖的控件和状态；未映射控件明确留在清单待办。宿主专属菜单与真实设备行为仍需现场验收。
4. 选择器标识与业务逻辑分离；添加 ID 不改变生产交互或视觉样式。

## 取舍

- 稳定 ID 需要随新增控件维护，增加少量标记，但可减少文案本地化和 CSS 重命名引起的测试漂移。
- 逐页映射比一次性自动点击所有控件慢；破坏性操作和需要宿主权限的动作必须依据各自前置条件与确认路径验证，不能盲目批量触发。

## 验证

- 搜索主面板新增 `search.*`、`filter.*`、`item.*`、`preview.*` 等语义 ID；组件清单列出已测试映射与仍无独立断言的标识。
- `pnpm run check` 与 `pnpm run test:ix` 通过，交互审计从 28/28 增至 44/44。
- 负向注入移除收藏控件 `item.favorite` 标识后，K3 失败（33/34）；移除搜索宿主 flex 收缩后，K11-K14 失败（40/44）；分别恢复后审计通过。
- 修复 `.xlc-dialog-host` 的 flex 收缩和搜索根 border-box 计算后，底栏入口在 900px 视口内可见并可打开帮助/设置。

## 未决

- 尚未加稳定 ID 的动态元数据 chip、空态 CTA 和动作菜单关闭路径/菜单项。
- 设置、首设、捕获、变量卡、导入导出、发现面板的逐控件映射。
- 原型与生产 DOM 自动结构差异门禁仍需单独设计。
