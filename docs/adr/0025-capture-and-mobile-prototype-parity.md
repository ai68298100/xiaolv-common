# ADR 0025：捕获表单与移动端原型一致性

- 状态：接受
- 日期：2026-10-13
- 关联：T-0050 / R197 / ADR 0017、ADR 0019

## 背景

修正前原型把捕获表单的类型画成只读文本，并把类型放在别名左侧；当前生产和原型均已统一为“别名｜类型”与可编辑下拉。移动端在无定向插入目标时，点按只选中条目，底部主按钮执行复制降级；直接插入能力尚未在真实移动宿主验证。

## 决策

1. 捕获表单字段顺序改为“别名｜类型”，类型保留生产下拉选择；原型与 smoke 同步体现可操作控件。
2. 移动端无定向插入目标时，原型显示点按选择、底部“复制选中”和明确的直接插入待验证提示；不声称点击即插入。
3. `test:ui` 检查生产捕获字段左右顺序、类型为 `select`，并检查移动模式下主按钮文案和降级提示。

## 取舍

- 这是原型与生产现状对齐，不改变移动端能力边界；待真实宿主验证插入后再调整主动作。
- 保持类型字段可访问标签和现有提交语义，不把展示顺序变化当成数据模型变更。

## 验证

- `pnpm run test:ui` 执行生产 DOM smoke，静态 prototype 渲染为 `prototype-mobile-sheet.png` 与 `prototype-capture-form.png`。
- 删除字段顺序或移动端降级断言应令对应 smoke 失败；恢复后复验。

## 未决

- 移动端真实触控和直接插入仍待 Android/Electron 现场验收（B-002）；当前产品行为是复制降级。
