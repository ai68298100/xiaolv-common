# ADR 0080：唯一别名精确匹配快捷直达与缩写极速插入 (G27) 契约

## 状态

已接受，T-0139 / R286（2026-10-20，对标 Alfred Snippets Keyword / Raycast Quick Action，落地 G27）。

## 背景与上下文

在重度键盘流用户的日常调用中，许多条目都设置了极短且唯一的别名（`alias`）或缩写（如 `yp` 代表「延期道歉」、`tk` 代表「退款指引」、`dz` 代表「收件地址」）：
1. **现有交互摩擦**：用户输入 `yp` 后，虽然该项被高分排序在第一位，但用户仍需确认列表聚焦或等待回车，无法直观确认当前输入是否已 100% 命中该唯一别名；
2. **行业对标**：Alfred 与 Raycast 当检测到唯一关键字精确匹配时，会在搜索框或首行右侧直接呈现金色「⚡ 直达徽标」与键帽提示，支持按 `Tab` 或 `Enter` 闪电插入，心流毫无停顿；
3. **中文输入法（IME）隔离**：在中文输入法拼音组词阶段（`isComposing` 或 `keyCode === 229`），不得误触直接插入。

## 决策

1. **唯一别名精确匹配判定纯函数 (`findExactAliasMatch`)**：
   - 在 `src/model/search.ts` 实现安全的纯函数匹配器；
   - 当用户查询词去除前后空白后，与库中某个条目的 `alias`（或当未配置别名时与 `title`）完全一致时，返回该条目；
   - 若多个条目具有相同别名，则不判定为唯一匹配（避免歧义误插）。
2. **UI 视觉与键盘交互联动 (`src/ui/dialog.ts`)**：
   - 搜索输入框右侧或首行呈现金色 `.xlc-badge--direct` 闪电徽标；
   - 当检测到精确匹配时，输入框内按 `Tab` 键优先被识别为「直达插入当前精确匹配项」；
   - 严格 IME 隔离：组词未上屏前绝不提前拦截。
3. **零破坏与向下兼容**：
   - 普通模糊搜索、拼音检索与多关键词组合 100% 保持原有流程不变。

## 结果与证据

- 单元测试覆盖单条精准别名命中、多条同别名去歧义、IME 组词隔离；
- 负向验证与全门禁通过。
