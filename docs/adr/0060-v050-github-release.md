# ADR 0060：v0.5.0 GitHub 发版范围与证据

## 状态

已接受，T-0118 / R265（2026-10-19，用户指令“当你感觉开发的内容已经值得发送到GitHub时，就加版号，经过检查后打包发版，可以通过gh发版”）。

## 决策

- 评估版本增量：自 v0.4.2 发布至今，本地累计推进了 34 个 commit，完成了 T-0086 至 T-0117 等 32 项高质量重要功能与安全防护，包括：
  1. 动态模板与占位符能力：日期算术（相对偏移与中文「今天/明天/后天/下周五」自然语言）、随机占位符与下拉选择多维标点（中英文逗号/顿号）归一化、变量填充卡默认值与预填支持；
  2. 片段嵌套与模板包：片段嵌套可视化代码芯片与展开详情诊断（`expandSnippetRefsDetailed`）、模板包依赖预检黄色警示徽标与提示、Compact Bundle 单行 Base64 与 URL 协议直接导入；
  3. 搜索与交互优化：搜索多关键词多维标点分词容错（加号、逗号、斜杠、分号、竖线连接）、拼音连续音节平滑高亮（消除打词闪烁）、时间范围筛选模型、捕获查重排除自身与全角空格归一化；
  4. 安全防御与硬门禁：B-006 Kramdown 写前保守防御（单行/完整代码围栏限制）、静态异常处理门禁（`scripts/check-error-handling.cjs`）、标签多维标点修正与 `#` 标签前后缀清洗、独立笔记本两步编排补偿凭据。
- 版本跃升：鉴于上述大量核心能力的成熟与闭环，决定将版本由 `0.4.2` 跃升为重大升级版 `0.5.0`。
- 目标为 `ai68298100/xiaolv-common` 的 GitHub main、tag 和附带 `package.zip` 的 Release。此次指令明确授权 GitHub 发版，但严格遵循项目不可撤销原则：**集市严禁自行推送**，不触碰 `bazaar/plugins.txt`，不发起上架 PR。
- 门禁守则：构建 `npm run build`、类型检查 `npm run check`、静态异常门禁 `npm run check:errors`、单元测试 `npm test`（553/553）、Chrome 生产 UI 冒烟测试 `npm run test:ui`、交互审计 `npm run test:ix`（74/74）、密钥扫描 `npm run scan` 与包检查 `npm run check:package` 必须全量通过后方可执行发版。
- B-005 隔离约束保持开放：离线验证不代表操作系统级沙箱已建立，严禁在未沙箱隔离环境下启动 Electron/思源宿主。真实 AI、Android 触控与 B-006 多块正文边界继续保留。

## 验证与结果

本地门禁全部通过，版本元数据（`package.json`、`plugin.json`）与中英文 `README`、`CHANGELOG` 完全同步。
通过 `gh release create` 执行标准发布与附件校验。
