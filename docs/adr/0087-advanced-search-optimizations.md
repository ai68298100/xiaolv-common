# ADR 0087：深度搜索优化（范围限定语法、拼音首字母增强、历史回填与时间戳归一）

## 状态
已接受，T-0150 / R292（2026-10-21，用户指令立项：继续优化搜索功能）。

## 背景与上下文
随着全库思源内容检索与常用语库的打通，搜索功能面临更深维度的体验与精度诉求：
1. **全库检索的范围限定**：思源大库中存在大量历史沉淀文档与归档笔记本，用户希望像高级检索一样直接在关键词中限定目录（如 `in:工作/日报` 或 `book:工作笔记`）；
2. **拼音首字母精准决策**：标题作为条目首要标识，连续拼音首字母缩写（如 `cwbx` 对应 `财务报销`）应享受高优先级专属打分；
3. **近期搜索历史的可视化回填**：以往只能通过盲操快捷键回溯历史，空输入时用户看不到自己搜过的内容；
4. **全库块与常用语的时间基线归一**：思源块 `updated` 包含 14 位 YYYYMMDDHHmmss 与秒级/毫秒级多种异构形态，混合排序时需严格转换为标准毫秒戳；
5. **键盘流盲操切域**：提供单键快捷轮转范围（`Alt+T`），无需鼠标移动。

## 决策

### 1. 范围限定语法解析与官方端点适配 (`parseOmniQueryScope`)
- 在 `src/service/omni-search.ts` 导出 `parseOmniQueryScope(query)` 纯函数；
- 识别 `in:路径`、`path:路径` 与 `book:笔记本` 前缀，提取出 `paths: string[]` 与 `notebook?: string`，剩余文本作为纯净检索词；
- 传参给思源官方 `/api/search/fullTextSearchBlock`，实现精准在特定目录或笔记本内穿透全文检索。

### 2. 标题拼音全拼与首字母缩写专属打分加权 (`calculateTitlePinyinBoost`)
- 在 `src/model/search.ts` 引入：
  - 标题首字母缩写完全吻合：+1.5 分；
  - 标题全拼完全吻合：+1.0 分；
  - 标题首字母缩写前缀吻合（前缀>=2）：+0.8 分；
  - 标题全拼前缀吻合（前缀>=3）：+0.5 分；
- 保持优雅的分值平衡，让首字母缩写大幅优先于正文与标签，同时恪守“拼音权重低于中文汉字标题”的根本契约。

### 3. 空输入态近期搜索历史 Chips 可视化回填
- 在 `src/ui/dialog.ts` 的搜索框下方新增 `.xlc-search-history-bar`；
- 输入框为空时，提取最近 5 条搜索历史展现为可点击的微型 Chips；
- 用户点击任意词秒级回填并激活检索；输入框有字符时自动收起，零视觉负担。

### 4. 思源异构时间戳标准毫秒归一化 (`parseSiYuanTimestamp`)
- 在 `src/service/omni-search.ts` 实现 `parseSiYuanTimestamp`；
- 将 14 位 `YYYYMMDDHHmmss`、秒级戳与毫秒戳安全转换为统一的标准毫秒时间戳，保证与常用语条目处于同一时间决胜基线。

### 5. 键盘流作用域快捷轮转 (`Alt+T` / `Alt+0`)
- 在 `onKeydown` 中支持 `Alt+T` 顺序轮转范围（all -> favorites -> recent -> current-doc -> all-notes -> all）；
- 支持 `Alt+0` 一键重置为全部范围，并同步顶部 Chips 高亮与占位符文案。

## 结果与证据
- 单元测试增至 704/704 全部通过；
- 契约测试覆盖范围解析、首字母缩写加权、时间戳跨进制归一；
- 全套工程门禁（check, scan, check:errors, check:package, build）全数通过。
