# ADR 0043：搜索框最近查询历史记忆与空输入历史回溯契约

## 状态

已采纳（2026-10-15，T-0070 / R217）。

## 背景

用户在使用小驴常用搜索面板时，常在几个场景关键词（如 `发票`、`延期`、`周报`）之间来回切换调用。
既有系统仅保留单个 `lastQuery`，当用户清空搜索框后，无法快速找回之前使用过的查询词。重度键盘用户习惯像终端命令或优秀启动器（如 Raycast、Alfred）一样，在输入框为空时通过 `↑` 方向键快速翻找上一次或前几次搜过的关键词。

## 决策

1. **最近查询历史持久化（Recent Queries Queue）**：
   - 在侧车配置 `SearchPrefs` 中增加 `recentQueries: string[]`，存储上限为 10 条；
   - 新增查询采用 LRU 式去重追加到首位（最新在前，自动剔除空串与重复项）；
   - 完全存储于本地思源插件侧车，绝不出域，保护用户隐私；
2. **空输入框 `↑`/`↓` 方向键历史回填**：
   - 当焦点在搜索输入框（`.xlc-search-input`）且当前文本为空（或处于历史回溯态）时：
     - 按 `ArrowUp` 依次向前读取历史查询词并自动回填至输入框，即时触发过滤；
     - 按 `ArrowDown` 向后回滚至更近的历史词，直至恢复为空输入；
   - 正常有输入且焦点在列表时，方向键严格保持现有的条目上下移动逻辑，杜绝行为冲突；
3. **前向与后向兼容性**：
   - 旧版本侧车数据无 `recentQueries` 字段时自动初始化为空数组，旧 `lastQuery` 依然保留作为最近项；
   - 损坏数据或超限数据在 `normalizeState` 中自动净化裁剪。

## 验证与边界

- 单元测试覆盖 storage 状态迁移对 `recentQueries` 的归一化、去重与容量上限；
- 单元测试覆盖历史回溯状态机的上翻、下翻与边界回退；
- 生产 UI 交互审计验证空搜索框按 `ArrowUp` 成功回填最近搜索词并重新过滤出条目。
