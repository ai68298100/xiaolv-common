# ADR 0052：真实 Electron 设置异常取证

## 状态

已接受，T-0082 / R229（2026-10-16）。

环境补注（T-0084）：收尾确认同一镜像存在额外日常工作区内核并自动同步，违反本 ADR 的预期隔离条件。压力结果仅是特定临时 renderer 在多工作区并存时的有限观测，不能作为严格隔离环境验收；详见 [事故记录](../electron-isolation-incident-2026-10-16.md) 与 ADR 0054。

## 问题

B-004 有 Chromium renderer crash 和宿主 `style` 为空两类历史现象。现有诊断脚本启动 Chromium，未覆盖完整真实插入/搜索前置；含直接删除宿主 Dialog DOM 的历史脚本不能作为可信 Electron 复现流程。单次压力未复现也不能证明问题已经解决。

## 决策

- 仅附着已核验的可销毁 Electron 副本：loopback CDP、临时工作区、镜像程序和精确主 PID 必须一致；不新启或操作日常宿主。
- 用公开内核 API、插件命令、真实键盘/鼠标与官方 Dialog 建立前置，不删除宿主 DOM、不 stub 编辑器、不强制穿透遮罩。
- 直接进入设置作为对照；真实复制/插入/搜索后再进入设置作为完整前置。用有限固定序列采样多轮快速操作和人工速度操作。
- `page crash`、插件异常、宿主异常、未知归因分别保留；完整 CDP 堆栈、实际操作命中和页面存活写入证据。未知归因不得被静默过滤。
- 本轮只改取证工具与记录，未有确定根因前不依据假设修改生产。未复现仍保留 B-004 开放，上游报告只准备本地草稿。

## 验证

诊断工具需实际证明前置动作落块、设置与库选择器存在、每次切换确实改变状态，并在退出时恢复本轮修改的设置。最终证据与限制记录于当期账本和 Electron 现场记录。

最终思源 3.8.7 / Electron 44.7.0 五组矩阵为 812 步、1849 次实际开关激活，11/11；无 crash、Runtime/pageerror/console 异常，六开关恢复，配置及源/目标快照不变。向唯一来源追加真实 witness、在 renderer 抛出真实 unknown 异常两项负向分别被原断言拒绝；原脚本随后短正向 7/7。B-004 继续开放，上游草稿已校正环境和根因断言，未发送。
