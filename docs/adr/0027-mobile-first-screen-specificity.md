# ADR 0027：移动端首屏覆盖优先级

- 状态：接受
- 日期：2026-10-14
- 关联：T-0053 / R200、ADR 0026

## 背景

R187 视觉 token 使用根作用域 `:is(...)` 统一弹窗样式。该选择器的特异性高于早先的窄屏覆盖，导致移动 sheet 标题栏和 body/content 恢复桌面宽松内边距，移动首屏的列表结果区域被压缩。旧宿主缓存还可能继续显示筛选换行。

## 决策

1. 在 `src/styles/index.scss` 的 `max-width: 620px` 中使用与 token 同等级的作用域选择器覆盖移动 sheet 的标题、内容区内边距和移动根间距。
2. 移动筛选保持单行横向滚动；搜索输入保持 16px，主操作、清空、帮助和设置入口继续遵循触控可达性。
3. 不通过隐藏结果、裁剪正文或改变插入降级语义换取空间；首屏优先级由标题/body 间距和根 gap 收敛实现。

## 验证

- 390×844 UI smoke：移动条目点按只选中、复制降级主操作、底栏入口和移动根结构通过。
- `pnpm run check`、`pnpm run build`、`pnpm run test:ui` 通过。
- 真实思源 Electron/Android 仍需刷新插件后现场确认，自动化截图不替代宿主验收。

## 未决

- Android 真实触控命中与宿主弹窗裁切继续按 B-002/B-004 跟踪。
