# ADR 0040：列表条目快捷收藏切换与即时响应契约

## 状态

已采纳（2026-10-14，T-0067 / R214）。

## 背景

在小驴常用的核心工作流中，收藏（星标）不仅决定了条目的高亮标识，还直接决定了在常用库手动排序（`manual`）与收藏范围筛选（`scope=favorites`）下的置顶位置。
目前用户只能借助鼠标点击列表行末尾的“★”按钮来切换收藏状态。在重度键盘浏览与检索时，缺少收藏切换快捷键，打断了全键盘整理的高效体验。

## 决策

1. **双键位快捷收藏设计**：
   - 绑定快捷键 `Alt + F`（Favorite，macOS 下 `⌥ + F`）与 `Alt + S`（Star，双键位兼容，避免特定桌面热键冲突）；
   - 触发条件：当前选中真实库条目（排除第三方虚拟 Provider 条目）；
   - 行为：`e.preventDefault()` 阻止浏览器菜单默认行为，调用 `toggleFavorite` 更新侧车持久化；
2. **位置保持刷新与焦点连续性**：
   - 触发后调用 `refreshPreservingPosition()`，在保持列表滚动位置的前提下即时重绘当前条目的星标状态（★/☆）、`.xlc-row--fav` 样式与无障碍名称；
   - 随后自动调用 `restoreFocusToSearch()` 确保焦点平滑稳定留在搜索输入框，不破坏连续打字心流；
   - 在“只看收藏”模式下，取消收藏后该行自然淡出并更新结果列表；
3. **防连发与防误触**：
   - 严格遵循 `if (e.repeat) return;`，杜绝用户长按导致星标高频抖动；
   - 顶部键帽提示栏同步增补 `Alt/⌥ + F` 收藏引导。

## 验证与边界

- 单元测试覆盖快捷收藏按键解析逻辑、虚拟条目隔离与防连发保护；
- 生产 UI 交互审计验证 `Alt+F` 准确派发条目 ID，更新星标状态并保持焦点；
- 移动端维持触控操作，不依赖物理热键。
