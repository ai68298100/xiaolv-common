# ADR 0032：键盘直达数字键与多区 Tab 导航契约

## 状态

已采纳（2026-10-14，T-0059 / R206）。

## 背景

在参考 Quicker 与易歪歪等同类高频内容工具的调用习惯后（参见 [`docs/research-2026-10-14.md`](../research-2026-10-14.md)），键盘调用效率是重度内容复用场景的核心指标。
既有实现虽然支持 `Alt+1~9` 快速插入和常规 `↑`/`↓`/`Enter` 导航，但存在以下待优化点：
1. **快捷复制缺失**：用户只能用 `Alt+1~9` 执行插入，若需要快捷复制前 9 项中的某一项，必须通过方向键移动选中后再按 `Ctrl+Enter`，增加了按键步骤；
2. **macOS 兼容性隐患**：macOS 输入法在按下 `Option(Alt) + 1~9` 时，常被捕获为输入特殊字符（如 ¡™£¢∞§¶•ªº），导致 `e.key` 无法命中 `/^[1-9]$/`；
3. **Tab 焦点流转与弹窗焦点陷阱（Focus Trap）**：主搜索面板在按 `Tab` 时默认穿越所有中间次要 DOM 元素（如清空按钮、筛选下拉框），且未实施焦点环绕保护，可能导致焦点逃逸出模态弹窗；
4. **数字角标可访问性与提示**：列表前 9 项虽渲染了序号，但其提示文案为通用的全局说明，未精准表达该项的直达快捷键。

## 决策

1. **数字直达增强**：
   - **快速插入**：`Alt + 1~9`（保持既有行为），在键位检测上增加 `e.code` 为 `Digit1`~`Digit9` 的兜底判断，确保 macOS/各输入法下的兼容性；
   - **快速复制**：新增 `Alt + Shift + 1~9`（同时支持 `e.code` 判定），直接将对应项的内容复制到剪贴板并给出提示，不触发插入；
   - **防连发控制**：严格继承 `if (e.repeat) return;`，防止长按连发。
2. **序号角标提示精确化**：
   - 前 9 项的 `.xlc-row-ordinal` 赋予精确的本地化提示（如 `Alt+1 插入 · Alt+Shift+1 复制`），并设置清晰的 `aria-label`。
3. **Tab 导航与焦点闭环（Focus Trap）**：
   - 在搜索主面板内接管模态内的 `Tab` 与 `Shift+Tab` 焦点循环，确保焦点永远在弹窗内部元素流转，绝不逃逸至思源底层视图；
   - 在主搜索输入框按 `Tab` 时，若右侧预览区操作栏存在可用操作（如插入/复制按钮），优先聚焦操作栏首项，提升键盘直达便利性。

## 验证与边界

- 单元测试与契约测试验证数字序号计算、快捷键分派逻辑（插入与复制分支互不干扰）、防连发与越界保护。
- 自动化 UI 交互审计验证 Tab 焦点闭环与键盘直达动作触发。
- 移动端不依赖物理键盘，保持原有触控与底栏操作，自动降级。

## 取舍

- 不采用无修饰键的纯数字 `1~9` 触发，因为搜索框内需要支持纯数字的关键词搜索（如搜索工单号、电话、版本号 123 等），无修饰键会与输入行为产生严重冲突。
- 快捷复制选择 `Alt + Shift + 1~9` 而非 `Ctrl + 1~9`，是因为 `Ctrl + 1~9` 在思源及部分桌面环境为工作区标签页切换保留热键，`Alt + Shift` 具有极佳的兼容性且符合组合语义。
