# ADR 0042：场景分类语义彩色徽标与确定性色系映射契约

## 状态

已采纳（2026-10-15，T-0069 / R216）。

## 背景

参考同类高频内容工具（Quicker 常用语、易歪歪等，参见 [`docs/research-2026-10-14.md`](../research-2026-10-14.md)）的视觉实践，色彩分层是提高列表可读性与信息获取速度的关键手段。
既有列表行仅展示了数据物理类型徽标（如 `TXT`、`MD`、`CODE` 等），条目的核心业务场景分类（`category`）未在列表首屏主干中呈现。用户在混合分类浏览时，只能通过阅读正文摘要或展开全部分类分组来区分场景，视觉扫视效率有待提升。

## 决策

1. **列表行场景分类徽标（Category Badge）**：
   - 在列表行标题栏（`.xlc-row-title`）类型徽标后，若条目拥有有效非空 `category`，插入独立分类胶囊 `.xlc-badge--cat`；
   - 徽标纯文本写入，包含完整的 `title` 与 `aria-label`；
2. **核心场景语义色与确定性哈希色板**：
   - 为常见高频业务场景预置 5 种语义色系（商务天蓝、客服翡翠绿、开发淡紫、写作暖琥珀、AI 提示词亮靛）；
   - 对任意自定义分类，采用确定性字符哈希函数映射到上述 5 种预置莫兰迪色系变体之一，保证同名分类在明暗主题、不同设备与会话下视觉呈现严格恒定；
3. **弹性排版与尺寸安全**：
   - 徽标设置 `max-width: 84px` 与文字截断省略，保证在移动端或窄容器下优先保障条目主标题的横向阅读宽度；
   - 遵循 `tokens-r187.scss` 变量体系，明暗主题自适应切换，无裸颜色值硬编码。

## 验证与边界

- 单元测试验证分类色彩确定性映射、空值安全与长文本保护；
- 负向门禁测试验证映射函数有效性；
- 生产 UI 冒烟测试断言包含分类徽标的列表行渲染及主题样式。
