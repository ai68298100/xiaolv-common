# ADR 0049：保存标签视图与引用同步

## 状态

提案已采纳，阶段二完成（2026-10-16，T-0078 / R225）；T-0079 / R226 补齐宿主修复与文档/文档树真实 Electron 验收。

## 决策

发现会话按标签聚合并提供可点击筛选；后续保存视图只保存名称、精确标签、范围和目标 ID 等 UI 快捷配置，不保存正文和引用关系。引用入口继续使用现有 `blockref` marker，正文调用时从源块实时读取。首版不把源块直接混入主搜索索引，避免隐式全库扫描和执行器语义扩张。

源块、标签和正文仍以思源块为真源；非法范围、缺少目标或空标签必须丢弃，不回退到当前文档。引用同步重复运行依靠来源块 ID 幂等，源块删除只显示来源失效。

## 实现与验收

- 发现面板按候选标签聚合并支持精确筛选；`常用` 不命中 `常用2`。
- 视图保存到 `SearchPrefs.savedDiscoveryViews`，上限 20 条，严格校验 ID、范围、目标和字段长度；只保存规则，不保存正文。
- 设置页支持视图打开/删除。文档、笔记本、文档树视图重开时预填标签，扫描完成后自动选中确定可新增候选并锁定引用模式；同名同规则保存幂等覆盖。
- `test:ui` 覆盖保存回执、设置列表和视图重开；`test:ix` 覆盖 B19/B20；`pnpm test`、构建、隔离内核与发现 E2E 均通过。

当前不支持从发现面板保存或重开“指定笔记本/全部笔记本”视图，模型仍保留这些范围以便后续补齐目标和确认状态。Android、真实 AI 和 Electron 现场边界不因本 ADR 改变。

## T-0079 / R226：宿主命名表单修订（2026-10-16）

隔离思源 3.8.7 Electron 中点击保存视图实际抛出 `Error: prompt() is not supported.`；原实现捕获后返回，导致保存入口没有反馈。命名交互改用官方 `Dialog`，沿用现有表单样式与内容容器兼容层，取消不写入，空白名称就地报错，输入法确认不提交，父发现窗关闭时销毁命名窗。

打开命名窗时冻结标签、范围、目标和默认分类；仅在有效提交时保存规则。正文真源、引用入口和侧车语义沿用本 ADR。回归使用真实 DOM 填写表单，不再通过浏览器 prompt stub 冒充宿主可用。现场验收和验证结果由 T-0079 账本与 Electron 验收记录跟踪。

文档树目标固定为根文档 ID；预览和写入前按该根文档的当前物理路径核验范围。思源的根文件 `/root.sy` 对应后代目录 `/root/`，须去除末尾 `.sy` 后按完整路径段比较，并核对笔记本边界。整树在同一笔记本移动后仍可使用；留在旧位置、仅有相似路径前缀或移到其他笔记本的来源必须拒绝。

标签胶囊独占筛选区一行并可换行；发现根工作面在高度不足时可滚动，确保回执和撤销动作完整可达。范围说明不再把引用收录误写成只复制正文。
