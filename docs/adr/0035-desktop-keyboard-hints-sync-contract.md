# ADR 0035：桌面快捷键键帽栏同步与按键引导契约

## 状态

已采纳（2026-10-14，T-0062 / R209）。

## 背景

在 T-0059 中，插件增强了重度键盘工作流：引入了 `Alt + Shift + 1~9`（macOS 下 `⌥ + ⇧ + 1~9`）快速直达复制，以及按 `Tab` 键快速在主搜索框与右侧预览操作区之间切换焦点。
然而，主搜索弹窗顶部的键帽提示栏（`.xlc-kbdrow`）此前仅静态展示了基础操作（方向键选择、Enter 插入、Ctrl+Enter 复制、Alt+1-9 插入、Esc 关闭），未能反映新增的高效快捷操作，导致用户第一眼无法获知这些能力。

## 决策

1. **键帽提示栏全面对齐高频键盘流**：
   - 新增 `Alt + Shift + 1-9`（Apple 设备显示 `⌥ + ⇧ + 1-9`）：引导直达复制；
   - 新增 `Tab`：引导从搜索输入框平滑聚焦至预览操作区；
2. **跨平台键帽符号规范**：
   - Windows/Linux：使用标准文本缩写 `Ctrl`、`Alt`、`Shift`、`Tab`；
   - Apple（macOS/iPad）：使用原生符号 `⌘`、`⌥`、`⇧`、`Tab`；
3. **弹性排版与折行安全**：
   - `.xlc-kbdrow` 采用 `flex-wrap: wrap;` 与规范的 4px 栅格间距，确保在不同视口宽度和容器尺寸下平滑折行，绝不横向撑破或裁切顶栏操作。

## 验证与边界

- 单元测试核对新增 i18n 键名及在多语言字典下的完整性；
- 生产 UI 冒烟测试断言键帽栏各元素正常渲染与无障碍提示关联；
- 移动端 sheet 不展示桌面键帽提示栏，维持移动端专属简洁布局。
