# ADR 0022：捕获辅助控件交互审计

- 状态：接受
- 日期：2026-10-12
- 关联：T-0047 / R194 / ADR 0019、ADR 0021

## 背景

捕获表单核心字段、保存和取消已由 R193 映射；其余高频创作辅助包括 AI 整理/草稿、建议采纳和变量快捷栏。原 smoke 只确认 AI 建议行出现，没有触发采纳；草稿和 10 种变量按钮也没有逐项结果断言。

## 决策

1. 为 AI 整理、AI 建议采纳、AI 草稿描述/生成及 10 种变量语法按钮增加稳定语义 ID。
2. 生产 DOM smoke 验证整理按钮空正文禁用、忙态锁和去重、建议被采纳到对应元数据且不改正文；草稿空描述禁用，已有正文先拒绝覆盖，明确确认后替换。
3. 变量快捷栏以表驱动方式逐个点击 10 种语法，验证插入到光标/选区处、保留前后正文、回焦正文、光标落在插入文本之后，并清除正文校验错误。
4. harness 记录 AI 调用及参数；这些调用记录与生产 DOM 交互结果只证明 UI 接线，不代表思源 AI 宿主端到端行为。
5. 延迟/失败/关闭后迟到响应等 AI 生命周期矩阵当时留作后续独立范围，已由 ADR 0023（R196）补齐 UI 失败恢复和关闭隔离；真实模型配置、超时语义和 Electron AI 行为继续受 B-001 限制。

## 取舍

- “全部采纳”按产品命名覆盖 AI 建议对应的元数据字段，正文保持不变；AI 草稿可能覆盖正文，必须经过现有确认回调。
- 稳定 ID 对应语义类型而非按钮文案；变量栏十项逐项映射，后续语法增删需同步 smoke 和组件目录。

## 验证

- `pnpm run test:ui` 逐项触发上述控件并核对字段/正文/焦点/光标和调用结果。
- 对新增断言执行负向注入，确认缺少控件映射或行为后 smoke 失败；恢复后重跑。
- 组合验证和截图证据记入当期开发账本与验收审计。

## 未决

- AI 服务失败重试、关闭后延迟响应和草稿错误回执已在 ADR 0023/R196 记录；建议字段的显式清空语义仍沿用现有采纳规则，未新增自动清空。
- Electron 内真实模型调用仍按 B-001 现场验证；不能由 harness 成功桩替代。
