# ADR 0070：跨应用富文本剪贴板双载荷输出 (G18) 契约

## 状态

已接受，T-0129 / R276（2026-10-20，对标 Quicker / TextExpander / PhraseExpress 客服与邮件多格式载荷复制能力，落地 G18）。

## 背景与上下文

小驴常用三大核心场景之一为**客服与邮件模板**。在日常办公中，用户高频将常用内容复制后粘贴至外部应用（如 Outlook、网页邮箱、飞书、企业微信、钉钉等）：
1. **痛点**：目前复制动作仅写入 `text/plain` 纯文本。若正文中包含加粗（`**text**`）、列表、超链接（`[title](url)`）或行内代码，粘贴到外部富文本应用时，对方接收到的仅为裸 Markdown 字符，排版结构丢失；
2. **行业对标**：Quicker 与 TextExpander 在复制时均默认注入 `text/html` 与 `text/plain` 双 MIMETYPE 载荷。现代操作系统剪贴板在目标应用粘贴时，若目标为普通输入框（如 Notepad、终端）则读取纯文本；若目标为富文本编辑器（如邮件、Word、富文本聊天框）则自动读取 HTML 呈现精美排版；
3. **安全红线**：所有 HTML 产出必须走严格受控的 AST/正则转义纯函数，绝对杜绝任何未转义外部 HTML/Script 注入（XSS 防御）。

## 决策

1. **轻量无依赖 Markdown 到安全 HTML 转换引擎 (`renderSafeHtmlFromMarkdown`)**：
   - 在 `src/model/clipboard.ts` 实现安全的轻量转换器；
   - 核心规则：
     - 转义 HTML 敏感字符：`&` -> `&amp;`, `<` -> `&lt;`, `>` -> `&gt;`, `"` -> `&quot;`；
     - 粗体：`\*\*(.*?)\*\*` -> `<strong>$1</strong>`；
     - 斜体：`\*(.*?)\*` -> `<em>$1</em>`；
     - 删除线：`~~(.*?)~~` -> `<del>$1</del>`；
     - 行内代码：`` `(.*?)` `` -> `<code style="...">$1</code>`；
     - 超链接：`\[(.*?)\]\((https?:\/\/[^\s)]+)\)` -> `<a href="..." target="_blank">$1</a>`（严格限制 http/https 协议）；
     - 无序列表：`^- (.*)` -> `<ul><li>...</li></ul>`；
     - 换行与段落：保留段落分隔 `<p>...</p>` 或 `<br>`。
2. **多载荷剪贴板写入能力 (`writeRichClipboard`)**：
   - 优先通过原生 `navigator.clipboard.write([new ClipboardItem({ 'text/plain': ..., 'text/html': ... })])` 写入双载荷；
   - 当宿主剪贴板权限受限或不支持 ClipboardItem 时，平滑安全回退至标准纯文本写入；
   - 纯函数模型，支持测试夹具与桩验证。
3. **执行层接入 (`ActionExecutor`)**：
   - 在条目复制（`copyItem`）和全域条目复制中透明接入，无需用户切换模式；
   - 复制 Markdown 或 Text 类型条目时，自动同步携带经过转义清洗的 HTML 载荷。

## 结果与证据

- 单元测试增设转换器覆盖率用例，覆盖 XSS 注入攻击防御、各种 Markdown 标记转换与协议白名单；
- 负向验证：故意注入脚本标签或破坏转义，测试精准拦截失败；
- 全套工程门禁全数通过。
