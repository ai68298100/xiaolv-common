# ADR 0072：安全内联算术计算占位符引擎 (G20) 契约

## 状态

已接受，T-0131 / R278（2026-10-20，对标 Quicker / Raycast / Espanso 算术求值扩展，落地 G20）。

## 背景与上下文

在商务报价、财务发票、折扣核算、工时汇算以及日常写作等场景中，用户高频需要在模板内直接进行数值运算：
1. **痛点**：目前小驴常用支持丰富的日期算术（如 `+3d`、`明天`），但缺乏数值四则运算能力。用户若需要计算含税价（`单价 * 1.13`）、折扣价或工时换算，必须切换外部计算器算好后再填写；
2. **行业对标**：Quicker、Raycast 与 Espanso 均内置文本内联计算器；
3. **安全红线**：严禁使用 `eval()` 或 `new Function()` 执行任意代码（杜绝任何代码注入与提权风险），必须基于受限词法与递归下降解析器（Recursive Descent Parser）实现纯数学四则运算。

## 决策

1. **安全数学求值引擎 (`evaluateMathExpression`)**：
   - 在 `src/model/calculator.ts` 实现纯函数数学表达式解析器；
   - 支持词法：数字（整数与浮点数）、基础运算符 `+`, `-`, `*`, `/`, `%`、优先级括号 `()`、安全数学函数 `round(x[, digits])`, `floor(x)`, `ceil(x)`, `abs(x)`；
   - 严格防御：除以零返回 `null`；畸形语法返回 `null`；无限循环防护（最大 Token 限制 100）；
   - 结果浮点精度修正（避免 `0.1 + 0.2 = 0.30000000000000004`，自动通过 `Number.EPSILON` 或 10 位精度修剪末尾多余零）。
2. **语法与参数解析 (`resolvePlaceholder`)**：
   - 语法：`{{xlc:calc|EXPRESSION}}`；
   - 示例：`{{xlc:calc|100 * 1.13}}` -> `113`；
   - 示例：`{{xlc:calc|round(100 / 3, 2)}}` -> `33.33`；
   - 示例：`{{xlc:calc|(50 + 30) * 0.8}}` -> `64`；
3. **安全边界与向下兼容**：
   - 非法或无法求值的表达式严格返回 `null`，原样保留原始占位符原文不被吞噬。

## 结果与证据

- 单元测试增设计算器专属套件，覆盖运算符优先级、括号嵌套、浮点精度修剪、函数调用与除零防御；
- 严格负向验证，并通过全套工程门禁。
