# ADR 0044：条目标签胶囊渲染与即时筛选联动契约

## 状态

已采纳（2026-10-15，T-0071 / R218）。

## 背景

在参考同类高频内容工具（Quicker 常用语、易歪歪等，参见 [`docs/research-2026-10-14.md`](../research-2026-10-14.md)）的知识整理与调用模式后，标签（Tags）是跨分类组织条目的重要正交维度（例如“发票”、“退换”、“跟进”、“SQL”）。
既有实现中：
1. 列表行内的标签与正文摘要混排为单串纯文本（`entry.tags.join(" / ") · 摘要`），视觉缺乏分层且无法单独点击；
2. 详情预览窗格中的标签为静态 `.xlc-meta-chip`，无法交互；
3. 用户若想按某个看到的标签进行过滤，必须在顶栏多个下拉框中定位到“标签：全部”，并在几十个标签选项中手动滚动翻找，严重打断调用心流。

## 决策

1. **列表行与详情区标签胶囊组件**：
   - 在列表元数据行（`.xlc-row-meta`）中，将有效标签渲染为微型胶囊按钮 `.xlc-tag-pill`；
   - 在详情预览区（`.xlc-pane-meta`）中，标签升级为支持点击的交互式芯片 `.xlc-meta-chip--clickable`；
   - 包含明确的无障碍属性与本地化提示（未筛选时提示“点击按此标签筛选：%s”，已筛选该标签时提示“点击取消标签筛选：%s”）；
2. **即时筛选联动与反选切换（Quick Filter & Toggle）**：
   - 点击标签胶囊时执行 `filterByTag(tag: string)`：
     - 若当前未筛选该标签：将标签筛选器选中值设为目标标签，持久化到侧车配置，并触发 `refresh()` 重新检索过滤同标签条目；
     - 若当前已经按该标签筛选：再次点击该标签胶囊，自动切回“全部标签”（`""`，即反选取消过滤），恢复全局列表；
   - 过滤触发后，自动调用 `restoreFocusToSearch()` 将焦点平滑归还搜索输入框，不破坏后续键盘连续输入；
3. **事件隔离与防误触绝对红线**：
   - 标签胶囊点击事件必须严格执行 `e.stopPropagation()`，绝对禁止冒泡触发整行条目的选中或主插入动作；
   - 标签胶囊支持键盘 Tab 聚焦与 Enter/Space 键触发；
4. **弹性排版与视觉保护**：
   - 列表行仅展示前 3 个标签胶囊，超出部分折叠为 `+N` 紧凑提示，优先保障正文摘要与使用计数的可见性；
   - 样式遵循全局 Token 规范，自适应思源明亮与暗色主题。

## 验证与边界

- 单元测试验证标签快速筛选与反选取消的状态机决策、多标签截断与空值安全；
- 生产 UI 交互审计验证点击列表行与详情区标签胶囊准确派发筛选、更新下拉框并在再次点击时恢复；
- 移动端保持触摸安全区，不影响整行触摸滑动。
