# ADR 0046：搜索结果空态智能诊断与范围回退引导契约

## 状态

已采纳（2026-10-15，T-0073 / R220）。

## 背景

在参考优秀桌面启动器（Raycast、Alfred、Quicker 等，参见 [`docs/research-2026-10-14.md`](../research-2026-10-14.md)）的检索体验后，空结果态（Empty State）不仅是告诉用户“没有结果”，更应作为高导向性的快捷跳板，引导用户以最小代价恢复成功检索。
目前在小驴常用中：
1. 当用户处于“只看收藏”（`scope=favorites`）或“最近使用”（`scope=recent`）范围时，若输入查询词未在当前子集中命中，界面呈现空态提示；
2. 此时该条目往往存在于全库其他条目中；用户必须移步顶栏，手动寻找并点击“全部”范围 chip，操作链路长且打断打字心流；
3. 用户如果在限制范围内反复检索不到，容易误以为库中没有该条目而重复创建。

## 决策

1. **空态受限范围智能诊断与一键全库回退按钮**：
   - 当搜索结果为空（`results.length === 0`）且存在查询词时，若检测到 `currentScope !== "all"`（即当前处于收藏或最近范围），在空态区域优先渲染一键动作按钮：
     - 控件标识：`data-xlc-control="empty.scope-fallback"` 与 `data-xlc-action="scope-all"`；
     - 按钮文案：`在全部内容中搜索「%s」`（英文：`Search "%s" in all items`）；
     - 按钮样式：使用突出的主操作按钮 `.xlc-btn-primary`，作为当前最可能解决问题的推荐动作；
2. **状态流转与即时检索**：
   - 点击该回退按钮后：
     1. 将当前范围设为全库（`this.currentScope = "all"`）；
     2. 自动同步顶栏范围芯片的选中态高亮（`this.syncScopeChips()`）；
     3. 触发 `this.refresh()` 立即以当前查询词在全库执行匹配；
     4. 调用 `this.restoreFocusToSearch()` 保持搜索输入框的连续输入焦点；
3. **成功路径共存与优先级排序**：
   - 处于受限范围无命中时，空态同时保留两条清晰的下一步路径：
     - 首选动作：“在全部内容中搜索「%s」”（扩大范围找已有）；
     - 次选动作：“＋ 以该词新建条目”（确实没有则就地新建）；
   - 用户无需清空已有输入或四处寻找控件，在当前焦点区即可一键解决。

## 验证与边界

- 单元测试直接调用生产范围判断/查询截断函数，并验证 i18n 资源多语言一致；
- 生产 UI 交互审计验证收藏和最近范围下搜索无命中时，回退按钮及次级新建入口正确呈现，点击后范围切换为 `all`、保留查询、重新检索命中并恢复焦点；
- 移动端 sheet 自适应紧凑排列，触控热区保持标准 44px。
