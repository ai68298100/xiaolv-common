# ADR 0081：常用语使用热力透视与打字时间节省计算看板 (G28) 契约

## 状态

已接受，T-0140 / R287（2026-10-20，对标 Raycast Usage Insights / TextExpander Statistics，落地 G28）。

## 背景与上下文

小驴常用在侧车中记录了每个条目的本机使用计数与最近使用时间（`UsageEntry`）：
1. **用户价值感知**：用户使用常用语和模板积累了大量复用操作，但缺乏直观的数字看板告知用户“到底用了多少次、节省了多少键盘敲击、省下了多少工作时间”；
2. **行业对标**：TextExpander 与 Raycast 均提供个人使用洞察（Statistics），量化展示累计展开词数、节省字符数以及换算出的工时收益；
3. **隐私与纯本地计算红线**：
   - 纯本地侧车统计，不收集任何用户隐私数据；
   - 纯函数计算模型，可随时清空重置。

## 决策

1. **时间节省与按键量估算纯函数 (`calculateUsageInsights`)**：
   - 在 `src/model/usage-insights.ts` 实现统计引擎；
   - 参数指标：
     - 人均平均打字速度常数：`TYPING_CPM = 200`（每分钟约 200 字符 / 约 40 词）；
     - 单次模态呼出平均按键成本估算：约 6 键（呼出 + 检索 3 键 + 回车确认）；
   - 计算模型：
     - 节省字符量（Saved Characters）：`∑ (条目正文长度 - 6) × 使用次数`；
     - 节省时间（Saved Time）：`节省字符数 / TYPING_CPM`，换算为分钟/小时；
     - 高频榜单（Top Frequent）：前 5 个最常用模板；
     - 近期活跃榜单（Recent Active）：最近 7 天内有调用的条目数；
2. **设置面板透视卡片 (`src/ui/settings-dialog.ts`)**：
   - 在设置面板渲染紧凑的「使用数据透视与时间节省看板」（`.xlc-usage-insights`）；
   - 展示三个核心指标卡（累计调用次数、节省键盘敲击、估算节省工作时间）；
   - 纯只读展示，数据可随时一键清空并回到零态。

## 结果与证据

- 单元测试覆盖各边界计算（单字短条目防负数、多条目聚合、时间换算格式化）；
- 负向验证与全门禁通过。
