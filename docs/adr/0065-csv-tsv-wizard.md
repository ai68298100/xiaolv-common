# ADR 0065：批量导入 CSV/TSV 字段映射向导 (G13) 契约

## 状态

已接受，T-0124 / R271（2026-10-19，对标 Raycast / Airtable 表格导入体验，落地 G13）。

## 背景与上下文

R267 实现了通用 CSV/TSV 批量导入引擎，但用户粘贴表格后仍需手动确认列映射关系。对于非技术用户或复杂表头场景，自动推断可能不准确，导致导入结果不符合预期。

## 决策

1. **交互式字段映射向导对话框**：
   - 在 `src/ui/csv-tsv-wizard.ts` 实现独立向导对话框；
   - 粘贴表格文本后自动检测列数并展示「标题/正文/分类/标签/别名/链接」映射下拉框；
   - 支持一键「智能推断」（基于表头关键词匹配）；
   - 实时预览前 5 行解析结果，确认后再进入导入策略对话框。
2. **自定义列覆盖 API 扩展**：
   - `parseCsvTsvItems` 增补 `customMapping` 参数，允许调用方显式指定各列索引；
   - 支持 `hasHeaderRow` 强制模式切换（有表头/无表头），避免自动推断误判。
3. **UI 集成与多入口统一**：
   - 设置页「从 CSV / 表格导入」按钮直接打开向导对话框；
   - 文件选择器导入时仍保留原有快速解析路径（兼容旧体验）。

## 结果与证据

- 单元测试增至 585/585 全部通过；
- 专项测试 `tests/r271-csv-wizard.test.cjs` 包含 3 项用例，验证自定义列映射、tags/alias 覆盖、urlIndex 映射；
- 全套工程门禁 `check:errors`、`check`、单元 `585/585`、`build`、`test:ui`、`test:ix`（74/74）、`scan`、`check:package` 全数通过。
