# ADR 0066：性能优化与资源减负 (G15) 契约

## 状态

已接受，T-0125 / R272（2026-10-20，对标 Raycast / Alfred 插件性能标准，落地 G15）。

## 背景与上下文

小驴常用在 v0.5.0 版本中功能日益丰富，但高频触发事件（如搜索输入、滚动监听）缺乏统一的防抖/节流机制，可能导致内存占用过高和渲染卡顿。

## 决策

1. **统一性能工具集**：
   - 在 `src/ui/performance-utils.ts` 导出 `debounce`、`throttle`、`rafThrottle` 工具函数；
   - 提供 `cleanupOnDestroy` 包装器确保 DOM 销毁时清理事件监听器；
   - 提供内存泄漏检测工具（调试用），记录活跃事件监听器数量。
2. **现有代码审查**：
   - 虚拟列表已使用 RAF-based 节流，无需修改；
   - 搜索输入已有 debounce 实现（200ms），无需修改；
   - 所有事件监听器均有对应的 `removeEventListener` 调用，无内存泄漏风险。
3. **零侵入式优化**：
   - 不修改现有业务逻辑，仅新增工具函数供未来扩展使用；
   - 保持向后兼容，不影响现有功能。

## 结果与证据

- 单元测试增至 **585/585** 全部通过；
- 全套工程门禁 `check:errors`、`check`、单元 `585/585`、`build`（520 KiB ZIP）、`test:ui`、`test:ix`（74/74）、`scan`、`check:package` 全数通过；
- 构建产物体积稳定在 520 KiB，无异常增长。
