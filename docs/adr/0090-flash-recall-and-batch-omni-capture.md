# ADR 0090：别名闪电直达 (Flash Recall)、全域块批量收录与二次精细重排

## 状态
已接受，T-0154 / R292（2026-10-21，用户指令立项：持续深度优化）。

## 背景与上下文
随着外部 Quicker 联动、全域思源块检索深入落地，用户在极速调用与批量资产沉淀方面迎来了全新诉求：
1. **外部调用一步直达**：Quicker / 外部启动器用户在微信、Word 等窗口中，希望直接输入别名（例如 `yq`）即可一步取回已展开变量的最终文本，避免“先检索列表、再二次取正文”的多轮通信往返；
2. **全域搜索结果的批量资产沉淀**：全库检索出 5~10 条有用笔记块时，以往只能单条逐个收录，缺乏一键批量收录为常用语条目的闭环能力；
3. **多关键词全库召回的精准度提升**：思源官方 FTS 端点主要按基础词频排序，当多词出现时，标题/大纲密集命中且间距紧密的块应当享有更高的排序优先级。

## 决策

### 1. 外部调用【别名闪电直达】接口 (`recall`)
- 在 `XiaolvCommonService` 与 `external-bridge.ts` 暴露 `recall(aliasOrKeyword, fills?)`；
- 阶梯决胜算法：
  1. 别名完全匹配（`alias === key`）：若唯一匹配，直接调用 `resolve` 计算并返回 `ResolvedItemData`；若重名返回候选列表；
  2. 标题拼音首字母缩写完全匹配（`pyi === key`，如 `cwbx` 匹配 `财务报销`）：若唯一匹配，直接计算返回；
  3. 普通前缀搜索降级：若有唯一结果直接返回，有多条返回前 5 项候选；未命中返回 `not-found`；
- 在 `src/index.ts` 注册协议命令 `xiaolv.common.recall`。

### 2. 全域条目多选批量收录入库 (`Batch Capture from Omni`)
- 在 `src/ui/dialog.ts` 的多选管理栏中新增 `✦ 批量收录 (N项)` 按钮；
- 用户在全库检索结果中按 `Alt+M` 勾选多项全库块后，点击一键并发收录进常用库，自动继承文档分类与溯源标签，并弹出批量成功通知。

### 3. 全库搜索块二次精细重排 (`rerankBlockHits`)
- 在 `src/service/omni-search.ts` 实现纯函数 `rerankBlockHits(hits, query)`；
- 标题/大纲块密集匹配所有 token (+50)、正文密集匹配所有 token (+30)、标题块固有权重 (+10) 综合加权，重排后呈现最强语义相关块。

### 4. 键盘导航平滑视野对齐
- 优化 `paintActive` 中选中行滚动行为：`scrollIntoView({block: "nearest", inline: "nearest"})`，消除外层文档跳闪。

## 结果与证据
- 单元测试增至 715/715 项全数通过；
- 契约测试验证别名唯一匹配一步返回展开正文、拼音缩写直达、多条候选分流与未命中错误信封；
- 全套工程门禁（check, scan, check:errors, check:package, build）全数通过。
