# ADR 0008：内测版显示名与技术标识分离

## 状态

已采纳（2026-10-08）

## 背景

插件进入内测阶段，需要让用户在集市、命令面板、顶栏和文档中明确看到「小驴常用（内测版）」。仓库、插件目录、协议和已有侧车数据使用 `xiaolv-common`，这些标识已经参与安装、联动与数据恢复。

## 决策

- 所有用户可见的中文显示名统一为「小驴常用（内测版）」；英文显示名使用 `LvCommon (Beta)`。
- `xiaolv-common` 继续作为 package name、plugin name、插件安装目录、协议名和 provider 查找标识。
- README 保留技术标识示例，并补充内测说明、交流 QQ 群和八个小驴系列插件索引。

## 理由

显示名表达发布阶段，技术标识表达稳定身份。两者分离可以明确告知用户当前处于内测，同时避免升级时改变插件目录、协议协商和已有数据的定位。

## 影响

新安装用户会在入口和元数据中看到内测版名称；旧数据、协议调用和安装路径无需迁移。模板包与导出文案同步更新为内测版名称，旧格式导入仍按原有元数据规则兼容。
