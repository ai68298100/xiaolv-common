# ADR 0026：桌面宽松密度与移动首屏优先

- 状态：接受
- 日期：2026-10-14
- 关联：T-0052 / R199、ADR 0015、ADR 0025

## 背景

真实使用反馈显示，桌面搜索与发现的列表/预览框纵向空间不足，条目正文容易被截断；移动端标题、说明和多行筛选挤占了结果首屏，搜索结果区域难以使用。

## 决策

1. 桌面弹窗使用更大的宽高上限，并由 `vh/vw` 约束避免超出宿主视口；主搜索和发现优先获得纵向空间。
2. 桌面字号、输入控件和列表行按统一密度档同步增大，避免只放大外框而文字仍拥挤。
3. ≤620px 维持移动 sheet/单列结构；标题与说明压缩为短行，筛选采用单行可横向滚动，结果区设置最小可用高度，底栏继续保留复制/插入、帮助和设置。
4. 移动端搜索输入维持 16px，防止 iOS 聚焦缩放；触控命中区不低于 44px。

## 取舍

- 移动筛选在窄屏可能需要横向滑动才能查看全部选项，但首屏结果区获得稳定空间；完整说明从使用帮助进入。
- 自动化 harness 负责结构与回归，真实思源 Electron 的宿主标题栏裁切和 Android 触控仍需现场确认。
