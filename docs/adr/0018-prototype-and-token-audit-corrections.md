# ADR 0018：原型与 token 的事实差异复核

- 状态：接受
- 日期：2026-10-12
- 关联：T-0043 / R190

## 背景

R189 把生产样式中的字号、行高、间距和圆角数值改为局部变量，并在原型增加了状态矩阵。逐项比对后发现，原型把生产实际隐藏的窄屏预览描述成“移动到列表下方”，并承诺没有实现的长标题全文提示和“查看条目”跳转。样式计数也只说明数值改成变量，并不能证明字号值数量或 4px 间距网格已收敛；token 文件中存在重复及互相覆盖的间距声明。

## 决策

1. 保持 `docs/design/prototype.html` 为唯一人工维护的视觉规范；组件清单和验收文档链接到生产实现与测试证据，不把静态样例当作接线证明。
2. 原型文案必须依生产 DOM/CSS 的真实行为描述。桌面搜索容器宽度 ≤620px 时隐藏桌面预览；首设窄屏提示纵向排列；搜索列表本身不提供展开全文控件。
3. 把 token 引用覆盖、token 数量、唯一视觉数值和网格符合率分开报告。变量化覆盖不等于视觉档位减少。
4. 删除重复且等值的 token 名称；只修复可证明的重复声明和覆盖冲突。字号与非 4px 间距的视觉合并，先建立逐组件、逐断点截图基线，再逐项调整。
5. 原型/生产差异自动门禁和稳定 DOM 控件清单仍是待办；不复制生产业务状态机到原型，也不把 28 项交互审计称为逐节点穷举。

## 取舍

- 选择保留既有尺寸，避免未经测量的密度变化；这意味着 4px 栅格和字号阶梯没有在本轮真正收敛。
- 对静态原型使用人工对照和截图检查，仍可能产生漂移；自动 DOM 对比需要先定义稳定组件标识和允许差异规则。

## 验证

- 原型窄屏、长文本、来源失败和成功反馈逐项对照 `src/styles/index.scss`、`src/ui/dialog.ts`、`src/ui/discovery-dialog.ts`；规范板变量底色、字号档和说明注释也逐项对照 `tokens-r187.scss`。
- 清理重复 `space-1..4`、冲突 `space-5/6` 定义、重复 `radius-xs/sm`；引用切换到等值 token。
- R189 的统计经 token 值解析后更正：字号定义 15 个值，`index.scss` 使用 12 个；字号/行高/字重字面量从 148 降到 0，但唯一字号数不变。间距声明 token 覆盖为 195/200；当前使用 24 个不同数值，9 个位于 4px 网格。
- R190 构建、UI smoke、交互审计和原型渲染复验结果记入 `docs/dev-plan-2026-10-06.md` 与 `docs/acceptance-audit-2026-10-12.md`。

## 未决

- 字号和间距值逐组件收敛，依赖可比较的生产截图基线。
- 原型与生产 DOM 自动差异门禁及逐节点交互清单依赖稳定 ID 约定。
- Electron、Android 和设置宿主异常仍由 B-001 至 B-004 跟踪。
