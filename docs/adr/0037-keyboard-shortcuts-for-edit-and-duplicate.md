# ADR 0037：列表条目快捷编辑与副本复制契约

## 状态

已采纳（2026-10-14，T-0064 / R211）。

## 背景

在小驴常用的高频使用中，条目的维护（编辑修正、基于现有模板衍生新副本）是仅次于调用的核心场景。
既有交互中，用户要编辑当前选中的条目或复制一个副本，必须借助鼠标点击详情操作区的“✎ 编辑”按钮，或者右键弹出动作菜单后再点击。这使得重度键盘用户在浏览与维护内容时频繁需要在键盘与鼠标之间切换，打断了连续心流。

## 决策

1. **快捷编辑（Edit Item）**：
   - 绑定快捷键 `Ctrl + E`（macOS 下 `⌘ + E`，并兼容 `Alt + E`）；
   - 触发条件：当前存在有效选中的真实库条目（非虚拟 Provider 条目）；
   - 行为：`e.preventDefault()` 阻止默认行为，关闭搜索弹窗并无缝呼出该条目的编辑表单（`editItem`）；
2. **快捷复制副本（Duplicate Item）**：
   - 绑定快捷键 `Ctrl + D`（macOS 下 `⌘ + D`，并兼容 `Alt + D`）；
   - 触发条件：当前存在有效选中的真实库条目；
   - 行为：`e.preventDefault()` 阻止浏览器默认书签热键，调用 `duplicateItem` 在库中克隆出带新逻辑 ID 的独立思源块，随后自动刷新搜索列表；
3. **防连发与防冲突治理**：
   - 严格增加 `if (e.repeat) return;`，杜绝用户误长按导致瞬间克隆多个重复条目；
   - IME 组合输入状态下（`e.isComposing`）绝不拦截；
   - 动作菜单（Action Menu）中的“编辑”与“复制副本”项同步标注快捷键提示。

## 验证与边界

- 单元测试覆盖快捷键识别器、有效条目过滤、虚拟条目排除与防连发；
- 生产 UI 交互审计验证 `Ctrl+E` 分派编辑 ID 与 `Ctrl+D` 分派克隆动作；
- 移动端不依赖物理热键，维持长按弹出动作菜单的触摸交互。
