# ADR 0033：模板场景包扩充与注释规则契约

## 状态

已采纳（2026-10-14，T-0060 / R207）。

## 背景

在参考 Quicker 与易歪歪等高频内容工具的场景调研后（参见 [`docs/research-2026-10-14.md`](../research-2026-10-14.md)），现有内置提示词场景包（16 项）主要涵盖了个人信息、基础邮件与开发写作常用件，但对于高频真实的商务往来与客服协同支持不足：
1. **商务与高频客服场景缺口**：
   - 商务往来中最频繁的开票资料（抬头、税号、银行账号、地址电话）；
   - 电商与技术支持中高频的售后退换指引（退换类型、寄回地址、订单号）；
   - 协作中经常需要的温和/正式催办提醒；
   - 知识库与常见问题解答 FAQ 骨架；
2. **模板注释与说明规则不清晰**：
   - 用户在编写含变量的模板时，常需要添加供自己或团队参考的使用说明与避坑提醒，需要统一推荐的正文内注释/说明实践；
3. **快捷调用技巧未在使用说明与帮助中完全体现**：
   - T-0059 增强的 `Alt+1~9` 直达插入、`Alt+Shift+1~9` 直达复制、`Tab` 键平滑跳转预览操作区等键盘高效特性，需要同步纳入使用说明条目与使用帮助体系。

## 决策

1. **场景包扩充至 20 项优质模板**：
   - `xlc-pack00000017`【开票资料】（分类：商务）：涵盖企业抬头、税号、开户行、银行账号、地址电话等必填字段，支持专票/普票类型下拉；
   - `xlc-pack00000018`【售后退换指引】（分类：客服）：涵盖退换类型选择（换货/退款/保修）、订单号、寄回指引与单号填报；
   - `xlc-pack00000019`【事项催办跟进】（分类：写作）：涵盖事项名称、原定期限、当前进度与协助建议；
   - `xlc-pack00000020`【常见问题解答 FAQ】（分类：客服）：结构化问题概述、排查解答、参考文档与后续支持。
2. **明确模板注释与说明推荐规范**：
   - **条目级说明**：优先使用条目块属性 `alias`（别名）作为检索与场景补充说明；
   - **正文内可见提醒**：推荐在模板开头使用 Markdown 引用块（如 `> 💡 注意：...`），提示操作者关键要求；
   - **正文内隐形注释**：支持标准 Markdown 注释 `<!-- 注释内容 -->`，在思源编辑器中不作为段落展示；
   - **变量约束提示**：使用下拉选项语法 `{{xlc:ask:字段|选项A,选项B}}` 规约输入值。
3. **使用说明与帮助同步**：
   - 扩充场景包首篇《使用说明：三步开始》条目正文；
   - 同步更新应用内使用帮助弹窗（`usageGuide*`），补齐 `Alt+Shift+1~9` 复制与 `Tab` 跳转技巧。

## 验证与边界

- 解析器契约验证：`parseMarkdownPack(PROMPT_PACK_MD)` 能够完整、合规地解析 20 个条目，无非法字段，逻辑 ID 符合 `^xlc-[0-9a-z]{10,40}$`。
- 门禁负向验证：注入破坏性条目数或格式错误，确认单元测试失败，恢复后复验通过。
- 所有模板内容保持纯 Markdown / Kramdown 结构，无外部侵入或代码执行风险，导入后作为真实块由用户完全掌控。
