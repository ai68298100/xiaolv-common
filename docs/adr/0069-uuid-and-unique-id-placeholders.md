# ADR 0069：唯一标识与 UUID 动态占位符引擎 (G17) 契约

## 状态

已接受，T-0128 / R275（2026-10-20，对标 Espanso / Raycast / TextExpander 开发者与业务唯一标识生成能力，落地 G17）。

## 背景与上下文

在研发测试、数据模拟、工单流转、合同流水号以及客户追踪等场景中，用户高频需要生成全局唯一标识符（UUID）或短流水编号：
1. **Espanso 对标**：Espanso 核心内置 `uuid` 扩展器，支持快速输出标准 RFC 4122 v4 UUID；
2. **TextExpander 对标**：TextExpander 支持动态计算序列号与全局唯一 ID；
3. **小驴常用现状**：在 R274 完成自定义日期时间引擎后，日期维度已完备，但缺乏生成不可预测唯一标识（UUID / 短 ID）的内置能力。用户若需要插入测试凭证或单号，必须切换至外部工具生成后再粘贴。

## 决策

1. **RFC 4122 v4 UUID 纯函数引擎 (`generateUuidV4`)**：
   - 在 `src/model/placeholders.ts` 实现安全的 v4 UUID 生成器；
   - 优先使用 `crypto.randomUUID()`（Node ≥ 18 与现代 Chromium 宿主全支持），并内置无依赖的 RFC 4122 兼容位运算回退实现；
   - 严格遵循版本号 `4` 与变体位 `10xx` 规范（`[0-9a-f]{8}-[0-9a-f]{4}-4[0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}`）。

2. **紧凑唯一定位符引擎 (`generateShortId`)**：
   - 实现无歧义字符集（排除易混淆的 `0/O`, `1/l/I`）的轻量短 ID 生成；
   - 支持指定长度（4 ~ 32 位，默认 8 位）。

3. **语法与参数扩展 (`resolvePlaceholder`)**：
   - `{{xlc:uuid}}`：生成小写标准 36 位 UUID；
   - `{{xlc:uuid|upper}}`：生成全大写标准 UUID；
   - `{{xlc:uuid|simple}}` 或 `{{xlc:uuid|compact}}`：生成去除短横线的 32 位纯十六进制 UUID；
   - `{{xlc:uuid|upper,simple}}` 或 `{{xlc:uuid|upper|simple}}`：复合选项容错；
   - `{{xlc:id}}`：生成默认 8 位紧凑短 ID；
   - `{{xlc:id|12}}`：生成指定 12 位紧凑短 ID（范围严格限制在 4~32 位，超出范围安全回退为 8 位）；
   - `{{xlc:id|upper}}`：生成大写紧凑短 ID。

4. **安全与兼容性边界**：
   - 保持所有既有占位符逻辑完全向下兼容；
   - 未知参数与非法语法返回 `null`，保持原始 `{{xlc:...}}` 原文绝不吞噬。

## 结果与证据

- 单元测试增设专项套件，验证 UUID 格式标准性、版本与变体位、大写/紧凑形态、短 ID 长度与无歧义字符分布；
- 严格负向验证：故意篡改 UUID 格式或禁用生成，测试精准捕获并失败；恢复后复验全绿；
- 全套工程门禁全数通过。
