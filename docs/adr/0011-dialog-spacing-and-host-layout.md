# ADR 0011：表单弹窗使用显式宿主布局与统一内边距

日期：2026-10-10 ｜ 状态：已采纳

## 背景

新建常用语和首次设置在部分思源前端版本中出现内容贴边。原有样式通过 `:has()` 判断 `.b3-dialog__body` 的子节点是否为 `.xlc-form`，但 `Dialog` 的内容容器在不同版本可能是 `.b3-dialog__body` 或 `.b3-dialog__content`，且中间层级不固定，因此样式命中不稳定。编辑、导入、模板包和使用说明等表单弹窗也有同一风险。

## 决策

1. 所有普通表单类 Dialog 在创建后给 `.b3-dialog__container` 加上 `xlc-form-host`；搜索弹窗和变量填充卡继续使用各自的专用宿主类。
2. `xlc-form-host` 统一设置纵向 flex 布局、`box-sizing: border-box`、18/20px 桌面内边距（窄屏 14/16px）和主体滚动边界。固定高度表单在主体内滚动，标题和外框不随内容增减跳动。
3. 保留 `:has()` 规则作为旧结构的兼容兜底，但产品行为不再依赖它。
4. 新建和编辑表单使用 `min(720px, 90vh)` 高度，长内容保持在视口内；其他设置类弹窗沿用各自既有高度策略。

## 理由与边界

显式宿主类把样式契约从思源内部 DOM 层级中解耦，能覆盖首跑设置、设置、捕获、编辑、导入、说明和体检等所有普通表单。内边距只作用于本插件标记的容器，不修改思源其他弹窗；真实思源 Electron 的最终渲染仍需按 B-001 现场验收。
