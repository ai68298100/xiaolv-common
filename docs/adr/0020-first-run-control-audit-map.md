# ADR 0020：首次设置向导控件审计映射

- 状态：接受
- 日期：2026-10-12
- 关联：T-0045 / R192 / ADR 0019

## 背景

首设向导已有加载、空结果、错误重试、根文档校验、竞态保护和窄屏 smoke，但定位多依赖旧 CSS 类、固定 ID 或按钮文案；完成配置和新建专用库的最终归宿没有正向断言。用户第一次进入插件时，这些操作决定专用库是否被正确创建或绑定。

## 决策

1. 按 ADR 0019 给首设控件增加 `data-xlc-control` 语义标识，覆盖方式选择、文档查询/结果/重试、笔记本选择/重试、新建标题/创建、稍后、下一步、返回和完成。
2. 复用 `render-production.cjs` 中现有生产 DOM smoke，并改用稳定标识驱动；不复制已有状态测试。为文档检索补充乱序响应测试，确认仅最新查询结果能够更新列表。
3. 增加可观察结果断言：选择文档后完成会保存准确目标并关闭；新建库经过确认后保存目标及 `createdDocIds`；稍后退出会关闭且不写配置。
4. 确认回调的自动确认只在显式设置 harness 标记后生效，不修改生产确认行为。
5. 组件目录只声称已被 smoke 触发并有结果断言的控件；设置其余区域和其他页面继续分批映射。

## 取舍

- 稳定标识不会改变样式和业务行为，但需要新控件同步维护目录和 smoke。
- 首设创建在 smoke 中验证生产 DOM 回调、目标配置和关闭归宿；隔离内核证明写路径不等于 Electron 界面端到端验收，后者仍受 B-001 限制。

## 验证

- `pnpm run test:ui` 覆盖首设原有加载/空/失败/重试/异步过期路径，并新增完成、返回、确认创建和稍后退出结果断言。
- 文档检索的旧请求延迟到新请求之后返回时，UI smoke 确认旧结果不会覆盖新结果。
- 负向验证移除 `setup.finish` 标识后，完成路径 smoke 因无法触发目标控件而失败；恢复标识后整套 UI smoke 通过。
- 负向验证移除文档搜索代次检查后，乱序响应 smoke 失败；恢复保护后重跑通过。
- `pnpm run check`、完整包构建、`pnpm test`、`pnpm run test:ix`、隔离内核 E2E、密钥扫描、包检查和文档链接复核记入 T-0045 最终验证。

## 未决

- 设置页其余区域、捕获、变量、导入导出、发现和动作菜单逐控件映射。
- Electron/Android 宿主真实交互仍按 `BLOCKERS.md` 现场验收，不由 Chromium smoke 替代。
