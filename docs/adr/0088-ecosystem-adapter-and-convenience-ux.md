# ADR 0088：小驴生态只读探测适配器与便捷操作体验 (Ecosystem Adapter & Convenience UX)

## 状态
已接受，T-0151 / R292（2026-10-21，用户指令立项：UI 与搜索深度优化、小驴系列插件结合且保证独立运行）。

## 背景与上下文
1. **小驴全家桶生态联动与零强依赖**：小驴系列插件（打卡、人脉、拾遗、雷切等）各自沉淀了独特的垂直领域数据（今日打卡状态、联系人名片、剪藏摘录）。小驴常用作为通用内容调用与复用器，应能够让用户在搜索相关意图时直接调取这些数据；同时必须恪守“零外部强依赖、渐进增强”原则，在未安装其他插件时 100% 独立稳定运行，零额外网络请求；
2. **便捷操作与跨窗口流转**：
   - 筛选标签繁多时，下拉菜单翻找效率低，需要直观的高频热门标签胶囊（Quick Filter Pills）一键过滤；
   - 跨应用办公流中（微信/Word/QQ/浏览器），用户经常在小驴常用中复制后还要按 Esc 关闭弹窗，需要一步到位的“复制并自动关闭”（Copy & Auto-Close）能力。

## 决策

### 1. 零强依赖生态轻量探测器 (`EcosystemAdapter`)
- 新建 `src/service/ecosystem.ts`；
- 纯只读探测当前宿主环境中的公开窗口桥：
  - 小驴打卡：`window.siyuanCheckin` (getItems / 今日打卡清单生成)
  - 小驴人脉：`window.LvContacts` / `window.siyuanContacts` (searchPeople / 联系人名片块生成)
  - 小驴拾遗：`window.siyuanGlean` (listClips / 剪藏引用)
  - 小驴雷切：`window.siyuanSpeedSwitch` (openSwitcher 互调)
- 所有探测与调用均包装在防挂起和隔离沙箱中，外部报错安全静默，未安装插件时静默返回空数组，零副作用。

### 2. 设置面板呈现【小驴家族全家桶协同矩阵】
- 在 `src/ui/settings-dialog.ts` 的外部联动卡片中新增“小驴家族全家桶协同状态”；
- 结构化展现 4 款兄弟插件的安装检测状态、能力描述及联动场景（`✓ 已就绪` 或 `未安装 (可单独使用)`）。

### 3. 热门标签快速筛选胶囊行 (`.xlc-quick-filter-pills`)
- 在搜索弹窗筛选行下方挂载前 6 个高频热门标签（如 `#模板`、`#代码`、`#客服`）；
- 单击即选，双击或再点取消过滤，并与顶部标签选择器双向同步。

### 4. 复制并自动关闭交互 (`Alt+C` / `Ctrl+Shift+Enter`)
- 支持 `Alt+C` 或 `Ctrl+Shift+Enter` 执行“复制并自动关闭弹窗”（Copy & Auto-Close）；
- 文本写入系统剪贴板后立即销毁弹窗（`this.destroy()`），焦点瞬间归还外部前台窗口，配合 `Ctrl+V` 一步到位。

## 结果与证据
- 单元测试增至 710/710 项全部通过；
- 专项契约测试 `tests/ecosystem.test.cjs` 包含 6 项用例，覆盖未安装零开销降级、打卡状态生成、联系人名片格式化以及外部异常严密隔离；
- 全套工程门禁（check, scan, check:errors, check:package, build）全数通过。
