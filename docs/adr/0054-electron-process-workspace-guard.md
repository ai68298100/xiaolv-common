# ADR 0054：Electron 全进程工作区检查与隔离边界

## 状态

已接受，T-0084 / R231（2026-10-16）。

## 触发事实

T-0083 清理回执中出现同一临时镜像启动的额外内核 PID 51040，参数为 `--workspace D:\SIYUAN --port 1228`。日常工作区日志证实 10:12:15 启动并执行自动云同步，最后相关日志为 10:45:26。仅验证临时 renderer、主 PID 和镜像路径不足以保证整个宿主不访问其他工作区；先前“日常工作区未触碰”的笼统声明作废。详见 [事故记录](../electron-isolation-incident-2026-10-16.md)。

## 决策

- 本轮不再启动或附着任何 Electron。保留特定临时 renderer 的功能观测，同时明确镜像整体隔离失效，不把这些结果称为未触碰日常环境的安全验收。
- 新增共享只读进程检查：核对镜像主进程、完整后代和同镜像目录下进程；所有内核必须带唯一显式工作区并精确等于允许的临时工作区。缺失、重复、不可读或出现其他工作区均拒绝。
- 在附着前、连接后的身份复核、每轮和关键 API/UI 操作前检查；CDP target 新增等变化使检查失效，下一动作前重新核对。失败状态保持，工具只写本地证据并断开，不向未知工作区恢复设置、退出或发写 API，也不停止未知进程。
- 该检查只能尽早发现越界，不能阻止同权限宿主在两次采样间启动其他工作区。后续真实宿主实验需另行建立操作系统层面的专用环境，且宿主配置目录、工作区列表、协议关联、云账号与网络边界均有证据；仅复制 exe、另设 Chromium userData 或加临时 `--workspace` 不构成隔离完成。
- 不凭未知同步来源回滚日常数据，不发送上游报告，不修改兄弟插件。

## 验证

使用进程清单夹具覆盖本次真实违规形态、脱离父树的镜像内核、缺失/重复参数和正常临时树；真实移除防护后负向测试必须失败，原字节恢复后再通过。本轮验证限本地单元与脚本语法，不重新启动宿主冒险验证。

## 结果与限制

- 共享进程检查专项 11/11，客户端页面/导航检查 5/5。四个近期采集器均在解析参数和连接前检查全部镜像进程，随后在关键 API、UI 动作、重载及每轮前复查；失败后不恢复设置、不发退出/写 API、不截图，也不停止未知进程。协议竞态采集器取消尚未放行的真实请求，不能在 `finally` 继续插入。
- 真实删除“同镜像脱离父树进程扫描”后专项 8 过 3 败；删除工作区精确比较后 7 过 4 败；均原字节恢复到 11/11。证据：本机临时目录 `xlc-r231-guard-negatives-V0d5Mu/result.json`。
- 临时绕过客户端动作前检查后 5 项中 3 项失败，原字节恢复后 5/5；证据 `xlc-r231-wrapper-negative-1792119985488.json`。
- 四入口离线 preload 探针把本次 PID 51040 违规进程清单交给真实参数入口，4/4 在连接前拒绝，连接与写入均为零；合法单核对照 4/4 到达连接 spy 后被阻止，仍没有真实 CDP 连接。删除工作区比较后四入口全部误放行到 spy、探针 exit=1，恢复后 4/4。汇总：`xlc-electron-r231-entry-probe-20261016110816020/mutation-restoration-summary.json`。
- 最终 `pnpm test` 484/484，类型检查、六个脚本语法、密钥扫描、包检查 13 项与 diff 检查通过。生产源码与 T-0083 最终构建一致，本轮没有重新启动或附着宿主。

B-005 继续开放。以上证据只证明离线夹具中的检查和接入有效，不能证明操作系统隔离已经建立，也不能确定日常数据影响。
