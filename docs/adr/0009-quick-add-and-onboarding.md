# ADR 0009：显式新增入口与可跳过的内置使用引导

日期：2026-10-09 ｜ 状态：已采纳

## 背景

搜索弹窗已有捕获命令、剪贴板、右键、工具栏和空库新建，但用户在有搜索结果或搜索无结果时看不到统一的新增动作。内置模板和变量能力也缺少一屏可重复打开的使用说明。参考 Quicker 常用语动作页的做法，新增内容和使用方法都应在高频动作旁边可达。

## 决策

1. 桌面搜索弹窗顶栏常驻「＋新建」按钮；普通搜索无结果时在空态显示同一动作。两处都复用 `CaptureDialog.newManual()`，避免第二套保存路径。
2. 无结果按钮只把普通查询作为可编辑的标题候选，不把查询词静默写入正文；`?` 语义查询不预填查询文本。
3. 搜索弹窗提供一屏「使用说明」，说明增加、搜索、插入、变量和真源边界；说明是本地 UI 文案，不依赖外部页面。
4. 预置分类和示例模板通过现有模板包显式导入，导入前仍经过策略确认，导入后成为真实思源块；不在启动时静默写入。模板只使用占位符，不内置真实地址、邮箱或密码。
5. 命令面板增加「新建条目」（`⌥⇧N`）入口，覆盖未打开搜索弹窗时的手动新增路径。

## 理由与边界

- 新增入口的回调、去重、回执和真源约束集中在现有捕获表单，降低行为分叉。
- 普通查询标题候选提升连续输入效率，但保留用户确认；正文仍需用户明确填写。
- 模板导入可跳过、可删除、可编辑、可再次分享，符合块是真源和幂等导入约束。
- 「地址/邮箱」仅作为分类和占位符示例；本插件不变成密码管理器，也不保存秘密。

## 验收

- 顶栏按钮在普通搜索、筛选、收藏/最近为空和无结果时都可见；点击只打开一个现有新建表单。
- 普通查询无结果显示新增 CTA；标题可编辑、正文不被静默填充，取消不落块。
- 使用说明在桌面和移动端弹窗可达，键盘和屏幕阅读器可识别按钮。
- 模板包包含说明条目及联系方式相关分类，重复导入按稳定 ID 跳过；`pnpm test`、`pnpm run check`、`pnpm run build` 通过。
