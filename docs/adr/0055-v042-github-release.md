# ADR 0055：v0.4.2 GitHub 发版范围与证据

## 状态

已接受，T-0085 / R232（2026-10-16，用户指令“发版”）。

## 决策

- 沿用现有 0.4.x 内测版本节奏，发布 v0.4.2；包含自 v0.4.1 以来的向后兼容改动，保持思源真实块和 `xiaolv-common/v1` 合同，无破坏性迁移。
- 目标为 `ai68298100/xiaolv-common` 的 GitHub main、tag 和附带 `package.zip` 的 Release。此次指令没有明确授权集市，不改 `bazaar/plugins.txt`，不创建上架 PR，也不发送上游报告。
- 版本、中文/英文 README 和 CHANGELOG 同步。发布说明覆盖引用入口与标签保存视图、搜索和快捷工作流、目标冻结和回执修复，并保留已知限制。
- B-005 不因发版解除：测试镜像曾额外启动日常工作区并自动同步，影响未确定；Electron 证据仅为特定临时 renderer 的局部观测。新增检查只能检测越界，后续宿主实验仍需操作系统层隔离。
- 本次不启动或附着思源宿主。重新执行类型、484 项单元、生产构建、Chrome 生产 UI/交互、密钥与包检查；此前 T-0083 的核心/发现内核证据按对应源码身份复用，明确不是本轮新跑。生产改动若使对应源码身份变化，重新评估而不冒充复验。
- 按现有 CI 使用 tag 触发构建与 Release；等待门禁和上传完成后核对远端 tag、版本及 zip 内容，下载发布附件并校验哈希。

## 验证与结果

进度和最终远端证据记录在当期账本 T-0085。开放的 Android、真实 AI、连续嵌入后选区和 B-004/B-005 边界保留，不以发布成功代替宿主验收。
