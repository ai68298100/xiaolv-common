# ADR 0015：R54 视觉语言与跨页面层级

日期：2026-10-11 ｜ 状态：已接受 ｜ 任务：T-0040

## 背景

小驴闪卡 R54 和小驴打卡的新页面使用浅薰衣草画布、白色工作面、克制的暖色提示和更宽松的间距。小驴常用此前各弹窗沿用宿主灰色变量，搜索、发现、捕获、设置和变量填写卡的层级不一致，移动端发现预览也容易被挤到不可读。

## 决策

1. 在小驴常用内建立局部 R54 视觉基座，使用 `tokens-r187.scss` 提供浅/深主题、语义颜色、间距、圆角、控件高度和焦点态；不覆盖思源全局主题。
2. 保留现有搜索弹窗和表单 DOM/能力，统一白色工作面、描边卡片、主动作和状态回执；不引入侧边导航或闪卡 KPI。
3. 发现页继续保持“范围 → 候选 → 预览 → 收录”的单页工作流。桌面双栏，窄屏使用根滚动，预览正文至少保留可读高度，页脚动作可滚动到达。
4. 所有异步扫描、收录和撤销在状态变化后立即同步控件锁；批量重复策略按开始时快照执行；范围切换清空旧候选、预览和分类覆盖。
5. 新增 `docs/design/prototype-r187.html` 作为可点击的交互原型，仅演示已存在的能力边界，不承诺自动创建笔记本或模板文档。

## 后果

- 主搜索、按需发现、捕获、设置、首用和变量填写卡拥有一致的视觉层级，暗色和触控尺寸也有明确降级规则。
- 生产 smoke 需要检查根滚动下的预览正文可达性，而不能要求整个发现预览首屏完整出现。
- R54 的颜色只在插件标记根和显式宿主容器内生效；真实思源 Electron 与 Android 仍需现场验收。
