# ADR 0016：R188 表单与动作区可达性

日期：2026-10-12 ｜ 状态：已接受 ｜ 任务：T-0041

## 背景

R187 的生产截图暴露了三类可见问题：设置和捕获页的导语仍使用浏览器默认段落样式；桌面表单的吸底操作区会覆盖下一组字段；详情窗格和动作菜单在内容较多时会把末尾按钮裁出容器。首次设置的三步说明卡也挤占了库方式选择的首屏空间。

## 决策

1. 给 `.xlc-page-intro` 使用统一的次级文字层级和零默认边距，避免裸 `p` 改变页面节奏。
2. 桌面普通表单的操作区随主体自然滚动，移动端继续吸底；表单末尾保留安全间距，避免最后一组字段被操作区遮挡。
3. 详情窗格动作区固定为不可压缩的单行紧凑布局；动作菜单向上留出宿主裁切安全区，并保留内部滚动。
4. 首跑三步说明在桌面改为紧凑三列，移动端保持纵向卡片，说明内容和操作顺序不变。

## 后果

- 桌面首屏不会再出现裸 key、大段默认段落留白或被 sticky 操作栏盖住的字段。
- 详情动作、菜单返回项和表单保存动作均能通过滚动或当前视口完整到达。
- 生产 smoke 需要检查根滚动下的预览正文可达性，而不能要求整个发现预览首屏完整出现。
- 真实思源 Electron/Android 仍需现场验收。
