# ADR 0034：面板拖拽放置与粘贴捕获契约

## 状态

已采纳（2026-10-14，T-0061 / R208）。

## 背景

在参考同类高频内容工具（Quicker 常用语、易歪歪等，参见 [`docs/research-2026-10-14.md`](../research-2026-10-14.md)）的输入工作流后，从外部拖入内容或在面板中直接粘贴是高频收集条目的典型手势：
1. 用户在外部浏览器、代码编辑器或思源其它页面选中文本、网址或代码片段，直接拖放进小驴常用搜索面板；
2. 用户在常用语面板浏览时，按 `Ctrl+V`（macOS `⌘+V`）希望直接将刚复制的内容转为新条目草稿。

既有实现需要先点击「＋ 新建条目」打开空白表单，再手动粘贴正文，操作链路偏长；而在搜索面板内未处理 `drop` 事件还会导致浏览器尝试导航或无响应。

## 决策

1. **搜索面板拖拽放置（Drag & Drop）**：
   - 在搜索主面板（`CommonSearchDialog`）监听 `dragenter`、`dragover`、`dragleave`、`drop`；
   - 拖拽进入时展示高亮浮层 `.xlc-drop-overlay`（提示「松开以添加常用条目」）；
   - `drop` 提取 `text/plain` 或 `text/uri-list` 文本，阻止默认页面跳转；
2. **非输入框区域快捷粘贴（Paste Capture）**：
   - 在搜索面板监听 `paste` 事件；
   - 当焦点处于候选列表、背景或非编辑控件时，拦截剪贴板文本并触发新建草稿；
   - 严格保留搜索输入框（`.xlc-search-input`）内部的原生粘贴行为，不破坏用户粘贴查询关键词；
3. **类型推断与安全授权红线**：
   - 提取到文本后，通过 `inferTypeFromText` 智能识别类型（`url`、`code`、`markdown`、`text`），并以首行推断建议标题；
   - **严格禁止静默写库**：捕获结果作为初始正文预填至 `CaptureDialog`，由用户核验、补充标签/分类并显式点击保存；
   - 文本一律作为纯文本处理，不作为 HTML 执行；
4. **生命周期治理**：
   - 在 `CommonSearchDialog.destroy()` 时彻底解绑全部拖拽与粘贴监听器，清理浮层元素。

## 验证与边界

- 单元测试验证类型推断、多源标题衍生与超长文本裁剪；
- 生产 UI 交互审计验证面板内粘贴与拖拽放置事件的分派与表单预填；
- 搜索输入框内的输入与常规粘贴不受任何干扰，负向验证确保输入框粘贴不误触新建表单。
