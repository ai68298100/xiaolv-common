## [0.6.8] — 2026-10-24

深度融合思源块双链体系与外部连续调用：窗口固定连续取用模式 (Alt+P)、块引用双链语法秒复 (Alt+R)、来源定位 (Alt+D)、多选复选变量交互 (multi)。

### 新增与核心优化

- **📌 窗口固定与连续调用模式 (`Alt+P`)**：顶栏新增固定按钮，开启后无论是插入编辑器、复制文本还是复制块引用，弹窗保持打开不销毁，专为微信、Excel、多字段表单填写等跨应用高频连续取用场景打造。
- **思源双链联动：块引用语法秒复 (`Alt+R`)**：全域检索（包括思源全库块与常用语）按下 `Alt+R`，自动提取目标块 ID 并生成标准思源块引用语法 `((blockId '锚文本'))` 写入剪贴板。
- **定位源文档块 (`Alt+D`)**：搜索选中任意块或常用条目，按 `Alt+D` 直达源文档并滚动定位高亮，快速审阅上下文。
- **多选复选变量类型 (`multi`)**：支持 `{{xlc:ask:需求|UI设计,前端开发,测试验收|multi}}`，在填参卡片呈现多选胶囊，支持用户自由点选复选多项并实时合并求值。
