# T-0121 / R268：详情预览轻量富文本与代码语法安全着色引擎 (G6)

日期：2026-10-19

## 目标

为对标 Raycast / TextExpander Snippet Preview 核心体验（G6），在右侧详情预览窗格提供高质量、现代化且严格零注入（防 XSS）的代码语法高亮与 Markdown 结构化着色：
1. 坚守插件安全红线（约束 7：外部文本一律按文本节点渲染，不注入 HTML），所有 DOM 构建均通过 `document.createTextNode` 挂载，绝对杜绝 `innerHTML` 与脚本注入风险；
2. 代码模式（`itemType === "code"` 或代码围栏）提供语言徽标栏、行数统计、行号对齐与关键字、字符串、数字、注释及内嵌 `{{xlc:...}}` 变量占位符安全着色；
3. Markdown 模式提供标题（H1/H2/H3）、引用块、列表项、粗体、行内代码与链接的结构化语义渲染；
4. 保证复制与插入动作 100% 保持原始 Kramdown / 纯文本真源，不受预览 DOM 影响；
5. 全面兼容亮色、暗色主题以及 Windows `forced-colors: active` 系统高对比度模式。

## 实现

- `src/ui/preview-renderer.ts`：
  - 导出 `tokenizeCodeLine`：词法分词，精准切分代码中的关键字、字符串、数字、注释与内嵌占位符变量；
  - 导出 `tokenizeMarkdownInlines`：解析粗体、行内代码、Markdown 链接与占位符变量；
  - 导出 `parseMarkdownBlocks`：多行文本结构化为标题、引用块、列表项、分隔线、围栏代码块与普通段落；
  - 导出 `renderSafePreview`：纯 DOM 构造与安全挂载，绝不调用 `innerHTML`。
- `src/styles/tokens-r187.scss`：
  - 在 `light-palette` 与 `dark-palette` 增补 `--xlc-tok-kw`, `--xlc-tok-str`, `--xlc-tok-num`, `--xlc-tok-comment`, `--xlc-tok-var` 语法令牌；
  - 在 `@media (forced-colors: active)` 映射到 `Highlight` 与 `CanvasText`，并将 `.xlc-preview-code`, `.xlc-code-banner` 赋予 1px CanvasText 边框；
  - 声明 `.xlc-code-banner`, `.xlc-preview-code`, `.xlc-code-line`, `.xlc-line-num`, `.xlc-tok`, `.xlc-md-*` 等样式类。
- `src/ui/dialog.ts`：
  - 引入 `renderSafePreview` 并在 `updatePreview` 中接管正文渲染，保留纯文本回退与无活动状态降级。
- `tests/entry.ts`：
  - 导出 `previewRenderer` 供测试套件统一引用。
- `tests/r268-preview-highlight.test.cjs`：
  - 编写 5 项专项测试用例，覆盖关键字与字符串识别、内嵌占位符切分、行内格式、Markdown 多行块结构与防 XSS 注入安全验证。
