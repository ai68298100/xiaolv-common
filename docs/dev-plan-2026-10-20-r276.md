## 二、目标与拆解

1. **安全轻量 Markdown 转 HTML 纯函数 (`renderSafeHtmlFromMarkdown`)**：
   - 在 `src/model/clipboard.ts` 实现零外部依赖的 Markdown 到安全 HTML 转换器；
   - 严格进行 HTML 实体转义（`&`, `<`, `>`, `"`），杜绝 XSS 注入；
   - 支持加粗（`<strong>`）、斜体（`<em>`）、删除线（`<del>`）、行内代码（`<code>`）、超链接（`<a href>`，仅限 http/https/mailto）、引用块（`<blockquote>`）与无序/有序列表（`<ul>/<li>`、`<ol>/<li>`）；
   - 支持段落换行与保留结构排版。
2. **多 MIMETYPE 剪贴板写入能力 (`writeRichClipboard`)**：
   - 优先通过 `navigator.clipboard.write([new ClipboardItem({ 'text/plain': ..., 'text/html': ... })])` 写入双载荷；
   - 当宿主环境权限受限或不支持 ClipboardItem 时，平滑安全回退至标准纯文本写入；
   - 纯函数模型，支持测试夹具与桩验证。
3. **执行层接入 (`ActionExecutor`)**：
   - 在条目复制（`copyItem`）和全域条目复制中透明接入，无需用户切换模式；
   - 复制 Markdown 或 Text 类型条目时，自动同步携带经过转义清洗的 HTML 载荷。
4. **自动化测试与负向验证**：
   - 编写 `tests/r276-rich-clipboard.test.cjs` 验证 HTML 转换保真度、XSS 注入防护与剪贴板载荷契约；
   - 执行负向违规注入验证，并通过全套工程门禁。
