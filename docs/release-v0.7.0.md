## [0.7.0] — 2026-10-24

原生块生态与自动化联动里程碑：思源属性视图（AV 数据库）自动化联动指引、timestamp 时间戳与 ISO week 周数自然计算宏、活资产与快照双模态直出。

### 新增与核心优化

- **思源属性视图（AV 数据库）自动化联动**：在设置面板增加原生属性视图（Attribute View）联动指引；因为小驴常用条目天然锚定在真实块上并携带标准的 `custom-xlc-*` 属性，用户可在思源笔记中任意插入属性视图并配置规则「`custom-xlc-id 存在`」，自动以原生表格、看板多维聚合管理全部常用资产。
- **时间戳与周数动态宏扩展**：新增 `{{xlc:timestamp}}`（秒级 Unix 时间戳）、`{{xlc:timestamp|ms}}`（毫秒级时间戳）、`{{xlc:week}}`（ISO 周数，如 `第43周`、`W43`、`43`），并在变量快捷条中提供一键点选。
- **活资产与快照双模态直出**：支持 Shift+Enter 一键插入思源原生嵌入块（Notion Synced Block 同款，源变动时多处自动同步更新）与 Alt+Enter 一键插入块引用。

### 验证与已知边界

- 全套质量门禁：单元测试 728/728 全绿通过、TypeScript 类型检查 0 错误、错误处理静态扫描、密钥安全扫描、安装包根相对结构校验（15 项必需资源健全）全部通过。
