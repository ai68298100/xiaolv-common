# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.6.x   | :white_check_mark: |
| < 0.6.0 | :x:                |

## Reporting a Vulnerability

If you discover a potential security issue in **xiaolv-common (小驴常用)**, please report it privately:

1. Open an issue on GitHub with title `[Security] ...` or submit via GitHub Security Advisories.
2. Provide steps to reproduce the issue.
3. We will respond within 48 hours to assess the impact and provide an update or fix.

Please do not disclose security issues publicly until a patch has been released.
